## 四、对 BAE 开发优先级的阶段性发现（首批 10 教程汇总）

对照 `docs/ui/motion-parity.md`，首批 10 个高频新手教程中**出现频次最高、但 BAE 目前为 `☐`（未实现）**的 8 大断层：

1. **工具栏与查看器直接创建（Shapes / Pen / Text / Mask）**：新手第 10 分钟内就会用 `Q`/`G`/`Cmd+T` 直接在合成查看器里拖画形状、蒙版和点击打字，且高度依赖「无选层建形状 vs 有选层建蒙版 vs 选形状层切换按钮」这一核心分流逻辑，以及双击工具铺满合成、拖拽中 `Shift`/`Space`/方向键修饰。
2. **查看器直接操作手柄（缩放 / 旋转 / 锚点 / 运动路径 / 临时手形与吸附）**：目前仅支持选取工具拖动位置，缺角点缩放手柄、旋转工具 `W`、锚点工具 `Y`（及 `Cmd/Ctrl+Alt+Home` / `Cmd/Ctrl+双击 Y` 居中）、按住 `Space` 临时手形、按住 `Cmd/Ctrl` 吸附和运动路径贝塞尔调柄。
3. **图表编辑器（`Shift+F3`）与单独尺寸**：所有动效教程在第 15–30 分钟必讲 `F9` + 进速度/值图表拉曲线手柄，以及拆分位置的「单独尺寸」。
4. **渲染队列导出面板（`Cmd/Ctrl+M`）**：全部完整新手教程的收尾一步，包括渲染设置、工作区域时间跨度、H.264 预设下拉、多输出模块 `+`/`-` 与输出路径。
5. **首选项对话框（`Cmd/Ctrl+Alt+;`）与快捷键编辑器（`Cmd/Ctrl+Alt+'`）**：尤其「在新形状图层中居中锚点」「路径点手柄大小」「网格与参考线」是新手教程反复提醒必改的设置。
6. **合成设置（`Cmd/Ctrl+K`）与预合成对话框（`Cmd/Ctrl+Shift+C`）**：几乎每个真实项目都会在制作中途修改合成时长或打包多个图层为预合成。
7. **效果和预设面板（搜索 + 拖拽/双击应用）与对齐面板**：新手加效果几乎全靠「效果和预设」搜索拖放，排版全靠「对齐」面板一键居中。
8. **时间轴效率细节**：按住 `Shift` 拖播放头/图层边吸附、按住鼠标上下扫拖开关列、波浪键 `` ` `` 最大化鼠标所在面板、单键展开 `E`/`M`/`F`/`L` 与递归 `Cmd/Ctrl+点击 ▶`。

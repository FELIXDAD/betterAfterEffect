# AE 26.2.1（macOS）键盘快捷键对话框实测

> 来源：Adobe After Effects 26.2.1（26.2.1x2），macOS，主屏 1920×1080，英文界面；中文按 AE 自带的 zh_CN 词典逐条核对（键名见 JSON 的 `dictKey`）。2026-11-24 实测。
> 机器可读版本：[`keyboard-shortcuts.json`](keyboard-shortcuts.json)。Windows 26.0 的记录：[`../../ui/dialogs/keyboard-shortcuts.json`](../../ui/dialogs/keyboard-shortcuts.json)。
> 只记结构、文字和行为，不提交截图。

## 打开

编辑 ▸ 键盘快捷键（⌘⌥'）。模态对话框，1520×887 pt，深灰底（#272727），打开时菜单和面板都不可用，搜索框获得焦点。

## 布局（自上而下）

1. **预设:** 下拉（当前 `After Effects Default.txt`）、**另存为...**、**删除**（选内置预设时置灰）、**复制到剪贴板**；右侧 **键盘布局 -** 下拉（`en`）。
2. **命令:** 下拉（应用程序 / 分隔线 / 11 个面板，按字母顺序）。
3. **可视化键盘**：主键区、功能键、编辑键区（无 Esc、Help、Insert）、方向键、数字小键盘；键帽左上写命令名（白色，最多两行，超长加 `...`），左下写键名。
4. 图例：紫色“无论面板焦点如何，应用程序快捷键都处于活动状态”、绿色“面板具有焦点时，面板快捷键会覆盖应用程序快捷键”、蓝色“按下辅助按键”。
5. 左下：搜索框 + 命令树（列：命令、快捷键）；右下：**键:** 标签 + 键表（列：修饰符、命令）+ **撤消**、**清除** 按钮。
6. 底部：提示栏（默认 ⓘ“通过单击“快捷键”列创建新快捷键或编辑现有快捷键”，冲突时换成 ⚠ 警告）、**取消**、**确定**（蓝色，默认按钮）。

“命令: 应用程序”时：只有应用程序命令的键是纯紫；只有面板命令的键左上灰、右下绿（沿左下到右上的对角线分开），不写名字；两种都有的左上紫、右下绿，写应用程序命令名。选某个面板时：只显示这个面板的快捷键（纯绿，写面板命令名），其他键全灰。

## 交互

- **修饰键**：点键盘上的 ⌘ / ⌥ / ⇧ / ⌃ 键帽会“按住”它（两个同名键都变蓝），可以叠加（先点 ⌘ 再点 ⇧ 显示 ⇧⌘ 层），再点一次松开；按住实体修饰键时同样显示该层，松手恢复。
- **悬停**：约 1 秒后显示提示，每个分配一行：`应用程序: 命令名 (应用程序 → 菜单 → 命令名)`；同时有面板命令时再加一行 `字符和段落面板: … (面板 → 字符和段落面板 → …)`。
- **点键帽**：键帽出现蓝色描边，右下变成“键: K（已分配多个命令）”，键表列出 16 种修饰组合（无、⌘、⌥、⇧、⌥+⌘、⇧+⌘、⌥+⇧、⌥+⇧+⌘、⌃、⌃+⌘、⌃+⌥、⌃+⇧、⌃+⌥+⌘、⌃+⇧+⌘、⌃+⌥+⇧、⌃+⌥+⇧+⌘）下的全部命令（应用程序和面板命令用“, ”连起来）。“（已分配多个命令）”在这个键一共有多于一个命令时出现。
- **命令树**：顶层“应用程序”“面板”。应用程序下先是 27 个工具命令（不分组），再按菜单分组（文件、编辑、合成、图层、效果、动画、视图、窗口，子菜单是下一级分组），最后是不在菜单里的命令（取消预览、帮助、首选项、退出……）；面板下每个面板一组。打开时两个顶层展开、各分组折叠；点分组行展开 / 折叠。
- **快捷键列**：未选中的行显示纯文字（“⌘+N, ⌘+K”）；选中的行每个快捷键是一个胶囊（圆角边框 + ×）。第一次点快捷键列：选中该行并聚焦第一个胶囊；再点空白处：多出一个空胶囊等待按键；按下组合键：立即分配，胶囊加在后面；点胶囊的 ×：立即删除。
- **快捷键写法**（Mac）：修饰键按 ⌃ ⌥ ⇧ ⌘ 的顺序用“+”连接，再加键名：`⌃+⌥+⇧+⌘+J`、`⌥+* (Num)`。键名：Return（返回）、Enter (Num)（输入（数字））、Escape、Delete（退格，删除）、Forward Delete（向前删除）、Home（开头）、End（结束）、Page Up（页上移）、Page Down（页下移）、Up / Down / Left / Right（向上 / 向下 / 向左 / 向右）、Space（空格）、数字小键盘加“ (Num)”（中文“（数字）”）。
- **冲突**：给“新建合成”加 ⌘K（原属“合成设置”）：⌘K 立刻归新建合成，合成设置的 ⌘K 被拿走；底部 ⚠：“The shortcut: ⌘+K is already in use by another Application command: Composition Settings. That command will no longer have a shortcut.”（中文“快捷键“⌘+K”已被另一个应用程序命令“合成设置”使用。该命令将不再有快捷键。”），命令名是蓝色链接，点了选中那一行。面板内冲突和“面板命令覆盖应用程序命令”两种提示只在词典里看到（见 JSON）。
- **撤消**：只有一级，撤消最近一次改动（冲突分配连同被拿走的快捷键一起恢复），之后置灰；提示栏清空。预设名不会改回默认值。
- **清除**：聚焦胶囊时可用，删除该快捷键（未实测）。
- **拖放**：把命令行拖到键帽上 = 给它加上“该键 + 当前修饰键”。例：合成设置拖到 F5 → F5 变紫绿、写“Composition Settings”，键表列出“Show Snapshot 1”“Composition Settings”两个胶囊；F5 原来只有面板命令，所以没有冲突提示。
- **搜索**：实时过滤命令树，命中的行连同上级分组展开显示；有文字时右侧出现 ×；键盘不变。改动快捷键后搜索被清空。
- **预设**：一改内置预设，预设名立刻变成 `Custom.txt`，删除按钮可用，下拉里出现 `After Effects Default.txt` 和 `✓ Custom.txt`。**AE 当场把 Custom.txt 写进 `aeks/`，按取消也不删**（这次实测就因此在用户的 AE 里留下了 Custom.txt，协调人已移走）。当前预设在 AE 退出时写进 Prefs.txt 的 `Shortcut File Location`。
- **另存为...**：弹出“创建预设”（354×240）：标题、横线、“预设名称 -”输入框（填好当前名字含 .txt，全选）、取消 / 保存（蓝）。新预设的默认名“无标题自定义预设”，名字非法、重名覆盖的提示见 JSON。
- **复制到剪贴板**：把整棵命令树（不管搜索、作用域、展开状态）复制成文字：每行 `<缩进的 Tab><名称>\t<快捷键>\t`，行尾 `\r`，最后多一个空行；分组行快捷键为空。复制后对话框底部中间弹出绿色提示“✓ Copied to clipboard ×”（中文“复制到剪贴板”），约 2 秒后淡出。
- **键盘布局**：Mac 上依次为 en、sv、ru、pt、nb、ko、de、it、es、fr、ja，只影响键帽文字。
- **Esc** 关闭对话框，等同取消（没有胶囊等待按键时）。**Return** 是确定（为了不改用户设置，未按）。

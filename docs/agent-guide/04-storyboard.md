# 04 · 分镜规范

分镜表（`Board`）由分镜格（`Panel`）组成。每个分镜格对应一个镜头（`Shot`），镜头再把分镜格、动效合成、剪辑片段串起来（见 [01 概念与术语](01-concepts.md)）。本章规定分镜格里各字段的写法，让分镜师、动效师、剪辑和 Agent 读到的是同一种语言。

分镜格的字段由 13 `ui/design` 定义：镜头号、时长、景别、台词、动作、镜头运动、备注。本章另外建议了"转场"和"声音"两项，字段名在 13 实现前都是待确认。

> 本章的工具名是 `bae mcp` 里的实际工具名；还没提供或还没接入的工具，以及替代做法，见 [tools.md](tools.md)。

## 1. 镜头号

- 格式：`SH` + 三位数字，按 10 递增：`SH010`、`SH020`、`SH030`……
- 中间插入新镜头用中间的数：`SH010` 和 `SH020` 之间插入 `SH015`；再插入用 `SH012`、`SH013`。
- 需要场号时加前缀：`SC01_SH010`。一个项目里要么都带场号，要么都不带。
- **镜头号一旦分享给别人就不再改。** 删掉的镜头号空着，不要把后面的镜头重新编号——动效合成、剪辑片段、批注都在引用它。
- 镜头号在其他地方的写法：动效合成 `SH010_<用途>`；工程层 `anim/shot010`。

## 2. 时长

- 用**帧数**写，后面括号里写秒数和帧速率：`72f（3.0s @24）`。帧速率以工程设置为准。
- 时长是这个分镜格在画面上停留的时间，必须是整数帧。
- 有台词或旁白的镜头，时长至少要容纳台词：中文配音按每秒 4 字、英文按每秒 2.5 个单词估算，前后各留 0.5 秒。
- 没有台词的镜头一般不短于 1 秒（快切蒙太奇除外）。
- 每次修改时长后，核对整张分镜表的总时长是否符合交付要求。

## 3. 景别

用下面这组固定写法，中文在前、缩写在后：

| 写法 | 含义（以人物为参照） |
|---|---|
| 大远景 ELS | 环境为主，人物很小或看不到 |
| 远景 LS | 人物全身占画面一小部分，交代环境 |
| 全景 FS | 人物全身刚好在画面内 |
| 中景 MS | 膝盖或腰部以上 |
| 近景 MCU | 胸部以上 |
| 特写 CU | 肩部以上或面部 |
| 大特写 ECU | 局部细节（眼睛、手、产品细节） |

没有人物的图形动画（信息图、Logo、UI 演示）可以不写景别，改在"动作"里写构图，例如"Logo 居中，占画面宽度 40%"。

## 4. 镜头运动

### 4.1 词汇

只用下面这些词，后面跟参数：

| 写法 | 含义 | 参数 |
|---|---|---|
| 固定 | 镜头不动 | — |
| 推 / 拉 | 靠近 / 远离主体 | 起止缩放或景别，例如 `推 MS→MCU` 或 `推 100%→115%` |
| 摇 | 原地左右转动 | 方向和角度：`摇 左→右 30°` |
| 俯仰 | 原地上下转动 | `仰 15°` |
| 移 | 平行移动 | 方向：`移 →`、`移 ←` |
| 升 / 降 | 上下平移 | `升` |
| 跟 | 跟随主体 | 跟谁：`跟 主角` |
| 变焦 | 改变焦距 | `变焦 50mm→85mm` |
| 甩 | 快速摇镜，带模糊，常用作转场 | 方向 |
| 手持 | 轻微晃动 | 强度：轻 / 中 / 强 |

### 4.2 完整写法

```
<运动> <参数>，<起止帧>，<缓动预设>
```

例子：

- `推 100%→112%，0–72f，柔和`
- `移 →，0–48f，线性（缓慢漂移）`
- `固定`
- `甩 →，60–72f，出场·强；接下一镜头`

缓动预设的名字见 [03 动画规范](03-animation.md) 第 2.4 节。

### 4.3 画面上的标注

在分镜画面上画镜头运动时：

- 实线框表示**起幅**（运动开始时的取景），虚线框表示**落幅**（运动结束时的取景）；
- 起幅到落幅之间画一个空心箭头表示镜头运动；
- 画面里的主体运动用实心箭头；
- 两种箭头不要混用。

## 5. 动作

- 用现在时、主语 + 动作，一个节拍一行，前面写帧号或帧范围（相对于本镜头开始）：

```
0–12f   标题从下方升起
12f     副标题淡入
24–36f  下划线从中间向两侧展开
36f–    停留
```

- 写"看到了什么"，不写"感觉"："产品从左侧滑入，停在画面中央"，而不是"产品很酷地出现"。
- 关键节拍和音乐卡点写清楚帧号，动效会按这个帧号做。

## 6. 台词与声音

- 台词 / 旁白：先写说话人，再写内容，前面写起始帧：`12f  旁白：每一帧，都在 GPU 上完成。`
- 音效：`SFX：嗖 @12f`、`SFX：落地 @24f`。
- 音乐：`音乐：鼓点进入 @0f`、`音乐：第 2 段 @bar_09`。

## 7. 转场（到下一个镜头）

默认是"切"，不用写。其他写法：`叠化 12f`、`推移 → 16f`、`擦除 ↓ 12f`、`匹配转场：圆形 → 下一镜头的 Logo`。时长用帧数。转场类型见 [03 动画规范](03-animation.md) 第 6 节。

## 8. 备注

写制作说明、参考、待定事项。待定事项用 `待定：` 开头，方便搜索：`待定：产品图等客户提供，先用占位`。

## 9. 模板

| 字段 | 内容 |
|---|---|
| 镜头号 | `SH010` |
| 时长 | `72f（3.0s @24）` |
| 景别 | `中景 MS` |
| 镜头运动 | `推 100%→112%，0–72f，柔和` |
| 动作 | `0–12f 标题从下方升起` / `12f 副标题淡入` / `24f– 停留` |
| 台词 | `12f 旁白：……` |
| 声音 | `SFX：嗖 @0f` |
| 转场 | `切` |
| 备注 | `待定：标题文案` |

## 10. Agent 处理分镜时的规则

- 分镜画面是分镜师的作品：可以补充、规范化文字字段（镜头号、时长、动作描述），不要重画或修改画面，除非用户要求。
- 修改分镜格时用 `panel_update`，同一张分镜表的一批整理放在一个事务里。
- 分镜格和动效合成的 Shot 关联不要断开；升级为动效合成用 `panel_promote_to_comp`，不要手工新建一个同名合成。
- 整理完成后核对：镜头号唯一、没有重新编号、每格时长是整数帧、总时长符合要求。
- 生成动态分镜的步骤见配方 [分镜生成动态分镜](recipes/animatic.md)。

# 配方：数据图表动画

柱状图、折线图、饼图的生长动画，加数字滚动。数据图表的第一原则是**准确**：动画结束时的画面必须是正确的图表，动画过程中也不能误导。

## 1. 输入

| 信息 | 没有时怎么办 |
|---|---|
| 数据：类别、数值、单位、数据来源 | **必须问**，绝对不能编；先做就用明显的占位数据（例如全部是 `0` 或 `00`）并在提案里写清楚 |
| 图表类型 | 用户没指定时：比较类别用柱状图，时间趋势用折线图，占比用饼图或环形图（类别不超过 5 个） |
| 坐标轴范围 | 柱状图的数值轴**从 0 开始**；最大值取数据最大值向上取整到"好看"的数（例如 87 → 100） |
| 数字格式 | 按语言习惯：千分位、小数位数、单位位置（`1,234 万`、`12.5%`） |

## 2. 结构（柱状图）

```
chart_bars  1920×1080, 30 fps, 210 帧（7 秒）
├─ title            文本图层：图表标题
├─ source_note      文本图层：数据来源（小字，左下）
├─ ctrl_chart       空对象：整个图表的位置
├─ value_01..N      文本图层：每根柱子上方的数值，父级 ctrl_chart
├─ label_01..N      文本图层：类别名，父级 ctrl_chart
├─ bar_01..N        形状图层：柱子，锚点在底边中点，父级 ctrl_chart
├─ axis_base        形状图层：基线
└─ bg_solid
```

柱子高度 = 数值 ÷ 坐标轴最大值 × 图表区高度（像素）。在提案说明里列出每根柱子的计算结果，方便核对。

## 3. 时间表（30 fps，6 根柱子）

| 元素 | 内容 | 帧 | 缓动 |
|---|---|---|---|
| `title` | 上移 20 px + 淡入 | 0–16 | 入场·强 |
| `axis_base` | 缩放 X 0 → 100%（锚点在左） | 8–24 | 入场·强 |
| `label_01..06` | 淡入，间隔 2 帧 | 16–30 | 线性 |
| `bar_01..06` | 缩放 Y 0 → 100%（锚点在底），间隔 4 帧 | `bar_01`：24–48；`bar_06`：44–68 | 入场·强 |
| `value_01..06` | 数字从 0 滚动到目标值，和对应柱子**同步** | 同各自柱子 | 同柱子 |
| `source_note` | 淡入 | 60–72 | 线性 |
| 停留 | | 68–209 | 约 4.7 秒 |

停留时间按数据点数估算：每个数据点 0.5 秒 + 2 秒，6 个点约 5 秒。

## 4. 数字滚动的做法

让数字和柱子用同一条缓动，并且能在时间轴上调：

1. 给 `value_01` 加一个"滑块控制"效果，命名 `value`，按柱子的帧和缓动做关键帧：0 → 目标数值。
2. 源文本用表达式读取滑块并格式化，例如：

```javascript
// Format the slider value with thousands separators; keep in sync with bar_01.
// Parameter index 1 avoids depending on the localized parameter name.
var v = effect("value")(1).value;
Math.round(v).toLocaleString("en-US");
```

3. 在 `value_01` 上留批注："数值由效果 value 驱动，改数据时改滑块关键帧的终值"。

参数用序号 `(1)` 而不是名字，避免中英文界面下参数名不同（BAE 的效果参数序号规则待确认）；交接给 AE 用户时，确认表达式在 AE 里同样可用（`toLocaleString` 的格式在不同表达式引擎里可能不同，必要时手写千分位）。

## 5. 步骤

1. 事务"柱状图：建立版式"：合成、坐标轴、标签、柱子（先设成最终高度）、数值文本、标题、来源。
2. 自检：`render_frame` 第 150 帧，`scale: 0.5`。**先确认最终画面是正确的图表**：高度比例、标签对应、数值正确、没有重叠。
3. 事务"柱状图：生长动画"：柱子缩放 Y 关键帧（0 → 100%）、错帧。
4. 事务"柱状图：数字滚动"：滑块关键帧和源文本表达式。
5. 事务"柱状图：标题、标签与标记"。
6. 自检：联系表 20–72 帧 `step: 2`；`prim_get` 核对每根柱子最后的缩放关键帧 Y = 100%、每个数值的滑块终值等于数据。

## 6. 规则

- **不加过冲。** 柱子冲过头的那几帧在表达一个错误的数值。数据图表用入场·强（干脆地减速停下）。
- **数值轴从 0 开始。** 截断的坐标轴会夸大差异。用户坚持要截断时，在图上标明，并在提案里说明。
- **数字和柱子同步。** 数字到达目标值的那一帧，柱子也正好到达。
- **顺序有意义。** 按数据顺序（时间、排名）错帧；需要强调某一项时，其他柱子先出、强调项最后出并用强调色。
- **停留时间足够。** 观众需要时间读数和比较。
- 颜色：一个系列一种颜色；强调色只给需要强调的一项。

## 7. 变体

- **折线图：** 线条是一条路径，加修剪路径从 0% 到 100%（线性或柔和，30–60 帧），数据点在线条经过时依次弹出（缩放 0 → 100%，入场·轻，不过冲）。
- **饼图 / 环形图：** 每一块是一段圆弧描边（环形）或扇形路径；用修剪路径按占比依次画出，起点在 12 点方向、顺时针；各块比例必须加起来等于 100%。
- **单个大数字：** 数字滚动 30–45 帧，入场·强；单位和说明文字晚 6–8 帧出现。

## 8. 常见坑

- 编造数据或"看起来差不多"的数据。
- 柱子锚点在中心，生长方向是上下同时伸展。
- 数字滚动用线性，柱子用缓动，两者不同步。
- 数字滚动到最后几帧还在跳动的个位数，停下后才是正确值——停留段必须是准确数值。
- 标签和柱子错位（排序变了但标签没跟着变）。

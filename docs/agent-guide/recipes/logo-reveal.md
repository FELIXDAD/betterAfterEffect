# 配方：Logo 演绎

Logo 从无到有地构建出来，在一个"成形点"完成，然后标语出现，最后静止停留。品牌规则见 [03 动画规范](../03-animation.md) 第 5 节，它们是硬性要求。

## 1. 输入

| 信息 | 没有时怎么办 |
|---|---|
| Logo 矢量资产 | **必须有**。在 `design/assets` 或素材里找（`prim_find`）；找不到就问，不要自己画 |
| Logo 是否拆分成部件（图形、文字标、各组件） | 看资产结构（`prim_get`）；没拆分就只能用整体手法（描边描绘、蒙版揭示） |
| 标语文案 | 问用户；没有就不做标语 |
| 品牌规范（留白、最小尺寸、禁用做法） | 问用户有没有；没有就按通用规则：不变形、不改色、四周留白至少为 Logo 高度的 25% |
| 音乐的重拍时间 | 有就把成形点对到重拍（见 [03 动画规范](../03-animation.md) 第 8 节） |

## 2. 结构

```
SH090_logo  1920×1080, 30 fps, 150 帧（5 秒）
├─ tagline        文本图层：标语，Logo 下方
├─ logo_final     引用设计资产的 Logo（预合成或引用），最终停留的就是它
├─ pc_logo_build  预合成：构建过程用的描边版本或部件
└─ bg_solid
```

**最终停留的 `logo_final` 必须是对设计资产的引用，不修改它的任何内容。** 构建过程需要的描边、拆分部件，可以在 `pc_logo_build` 里复制路径来做（它们只在构建过程中出现，成形后隐去）。

## 3. 时间表（30 fps，手法：描边描绘再填充）

| 段落 | 帧 | 内容 | 缓动 |
|---|---|---|---|
| 留白 | 0–7 | 空画面 | — |
| 引入 | 8–40 | `pc_logo_build` 里各路径的修剪路径"结束"从 0% 到 100%，部件之间错开 3 帧 | 柔和 |
| 成形 | 36–46 | `logo_final` 不透明度 0 → 100（填充显现） | 线性 |
| 成形 | 40–48 | `pc_logo_build` 不透明度 100 → 0（描边隐去） | 线性 |
| 成形点 | 46 | Logo 完整出现。有音乐时对齐重拍 | — |
| 回稳 | 46–64 | `logo_final` 缩放 97% → 100%（很轻的"落定"） | 入场·强 |
| 标语 | 58–76 | `tagline` 上移 20 px + 不透明度 | 入场·强 |
| 停留 | 76–149 | 静止 | — |

停留 74 帧（约 2.5 秒）。

## 4. 步骤

1. `prim_find` 找 Logo 资产，`prim_get` 看它的结构和来源工程层。
2. 事务"Logo 演绎：建立合成和版式"：新建合成；`prim_set_references` 或 `layer_create(kind: "precomp")` 引用 Logo 资产为 `logo_final`；建 `tagline`。
3. 自检：`render_frame` 第 120 帧，`scale: 0.5`。确认 Logo 尺寸、位置、留白、标语位置。这一帧就是最终画面，要先定下来。
4. 事务"Logo 演绎：构建预合成"：建 `pc_logo_build`，放入 Logo 路径的描边版本（无填充，描边颜色用品牌色），加修剪路径。
5. 事务"Logo 演绎：构建与成形动画"：按时间表设关键帧。
6. 事务"Logo 演绎：标语与标记"：标语动画；标记 `build`（8）、`resolve`（46）、`hold`（76）。
7. 自检：联系表 0–80 帧 `step: 3`；`render_frame` 第 46、149 帧，`scale: 1`。

## 5. 自检要点

- 最后一帧：`prim_get` 核对 `logo_final` 最后的关键帧（或静态值）是缩放 [100, 100, 100]、旋转 0、不透明度 100、位置 = 版式位置；`pc_logo_build` 最后的不透明度是 0。
- `sublayer_diff` 里没有对 `design/assets` 来源节点的任何覆盖（硬性项 H8）。
- 成形点之前的描边版本和成形后的填充版本完全重合，没有错位（渲染第 44 帧检查）。
- 标语离 Logo 的距离符合留白要求。

## 6. 变体

- **部件组装（Logo 已拆分）：** 各部件从画外或缩放 0 错帧进入（间隔 2–3 帧），入场·强，带 3–5% 的轻微过冲；全部在第 44–46 帧之间落位，形成一个成形点。部件用 `logo_final` 内部对应部件的引用来做动画会改到资产，所以同样在 `pc_logo_build` 里做，成形后切换到 `logo_final`（同一帧切换，位置必须完全重合）。
- **蒙版揭示：** `logo_final` 上加一个蒙版，蒙版路径从一条线扩展到完整区域（柔和，20–30 帧）。不改资产本身，只在图层上加蒙版。
- **光效扫过：** 成形后（第 60–75 帧）一道斜向高光从左到右扫过，用 Logo 作为轨道遮罩限制在 Logo 范围内；只扫一次。
- **短版（3 秒，90 帧）：** 引入压缩到 6–28 帧，成形点第 30 帧，标语 38–52 帧，停留到 89 帧。

## 7. 常见坑

- 在 `logo_final` 上直接改填充颜色、加描边——这是在改设计资产。
- 最后一帧 Logo 还在缓慢缩放或漂移，不是干净的静止画面。
- 多个"高潮"：部件落位、闪光、标语、粒子各来一次，没有一个明确的成形点。
- 用不等比缩放做"弹性"效果，导致 Logo 变形。
- 描边版本的线宽和填充版本的轮廓对不上，成形瞬间看到跳变。

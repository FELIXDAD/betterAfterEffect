# BAE 0.1.0 发布候选冒烟清单

Windows x64 和 Apple Silicon macOS 各走一遍，每台约 14 分钟。两位测试员使用同一次 `CI full` 运行中的安装包。候选取太平洋时间 15:00 冻结后，第一个双平台完整 CI 全绿的 `dev` 提交。负责人提供运行链接，测试员按链接取包。

**开始前**　下载并解压对应的 Actions 构件。准备一张内容清晰的彩色 PNG、一段从开头就有声音且至少 2 秒的 WAV，以及一个空的输出目录。先用系统播放器听一次 WAV，确认耳机或扬声器能出声。以下步骤共用一个工程。

| 完成 | 时间 | 操作 | 通过条件 |
| --- | ---: | --- | --- |
| ☐ 启动 | 1 分 | Windows 完整解压候选 ZIP，启动其中的 `bae.exe`。Mac 打开候选 DMG，把 `BAE.app` 拖到“应用程序”，推出映像，从“应用程序”启动。打开“关于 BAE”。 | 主窗口可操作，版本为 **0.1.0**。 |
| ☐ 新建、导入 | 2 分 | 新建工程，建一个名为“冒烟”的合成，设为 640 × 360、24 帧/秒、2 秒，从第 0 帧开始。导入 PNG 和 WAV，把两项从项目面板拖到合成时间轴的起点。 | 项目面板里有两项素材。时间轴有图像层和音频层，合成查看器能看到图片。 |
| ☐ 时间轴、快捷键 | 1 分 | 选图片层，按 P 展开位置。在第 0 帧点秒表，第 12 帧把 X 增加 80 像素。按 Ctrl+Z（Mac 用 Cmd+Z）撤销第二次编辑，再把 X 改回移动后的值。 | 撤销后图片回到原位。重新移动后有两个关键帧，拖动播放头可看到图片在两点之间移动。 |
| ☐ 效果、文字、3D | 2 分 | 给图片层添加“反转”，开关一次效果，最后保持开启。在图片上方建文字层，输入“BAE 01”。用文字工具选中“01”，在“字符”面板放大字号。打开文字层的 3D 开关，将 Y 旋转从 0° 改为 30°。 | 开关效果时图片颜色变化；只有“01”变大。文字层出现三维旋转属性，倾斜后的文字仍可读。 |
| ☐ 预览、音频 | 1 分 | 从合成起点开始预览，在“预览”面板开启音频，观察“音频”面板并听完整段。停播后关闭 WAV 层的音频开关再播一次，最后重新打开该开关。 | 图片移动，文字可见。首次能听到 WAV，电平表随声音跳动；静音后同一段无声。 |
| ☐ 首选项 | 1 分 | 打开首选项，确认音频页显示当前使用的输出设备。记下网格间隔，改为另一数值后点“取消”，再打开同一页。 | 音频设备与试听一致，网格间隔恢复原值。 |
| ☐ 保存、重开 | 2 分 | 将工程另存为 `冒烟.baez`，按 Ctrl+S（Mac 用 Cmd+S）。关闭工程，从“文件”菜单重新打开刚保存的文件，再打开“冒烟”合成。 | 两项素材均在线。两枚位置关键帧、反转效果、局部字号和 3D 旋转仍在，拖动播放头仍有运动。 |
| ☐ 渲染、回放 | 4 分 | 将重开的合成添加到渲染队列，按下表为每种格式各加一项，帧范围都设为 **0–47（含首尾）**，写到各自路径。电影保留音频输出。点击“渲染”，完成后从磁盘直接打开文件。 | 队列所报结果与磁盘内容一致，按下表逐项判断。 |

| 输出 | Windows x64 | macOS arm64 | 打开文件后核对 |
| --- | --- | --- | --- |
| H.264 MP4 | 导出 `冒烟.mp4` | 同左 | 用系统播放器从头播到尾，约 2 秒。能看到图片移动和倾斜文字，能听到原 WAV。 |
| QuickTime MOV | 展开“格式”，确认 QuickTime 的 ProRes 422 HQ 项置灰，记“平台不适用”。 | 选 QuickTime（Apple ProRes 422 HQ），导出 `冒烟.mov`。 | Mac 用 QuickTime Player 播放，核对时长、画面变化和声音。Windows 若能选中该预设，记录实际行为。 |
| PNG 序列 | 在空子目录导出 `冒烟_[####].png` | 同左 | 恰好 48 张，编号 0000–0047 连续。打开首尾各一张，文字均可见，图片位置不同。 |

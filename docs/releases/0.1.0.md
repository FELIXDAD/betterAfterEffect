# BAE 0.1.0 发布说明

从 0.0.1 升级后，可以在合成里给图层叠加效果，边听声音边调整关键帧，在图层上画笔画，再把画面和声音一起导出。

## 合成、预览与时间轴

- 播放时，时间轴的绿条标出已缓存的帧。可以在首选项调整显存缓存，在预览面板设置播放范围、帧速率、跳帧和分辨率。拖动属性数值时，查看器会跟随当前值刷新，包括使用图像颜色采样的表达式。
- Apple Silicon 上加快了多图层 4K 合成的预览。在 M4 Mac mini 上，4K、1,000 个旋转矩形的测试场景从约 20 帧/秒提高到 30 帧/秒。
- 合成查看器可切换颜色通道、调整曝光、限定预览区域和保存快照。打开标尺、参考线和网格后，可以直接在画面上拖动运动路径的关键帧和手柄。
- 可以按名称搜索图层和属性，一次修改多个图层的同名属性，反向粘贴关键帧，也可以在合成或图层上添加标记。预合成支持双击进入，用 Tab 查看合成之间的关系。
- 混合模式、轨道遮罩、调整图层和运动模糊可用于合成。图层时间支持伸缩、重映射和冻结帧，变速素材可选择帧混合或像素运动补帧。
- 拖动图层时可以吸附到其他图层边缘的延长线，也可以吸附到已折叠预合成里的图层。右键单击运动路径上的关键帧可直接编辑它。在时间轴选中属性后，按 Shift+J 或 Shift+K 跳到它的上一个或下一个关键帧。
- 用父级拾取鞭连接图层时，按住 Shift 可把子图层移到父级位置。表达式拾取鞭可以直接拖到效果或蒙版上。图层标记可以标为分段标记。
- 项目、时间轴和渲染队列面板都可以调整显示列。时间轴还可切换波形、缓存指示和双时间显示。修改工程时，只有受影响的合成需要重新准备预览计算。
- 在“动画”菜单可以把位置拆成独立的轴。在“视图”菜单可以显示或隐藏全部图层控件，也可以打开摄像机设置。

## 效果与粒子

- 从“效果”菜单或“效果和预设”面板给图层添加效果，在“效果控件”中调整参数。在合成查看器中可以直接拖动效果的控制点，也可以保存、套用动画预设。
- 调色可用 Lumetri 颜色、曲线、色阶、曝光和 LUT。Lumetri 范围面板提供波形图、矢量示波器、直方图和分量图。其他常用效果包括镜头模糊、液化、抠像、杂色与颗粒、描边、时间扭曲和图层转场。风格化效果还可制作蜂巢平铺、塑料浮雕和烧片。
- CC Particle World 和 CC Particle Systems II 支持给出生率和发射器位置打关键帧。还可直接生成雨、雪、气泡、碎片和卡片动画。
- Lumetri 支持从画面取白平衡，在 HSL 次要校正中吸取、添加或移除颜色，用五条色相与饱和度曲线组合调色。可调 HDR 白点，在范围面板切换 8 Bit、float 和 HDR 刻度。关闭“固定信号”可查看超过白位的值。自己的 `.cube` LUT 可以随工程保存。
- 处理多通道 EXR 时，可以用 EXtractoR 分配 RGBA 通道，用 ID 遮罩提取物体或材质。Cryptomatte 支持在查看器里拾取一个物体，换帧后遮罩继续跟随它。IDentifier 可以查看单独通道的原始值或遮罩。
- “音频波形”和“音频频谱”能把指定音频图层画成随声音变化的图形。“基本文字”和“路径文本”可在效果控件中排字，“基本 3D”可让平面图层翻转并显示高光。

## 绘画、形状与文字

- 双击图层打开图层面板，用画笔、仿制图章或橡皮擦直接绘画。每笔可以单独撤销。在“绘画”和“画笔”面板调整颜色、直径、硬度和持续时间。使用仿制图章时，按住 Alt（Mac 上为 Option）单击取样。
- 形状图层可以添加修剪路径、中继器等操作。蒙版支持沿轮廓调整局部羽化宽度。文字可以沿蒙版路径排列，也可以用文字动画器按字符或选定范围制作动画。
- 仿制图章可以复制同一图层上的像素。橡皮擦可只擦绘画、只擦最后一笔，或连同图层源一起擦除。展开时间轴的“绘画”效果，可以逐笔调整路径、直径、不透明度和变换，并为它们设置关键帧。
- 双击矩形、椭圆或星形可选中形状组，直接拖动、缩放或旋转。图层可以叠加投影、外发光、渐变叠加、描边等九种图层样式，样式参数也能设置关键帧。
- 用文字工具拖选几个字，就能在“字符”或“段落”面板调字体、字号、填充、描边、对齐和段落间距。可在同一文字层里为不同字符设置不同样式。

## 3D、跟踪与表达式

- 可在一个或多个视图里摆放 3D 图层，切换摄像机或正交视图，用轴向手柄移动、缩放或旋转。灯光可以照亮图层，图层可投射和接收阴影。
- 在图层上设置跟踪点、搜索区域和附加点，逐帧分析后，可把结果应用到运动、稳定或边角定位。运动草图、摇摆器和平滑器也可用于制作和整理关键帧。
- 可以在时间轴上用关联器和多行编辑框编写表达式，定位报错，或将表达式转换为关键帧。表达式可读取文字、形状路径、标记、摄像机和灯光属性，也可采样图像颜色。
- 灯光和图层静止时，移动摄像机可以复用已有阴影。在 Apple Silicon 的 50 个平面、3 盏投影灯测试场景中，摄像机绕行的 1080p 渲染从约 22 帧/秒提高到 114 帧/秒。
- VR 合成编辑器可新建全景合成、添加 2D 或 3D 编辑、设置输出投影，并提取和切换立方图的六个面。
- 多行表达式可显示行号和缩进线，支持自动补全括号、按词换行，以及用 Tab 或 Shift+Tab 整块调整缩进。

## 音频、素材与输出

- 导入音频后，在时间轴上连续按两次 L 可展开波形。预览时可听到合成混音，拖动播放头可试听当前位置。音频面板显示左右声道电平，也可将音频振幅转换为关键帧。
- 混音可使用均衡、压缩、门限、延迟和混响等效果。可单独导出 WAV，也可将混音作为 AAC 音轨随视频导出。
- 在音频首选项中可选择预览输出设备、调整缓冲时长，或对调左右输出。面板显示当前设备的名称、采样率和声道数。
- 分层 Photoshop 文件（PSD、PSB）可导入为合并画面、单层素材或分层合成。选择“保持图层大小”可保留各层边界。简单点文字可继续编辑，图层样式也可以导入为可编辑样式。重新载入时会按源文件中的图层匹配。
- “解释素材”可设置 Alpha、帧速率、像素长宽比和循环次数。导入图像序列时，可查看缺少的帧号，也可让 BAE 在后台检查哪些帧读不出来。
- 选中项目面板里的素材后，可用 Ctrl+/（Mac 用 Cmd+/）将它们加入当前合成。“编辑原稿”会用系统默认应用打开源文件。
- 渲染队列随工程保存，可复用渲染设置与输出模块模板，也可单独保存当前帧。Windows 可读写 H.264、HEVC 视频，macOS 还支持导出 ProRes。项目面板支持替换、重新载入素材及定位源文件。在 macOS 上可从访达将素材拖入时间轴或查看器，并从系统最近文稿重新打开工程。
- 渲染队列可沿用上一个输出目录并给同名文件自动编号。导出长图像序列时可按指定张数分到多个文件夹，帧号保持连续。

## 工作区与扩展

- 可以保存快捷键预设，在首选项中直接切换中英文。工作区加入素材、媒体浏览器、流程图和元数据等面板，重新打开面板会回到原来的停靠位置。
- BAE 脚本可以读取工程属性并执行编辑命令。开发者可以用原生插件扩展 BAE 的效果。
- 新建工程可从自己的模板开始，打开工程时可以选择沿用当前工作区。新图层的持续时间、位置是否分开为各轴，以及新形状图层的锚点位置都可预设。
- 双击图层可按首选项打开图层、源素材或源合成，按住 Alt（Mac 用 Option）可临时反转打开方式。流程图里的图层可通过右键改名、选择子项或更换标签颜色。
- 首选项可查看本机内存和 GPU 信息，调整透明网格的颜色与大小，预览主题、参考线和标签颜色。点“取消”会恢复原来的显示。项目和时间轴的列头、图层编号和列宽控件也有中英文读屏名称。

## 系统要求与安装

| 平台 | 要求 | 安装方法 |
| --- | --- | --- |
| Windows | Windows 10 21H2 或更新版本、Windows 11，x64，支持 Direct3D 12 的显卡 | 将 `BAE-0.1.0-x86_64-windows.zip` 完整解压，双击 `bae.exe`。 |
| macOS | macOS 12 或更新版本，Apple Silicon，Metal | 打开 `BAE-0.1.0-aarch64-macos.dmg`，将其中的 `BAE.app` 拖到旁边的 Applications（应用程序）文件夹，推出磁盘映像后打开应用。 |

macOS 应用使用本地临时签名（ad hoc），未取得 Developer ID 签名和 Apple 公证。Windows ZIP 内的程序未使用发布者证书签名。从项目正式发布页下载并确认来源后，如首次启动受系统拦截，macOS 可在“隐私与安全性”里选择“仍要打开”，Windows 可在 SmartScreen 的“更多信息”里选择“仍要运行”。

## 已知问题与限制

- 0.1.0 使用内存和显存缓存预览帧。关闭应用再打开工程时需要重新生成预览，磁盘预览缓存将在后续版本提供。[磁盘预览缓存 #739](https://github.com/FELIXDAD/betterAfterEffects/pull/739)
- 高分辨率合成叠加大量带表达式的形状图层时，预览可能低于合成帧率。可降低预览分辨率，并通过时间轴绿条查看缓存情况。[性能跟踪记录](https://github.com/FELIXDAD/betterAfterEffects/issues/366)
- Windows 的 HEVC 读写取决于系统解码器和硬件编码器，可能需要安装 HEVC 视频扩展。Windows 的 H.264 和 HEVC 输出为 8 位且不带透明通道。需要在 Windows 保留透明通道时，可输出带 Alpha 的 PNG 或 OpenEXR 序列。
- 运动跟踪支持图层上的跟踪点。Roto 笔刷和 3D 摄像机跟踪器将在后续版本提供。变形稳定器尚不可用。
- 0.1.0 支持 BAE 自身的脚本。现有 After Effects 脚本的兼容支持，以及多人同时编辑同一工程的功能，安排在后续版本。

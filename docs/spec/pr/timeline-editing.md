# Pr 清单：时间轴编辑（PR-TL）

## 范围

序列时间轴面板和所有编辑操作：轨道与轨道头、显示与缩放、对齐、插入/覆盖、删除与波纹删除、间隙、轨道定位、源修补、同步锁定、锁定、四种修剪（常规、波纹、滚动、修剪到播放头）、外滑、内滑、比率拉伸、剃刀与添加编辑、移动与微移、复制粘贴、选择、链接、编组、嵌套、替换剪辑、粘贴属性、速度与时间重映射、帧定格、多机位。

**做到"和 Pr 一样好用"的共同要求：**

1. 每个手势一个撤销步骤；拖动时实时预览（显示时间偏移、两侧帧），松手才提交（edit-model.md 第 11 节"预演"）。
2. 拖动时吸附（PR-TL-007），吸附点出现时有可见的指示线。
3. 被阻挡时不悄悄失败：修剪碰到相邻剪辑或媒体尽头会停住，并在光标旁给出原因（"媒体不足"）。
4. 所有操作都有键盘方式，Pr 用户大量依赖快捷键剪辑。
5. 命令参数显式给出目标轨道、源修补、播放头（edit-model.md 第 1 节原则 2），界面负责从当前状态填参数。

## 轨道与时间轴显示

### PR-TL-001 · 时间轴面板与轨道（Timeline Panel / Tracks）

- **行为要点：** 视频轨在上（V1 在最下面、靠近中线，编号往上增大），音频轨在下（A1 在最上面、靠近中线，编号往下增大），最下面是主声道（混合）轨。上层视频轨盖住下层。时间标尺在顶部，带入出点、标记、渲染条。轨道高度可拖动，Cmd+= / Cmd+- 加高/减矮所有视频轨，Opt+= / Opt+- 调整所有音频轨，Shift+= / Shift+- 展开/最小化所有轨道；双击轨道头空白处展开该轨。PageUp / PageDown 向前/向后翻一屏。
- **优先级：** M1 — 骨架时间轴要显示多条视频轨、音频轨和片段。
- **BAE 模块：** bae-ui-edit (+ bae-edit)
- **数据模型：** 轨道顺序来自子节点位置（#66，edit-model.md 第 2 节）；高度、展开是视图状态。
- **备注：** 与 AE 时间轴相反，Pr 的视频轨"向上长"。剪辑工作区必须照 Pr 画，动效工作区照 AE 画，两个面板分开实现、共用通用控件。

### PR-TL-002 · 添加和删除轨道（Add / Delete Tracks）

- **行为要点：** 右键轨道头"添加单个轨道""添加音频子混合轨道""添加轨道…"（对话框里可以一次加多条视频、音频、子混合轨，指定位置和音频轨类型）、"删除单个轨道""删除轨道…"（可选删除所有空轨道）。把剪辑拖到最上面视频轨之上（或最下面音频轨之下）的空白处会自动新建轨道。
- **优先级：** M1 — #66 的 `track.add` / `track.remove` 已有。
- **BAE 模块：** bae-edit (+ bae-ui-edit)
- **数据模型：** Track 的 `track_kind` 增加 `submix`、`master`、`caption`；`audio:channel_format`（edit-model.md 第 4 节）。
- **备注：** "拖到空白处自动新建轨道"由放置命令的参数 `create_track_if_needed` 实现，保持一个撤销步骤。

### PR-TL-003 · 轨道头开关（Track Header Controls）

- **行为要点：** 视频轨：切换同步锁定、切换轨道锁定、切换轨道输出（眼睛）；音频轨：同步锁定、锁定、静音（M）、独奏（S）、画外音录制（麦克风）。Opt/Cmd 点击某个开关会作用到同类所有轨道（待核哪个修饰键）。轨道名可以双击改名。锁定的轨道显示斜纹，不能编辑但正常播放；关闭输出的视频轨不渲染、不导出。
- **优先级：** M1 — #66 的 `track.set_state` 已有锁定、输出、静音、独奏、改名；同步锁定待加。
- **BAE 模块：** bae-ui-edit (+ bae-edit)
- **数据模型：** Track 的 `enabled`、`locked`、`muted`、`solo`、`sync_lock`、`name`。
- **备注：** 画外音录制以后再做（需要 08 的音频输入）。

### PR-TL-004 · 时间轴显示设置（Timeline Display Settings）

- **行为要点：** 时间轴左上角扳手菜单：显示视频缩略图（仅头部 / 头尾 / 连续）、显示视频关键帧、显示视频名称、显示音频波形、显示音频关键帧、显示音频名称、显示剪辑标记、显示重复帧标记（同一来源的同一帧在序列里出现多次时，剪辑底部画彩条）、显示直通编辑点、显示 fx 徽章（效果是否存在、是否有关键帧、是否是主剪辑效果用颜色区分）、经修正的音频波形、显示标签颜色等；可以保存成预设。
- **优先级：** M4（M1 只要剪辑名称和波形）
- **BAE 模块：** bae-ui-edit (+ bae-media, bae-render)
- **数据模型：** 无，视图状态。
- **备注：** 连续缩略图依赖 08 的快速缩略图解码和缓存；"重复帧标记"由 `bae-edit::query` 计算（同来源源区间重叠）。

### PR-TL-005 · 时间轴缩放与导航（Zoom / Navigate）

- **行为要点：** = / - 放大/缩小（以播放头为中心），\ 缩放到整个序列（再按一次回到之前的缩放）；底部缩放滚动条两端可拖动；Opt+滚轮缩放（Mac 上也可以触控板捏合），滚轮垂直滚动，Shift+滚轮（或触控板横扫）水平滚动；播放时视图跟随播放头（偏好：页面滚动 / 平滑滚动 / 不滚动）。
- **优先级：** M1（=/-、\、滚动）；其余 M4
- **BAE 模块：** bae-ui-edit
- **数据模型：** 无
- **备注：** 大序列（上千个剪辑）缩小时要合批绘制，拖动不能卡（VISION"拖动时间轴不卡"）。

### PR-TL-006 · 选择（Selection）

- **行为要点：** 选择工具（V）点选，Shift 点击加选/减选，框选；D 选择播放头下目标轨道上的剪辑；Cmd+↑ / Cmd+↓ 选择上一个/下一个剪辑；Cmd+A 全选，Shift+Cmd+A 取消全选。向前选择轨道工具（A）选中点击位置及之后所有轨道上的剪辑，Shift+A 向后；按住 Shift 只选当前轨道。Opt 点击链接剪辑只选一边（临时忽略链接）。点击编辑点（剪辑边缘）选中编辑点而不是剪辑，Shift 可选多个编辑点。Pr 26.2 默认键位里还有"范围选择工具"（Opt+Cmd+G），行为待核。
- **优先级：** M1（点选、加选、框选、选中编辑点）；其余 M4
- **BAE 模块：** bae-ui-edit (+ bae-edit)
- **数据模型：** 无。选择是视图状态，命令参数显式给出要操作的剪辑和编辑点。
- **备注：** 协同时其他人的选择通过在线状态（09）显示，不进工程。

### PR-TL-007 · 对齐（Snap in Timeline）

- **行为要点：** S 开关（时间轴左上角磁铁按钮）。打开时拖动剪辑、编辑点、播放头、入出点会吸附到剪辑边缘、播放头、标记、入出点、关键帧（拖动关键帧时），吸附时出现黑色竖线和三角指示。拖动过程中按 S 可以临时切换。节目监视器里另有"对齐参考线"（Shift+Cmd+;）。
- **优先级：** M1 — 吸附点计算在 `bae-edit`，界面只负责指示线。
- **BAE 模块：** bae-ui-edit (+ bae-edit)
- **数据模型：** 无
- **备注：** 吸附阈值按屏幕像素算（缩放后时间距离不同），吸附结果再对齐到帧。

## 放置剪辑

### PR-TL-008 · 插入编辑（Insert）

- **行为要点：** ,（逗号）或源监视器的插入按钮。在序列入点（或播放头）处插入，插入点之后的内容往后推。被推开的轨道：源修补到的轨道（放剪辑的轨道）+ 打开了同步锁定的其他轨道；关闭同步锁定的轨道不动。插入点落在某个剪辑中间时把它切开。三点/四点规则见 PR-MON-009、PR-MON-010。
- **优先级：** M1 — #66 的 `clip.insert` 已有，同步锁定待补。
- **BAE 模块：** bae-edit (+ bae-ui-edit)
- **数据模型：** 无新增。命令参数：来源、四点、源修补（`patch`）、`sync_lock`（edit-model.md 第 11 节）。
- **备注：** #66 已知问题：只推后目标轨，未实现同步锁定。这是 Pr 用户最依赖的行为之一，M1 必须补上，否则插入会让音画错位。

### PR-TL-009 · 覆盖编辑（Overwrite）

- **行为要点：** .（句号）或覆盖按钮。在序列入点（或播放头）处覆盖源修补到的轨道上已有的内容，长度不变，后面的内容不动。被部分覆盖的剪辑被修剪，完全覆盖的被删除，跨过覆盖区间的被切成两段。
- **优先级：** M1 — #66 的 `clip.overwrite` 已有。
- **BAE 模块：** bae-edit (+ bae-ui-edit)
- **数据模型：** 无
- **备注：** 被覆盖剪辑上的过渡：覆盖区间完全盖住过渡时删除过渡，否则保留并按剩余长度裁短，待核细节。

### PR-TL-010 · 拖放到时间轴（Drag and Drop to Timeline）

- **行为要点：** 从项目面板或源监视器拖到时间轴默认是覆盖，放下的轨道和位置由鼠标决定（视频和音频分别落在对应轨道上，保持相对关系）；按住 Cmd 拖动变成插入（时间轴上显示向右的箭头）；拖到最上/最下的空白处新建轨道；拖动时吸附。多选素材一起拖入时按选择顺序首尾相接放置。
- **优先级：** M4（M1 支持基本的拖入覆盖）
- **BAE 模块：** bae-ui-edit (+ bae-edit)
- **数据模型：** 无
- **备注：** 拖放时的源修补由鼠标所在轨道临时决定，不改变轨道头上的源修补设置。

### PR-TL-011 · 清除与波纹删除（Clear / Ripple Delete）

- **行为要点：** Delete（Backspace）清除选中剪辑，留下空隙；Shift+向前删除（时间轴获得焦点时也可用 Opt+Delete）波纹删除：删除后同轨后面的内容前移，打开同步锁定的其他轨道同步前移。如果其他轨道上有东西挡住无法前移，Pr 只移到能移的位置或拒绝并提示（待核）。选中一个空隙按 Delete 也是波纹删除这个空隙。
- **优先级：** M1 — #66 的 `clip.lift` / `clip.ripple_delete` 已有。
- **BAE 模块：** bae-edit (+ bae-ui-edit)
- **数据模型：** 无
- **备注：** 波纹类命令都要支持"波纹序列标记"开关（edit-model.md 第 7 节）。

### PR-TL-012 · 间隙（Gaps: Select / Close / Find）

- **行为要点：** 点击两个剪辑之间的空隙可以选中它，Delete 波纹删除空隙；"序列 > 闭合间隙"删除序列（或入出点范围）内目标轨道上的所有空隙（待核菜单位置与版本）；Shift+; / Opt+; 跳到序列中的下一个/上一个间隙。有同步锁定的轨道挡住时空隙删不掉（右键菜单"波纹删除"变灰）。
- **优先级：** M4
- **BAE 模块：** bae-edit (+ bae-ui-edit)
- **数据模型：** 无。空隙不存数据，由 `query` 根据剪辑位置计算。
- **备注：** Agent 粗剪后经常需要"删掉所有空隙"，命令 `clip.close_gaps` 价值高。

## 轨道定位、源修补与同步锁定

### PR-TL-013 · 锁定轨道（Lock Track）

- **行为要点：** 锁定的轨道上不能选择、移动、修剪、插入、删除任何东西，插入和波纹删除也不会推动它（相当于对它关闭同步锁定，并且禁止编辑）。锁定的轨道仍然播放和导出。
- **优先级：** M1 — #66 已有 `locked`，命令拒绝编辑锁定轨道。
- **BAE 模块：** bae-edit
- **数据模型：** Track `locked`。
- **备注：** 协同时"锁定"只是本序列里的编辑保护，不是协同锁（edit-model.md 第 12 节）。

### PR-TL-014 · 轨道定位（Track Targeting）

- **行为要点：** 轨道头右侧的 V1/A1 这类按钮（蓝色高亮 = 已定位）。定位决定这些操作作用于哪些轨道：↑/↓ 跳转编辑点、匹配帧（取最上面的已定位轨道）、粘贴（Cmd+V 粘贴到最下面的已定位轨道）、添加编辑（Cmd+K）、标记剪辑（X）、提升/提取、D 选择剪辑、修剪到播放头（Q/W）。Cmd+0 / Cmd+9 切换所有视频 / 音频轨道的定位。点击切换单个，Shift 点击（待核）独占。
- **优先级：** M1 — 定位状态由界面保存，命令接收显式的目标轨道列表。
- **BAE 模块：** bae-ui-edit (+ bae-edit)
- **数据模型：** 无，视图状态（edit-model.md 第 4 节"不进工程的状态"）。
- **备注：** Pr 初学者最容易混淆"轨道定位"和"源修补"。BAE 照 Pr 的语义做，界面上两组按钮的位置和颜色也照 Pr（源修补在左、定位在右）。

### PR-TL-015 · 源修补（Source Patching）

- **行为要点：** 轨道头最左侧一列的源轨道指示（V1、A1、A2……对应源监视器当前来源的各个轨道），拖动或点击决定插入/覆盖时源的每个轨道放到序列的哪条轨道；点击可以关掉某个源轨道（不放这条）。Opt+Cmd+0 / Opt+Cmd+9 切换所有源视频 / 源音频。源有多个音频声道时会显示 A1、A2…多个源指示（取决于声道映射，PR-AUD-002）。
- **优先级：** M1 — 命令参数 `patch` 显式给出映射。
- **BAE 模块：** bae-ui-edit (+ bae-edit)
- **数据模型：** 无，视图状态。#66 的 `PlaceParams.track` / `audio_track` 是它的简化形式，建议扩展成"源轨道 → 序列轨道"的映射（edit-model.md 第 11 节）。
- **备注：** 拖放时按鼠标位置临时修补，不改轨道头的设置（PR-TL-010）。

### PR-TL-016 · 同步锁定（Sync Lock）

- **行为要点：** 每条轨道头上的同步锁定开关（新建轨道默认打开）。插入、提取、波纹删除、波纹修剪改变某条轨道上后续内容的位置时，所有打开同步锁定、没被直接编辑的轨道在同一位置插入相同长度的空白或删掉相同长度的内容，保持各轨道之间的同步。关闭同步锁定的轨道不受影响（例如背景音乐轨常常关掉同步锁定）。如果同步锁定的轨道在那个位置有剪辑跨过，插入时把它切开（待核：Pr 是切开还是只推开）。
- **优先级：** M1
- **BAE 模块：** bae-edit
- **数据模型：** Track `sync_lock`（bool，默认 true，edit-model.md 第 4 节）。
- **备注：** 同步锁定和链接是两件事：链接让一对剪辑一起被选中和修剪，同步锁定让轨道整体保持相对位置。两者都要有，缺一个 Pr 用户就会剪出不同步的片子。

### PR-TL-017 · 不同步指示与移入同步（Out of Sync Indicator / Move into Sync）

- **行为要点：** 链接的视频和音频被错开（例如单独移动了一边）时，两边剪辑的名称前面显示红色的偏移帧数（如 `+12`、`-12`）。右键这个数字：移入同步（移动这一边对齐另一边）/ 滑动入同步（外滑这一边的内容对齐）。
- **优先级：** M4
- **BAE 模块：** bae-edit (+ bae-ui-edit)
- **数据模型：** 无新增：链接组内各剪辑"源时间 − 序列时间"之差即偏移（来源相同时才有意义）。
- **备注：** 链接剪辑来源不同（例如合并剪辑、手工链接的外录音频）时不显示偏移，Pr 的行为待核。

## 修剪

### PR-TL-018 · 常规修剪（Regular Trim with Selection Tool）

- **行为要点：** 用选择工具拖动剪辑的头或尾（光标变成红色括号），只改变这个剪辑的入点或出点，旁边留下空隙或被相邻剪辑挡住；不会移动其他剪辑。拖动时节目监视器显示修剪处的帧和时间偏移；碰到媒体尽头停住。链接的视频和音频一起修剪；按住 Opt 只修剪一边（做 J/L 剪切）。Cmd 拖动编辑点临时切换成波纹修剪（Cmd 再按一次在滚动和波纹之间切换，待核）。
- **优先级：** M1 — #66 的 `clip.trim` 已有。
- **BAE 模块：** bae-edit (+ bae-ui-edit)
- **数据模型：** 无
- **备注：** J/L 剪切（音频比视频早进或晚出）是对白剪辑的基本手法，"Opt 拖动只修一边"在 M1 就要支持。

### PR-TL-019 · 波纹编辑（Ripple Edit Tool, B）

- **行为要点：** 拖动编辑点改变剪辑长度，后面的内容跟着移动，不留空隙（打开同步锁定的其他轨道同步移动）；光标是黄色带箭头的括号。拖动时节目监视器显示双画面（出点和入点两侧）。也可以选中编辑点后用 Opt+← / Opt+→（以及 Shift 加大到大修剪偏移）逐帧修剪。
- **优先级：** M1 — #66 的 `clip.ripple_trim` 已有。
- **BAE 模块：** bae-edit (+ bae-ui-edit)
- **数据模型：** 无
- **备注：** 波纹修剪被同步锁定的轨道挡住（那条轨道上无法插入空白或无法删除内容）时，Pr 拒绝修剪并在光标处提示，BAE 的命令返回明确的阻挡原因。

### PR-TL-020 · 滚动编辑（Rolling Edit Tool, N）

- **行为要点：** 拖动两个相邻剪辑之间的编辑点，一个变长、另一个变短，总长度和其他剪辑都不变；受两侧媒体余量限制。节目监视器显示两侧帧。选中编辑点后 Opt+←/→ 逐帧滚动。
- **优先级：** M1 — #66 的 `clip.roll` 已有。
- **BAE 模块：** bae-edit (+ bae-ui-edit)
- **数据模型：** 无
- **备注：** 滚动编辑点上有过渡时，过渡跟着编辑点移动。

### PR-TL-021 · 修剪到播放头（Ripple Trim / Extend to Playhead）

- **行为要点：** Q：把目标轨道上播放头所在剪辑的头部波纹修剪到播放头（删掉从剪辑开头到播放头的部分并合拢）；W：把尾部从播放头修到结尾并合拢；Opt+Q / Opt+W：同样修剪但不合拢（留下空隙）；E：把选中的编辑点延伸到播放头；Shift+Q / Shift+W：把上一个 / 下一个编辑点延伸到播放头。延伸时媒体不够会提示"媒体不足以扩展编辑点"。
- **优先级：** M4
- **BAE 模块：** bae-edit (+ bae-ui-edit)
- **数据模型：** 无
- **备注：** Q/W 是熟练 Pr 用户最常用的快捷剪法之一，实现成本低（复用波纹修剪），可以提前到骨架之后尽快做。

### PR-TL-022 · 修剪模式与键盘修剪（Trim Mode / Keyboard Trimming）

- **行为要点：** 双击编辑点（或选中后按 Shift+T，待核）进入修剪模式，节目监视器变成修剪监视器（PR-MON-019）；Ctrl+T 在常规、波纹、滚动修剪之间循环切换选中编辑点的修剪类型（编辑点颜色随之变化：红色常规、黄色波纹、两侧都高亮是滚动）。选中编辑点后：Opt+← / Opt+→ 修剪 1 帧，Opt+Shift+← / → 修剪"大修剪偏移"（偏好，默认 5 帧，待核）；在数字键盘上输入 `+10` / `-10` 回车修剪指定帧数。可以同时选中多条轨道上的编辑点，做不对称修剪（一条轨道波纹、另一条滚动）。
- **优先级：** M4
- **BAE 模块：** bae-edit (+ bae-ui-edit)
- **数据模型：** 无
- **备注：** 多编辑点修剪要求修剪命令接收"编辑点列表 + 各自的修剪类型"，一次执行、一个撤销步骤。M1 的命令参数就按列表设计，避免以后改接口。

### PR-TL-023 · 外滑（Slip Tool, Y）

- **行为要点：** 在剪辑上左右拖动，改变它用到的源区间（入点和出点同时平移），剪辑在序列中的位置和长度不变，相邻剪辑不受影响。拖动时节目监视器显示四个画面：前一剪辑的出点帧、本剪辑的新入点、新出点、后一剪辑的入点帧。键盘：选中剪辑后 Opt+Cmd+← / → 外滑 1 帧，加 Shift 外滑多帧（Windows 是 Ctrl+Alt+← / →）。受源媒体长度限制。
- **优先级：** M1 — #66 的 `clip.slip` 已有。
- **BAE 模块：** bae-edit (+ bae-ui-edit)
- **数据模型：** 无，只改 `source_in`。
- **备注：** 外滑时片段上的关键帧是否随内容移动取决于关键帧时间基准（edit-model.md 第 5.6 节）。

### PR-TL-024 · 内滑（Slide Tool, U）

- **行为要点：** 拖动剪辑在两个邻居之间移动：剪辑本身的源区间和长度不变，前一个剪辑的出点和后一个剪辑的入点相应修剪，序列总长度不变。节目监视器显示四个画面（前一剪辑的新出点、本剪辑入点和出点、后一剪辑的新入点）。键盘：Opt+, / Opt+. 内滑 1 帧，加 Shift 多帧。受邻居媒体余量限制。
- **优先级：** M1 — #66 的 `clip.slide` 已有。
- **BAE 模块：** bae-edit (+ bae-ui-edit)
- **数据模型：** 无
- **备注：** 剪辑一侧是空隙时，那一侧的空隙变长或变短（Pr 行为待核）。

### PR-TL-025 · 比率拉伸（Rate Stretch Tool, R）

- **行为要点：** 拖动剪辑的头或尾改变它的长度，同时按比例改变速度，使源区间不变（拉长变慢、缩短变快）。拉伸后剪辑名称旁显示速度百分比。与其他剪辑相邻时被挡住（不推动别人）。
- **优先级：** M4
- **BAE 模块：** bae-edit (+ bae-ui-edit)
- **数据模型：** 无新增，结果写 `speed` 和 `duration`。
- **备注：** 速度改变后音频是否保持音调按 `maintain_pitch`（PR-TL-038）。

## 切分、移动与复制

### PR-TL-026 · 剃刀与添加编辑（Razor Tool, C / Add Edit）

- **行为要点：** 剃刀工具（C）点击剪辑在该处切开（吸附到播放头）；Shift 点击切开所有轨道；Cmd+K 在播放头处切开所有已定位轨道上的剪辑（选中了剪辑时只切选中的），Shift+Cmd+K 切开所有轨道。切开后两段剪辑共享同一来源，中间形成"直通编辑点"。链接的视频和音频一起切开。
- **优先级：** M1 — #66 的 `clip.razor` 已有。
- **BAE 模块：** bae-edit (+ bae-ui-edit)
- **数据模型：** 无新增。切开后两个剪辑复制所有属性和效果；关键帧按片段时间保留在各自范围内（edit-model.md 第 5.6 节）；新剪辑和原剪辑的链接组要成对拆分。
- **备注：** 被切开剪辑上的过渡：开头的过渡留给前一段，结尾的留给后一段。

### PR-TL-027 · 直通编辑点（Through Edit）

- **行为要点：** 同一来源、源时间连续的两个相邻剪辑之间的编辑点叫直通编辑点；时间轴显示设置里打开"显示直通编辑点"时画成虚线小三角。右键"合并直通编辑"把两段合回一个剪辑（两段的效果和关键帧不同时，以前一段为准，待核）。
- **优先级：** M4
- **BAE 模块：** bae-edit (+ bae-ui-edit)
- **数据模型：** 无，由 `query` 计算。
- **备注：** Agent 剪辑后用"合并所有直通编辑"清理很常见。

### PR-TL-028 · 移动与微移（Move / Nudge）

- **行为要点：** 用选择工具拖动剪辑到别的时间或轨道（覆盖目标位置的内容）；拖动时按住 Shift 限制在同一轨道或同一时间。键盘微移：Cmd+← / Cmd+→ 移动 1 帧，Shift+Cmd+← / → 移动 5 帧（Windows 是 Alt+← / →、Alt+Shift+← / →），Opt+↑ / Opt+↓ 移到上一条 / 下一条轨道（会覆盖目标位置的内容）。
- **优先级：** M1 — #66 的 `clip.move` 已有。
- **BAE 模块：** bae-edit (+ bae-ui-edit)
- **数据模型：** 无
- **备注：** 微移的 Windows 键位和 macOS 修饰键不对应（macOS 用 Cmd，Windows 用 Alt），需要 11 的键位表支持按平台覆盖（见 11 的请求）。

### PR-TL-029 · 插入移动与交换（Rearrange / Swap）

- **行为要点：** 拖动剪辑时按住 Cmd，放下时变成插入（目标位置后面的内容往后推）；按住 Cmd+Opt 拖动是"重新排列"：从原位置提取（合拢）并插入到新位置；拖动时先按 Cmd 再加 Opt 把剪辑拖到另一个剪辑的边界上可以交换两者的位置（待核）。
- **优先级：** M4
- **BAE 模块：** bae-edit (+ bae-ui-edit)
- **数据模型：** 无
- **备注：** "重新排列"是一个命令（提取 + 插入），一个撤销步骤。

### PR-TL-030 · 复制、粘贴与粘贴插入（Copy / Paste / Paste Insert）

- **行为要点：** Cmd+C 复制选中剪辑（保持它们之间的相对时间和轨道关系）；Cmd+V 在播放头处粘贴到已定位的轨道（从最下面的已定位轨道开始），覆盖原有内容；Shift+Cmd+V 粘贴插入（推开后面的内容）；在时间轴获得焦点时 Cmd+V 是"粘贴到同一轨道"（时间轴作用域的绑定）。按住 Opt 拖动剪辑直接复制一份。可以跨序列、跨项目粘贴。
- **优先级：** M4（M1 支持同序列内复制粘贴）
- **BAE 模块：** bae-edit (+ bae-ui-edit)
- **数据模型：** 剪贴板内容是一组 `PrimTree`（data-model.md 第 2 节 flatten），粘贴时重建为新 Prim，链接组和编组 ID 重新生成。
- **备注：** 跨工作区粘贴（时间轴剪辑 → 动效合成的图层）见 PR-XCH-009。

### PR-TL-031 · 启用与禁用剪辑（Enable）

- **行为要点：** Shift+Cmd+E 切换选中剪辑的启用状态；禁用的剪辑变暗，不渲染、不发声、不导出，但仍占据时间轴位置，可以被编辑。
- **优先级：** M1（预留属性）；M4 实现
- **BAE 模块：** bae-edit (+ bae-ui-edit, bae-render)
- **数据模型：** Clip `enabled`（edit-model.md 第 5.1 节）。
- **备注：** 序列求值直接跳过禁用剪辑（edit-model.md 第 10 节）。

### PR-TL-032 · 替换剪辑（Replace With Clip）

- **行为要点：** 右键"使用剪辑替换 > 从源监视器 / 从源监视器，匹配帧 / 从素材箱"：保持剪辑在序列中的位置、长度、效果和关键帧，只换来源（"匹配帧"版本按源监视器当前帧对齐，否则按源入点）。按住 Opt 把素材从项目面板拖到时间轴剪辑上也是替换。项目面板里的"替换素材"则换所有使用该来源的剪辑（PR-PRJ-017）。
- **优先级：** M4
- **BAE 模块：** bae-edit (+ bae-ui-edit)
- **数据模型：** 无新增，改 Clip 的 `source` 和 `source_in`。
- **备注：** 来源换成动效合成即"替换为动效合成"（PR-XCH-007），是动效和剪辑衔接的核心操作。

### PR-TL-033 · 粘贴属性与删除属性（Paste Attributes / Remove Attributes）

- **行为要点：** 复制一个剪辑后，选中其他剪辑按 Opt+Cmd+V 打开"粘贴属性"对话框：勾选运动、不透明度、时间重映射、音量、声道音量、声像器、各个效果，以及"缩放属性时间"（关键帧按目标剪辑长度缩放）；粘贴到多个剪辑。右键"删除属性"对话框勾选要删除的效果和固有属性（恢复默认）。
- **优先级：** M4
- **BAE 模块：** bae-edit (+ bae-ui-edit)
- **数据模型：** 无
- **备注：** 效果是 Prim、固有效果是属性，粘贴属性命令按 edit-model.md 第 5.2、5.4 节分两类处理。

## 链接、编组与嵌套

### PR-TL-034 · 链接与链接选择项（Link / Unlink / Linked Selection）

- **行为要点：** 来自同一素材的视频和音频放进序列时自动链接：一起选中、移动、修剪、切开、删除；名称后面带 `[V]` / `[A]`，取消链接后名称加下划线（待核）。Cmd+L 链接 / 取消链接选中的剪辑（可以把视频和外录的音频手工链接）。时间轴左上角"链接选择项"开关全局关闭链接行为；Opt 点击临时只选一边。一个链接组可以有一个视频剪辑和多个音频剪辑（待核上限）。
- **优先级：** M1 — #66 的 `clip.link` / `clip.unlink` 和 `link` 属性已有。
- **BAE 模块：** bae-edit (+ bae-ui-edit)
- **数据模型：** Clip `link`（string 链接组 ID，#66）。
- **备注：** "链接选择项"开关是用户偏好，不进工程；关闭时所有命令把每个剪辑当成独立的（命令参数 `linked_selection: bool`）。

### PR-TL-035 · 编组（Group / Ungroup）

- **行为要点：** Cmd+G 把选中剪辑编成一组，Shift+Cmd+G 取消编组。编组的剪辑一起选中、移动、删除，可以对整组外侧边缘修剪；Opt 点击选中组里的单个剪辑。编组和链接互相独立（一个剪辑可以既在链接组里又在编组里）。
- **优先级：** M4（M1 预留属性）
- **BAE 模块：** bae-edit (+ bae-ui-edit)
- **数据模型：** Clip `group`（string 编组 ID，edit-model.md 第 5.1 节）。
- **备注：** 编组不影响渲染，和"嵌套"不同。

### PR-TL-036 · 嵌套（Nest）

- **行为要点：** 选中若干剪辑，右键"嵌套…"并命名：这些剪辑（保持轨道关系）被移进一条新序列，原位置换成一个引用该序列的剪辑。嵌套序列剪辑在时间轴上是绿色（默认标签色）。双击嵌套剪辑打开那条序列；Opt+Cmd+F（待核命令名"在序列中显示嵌套序列"）。嵌套序列内容改了，所有引用它的剪辑跟着变；但嵌套序列变长后，父序列里剪辑的长度不会自动变长，需要手动修剪出来。对嵌套剪辑加效果相当于对整组加效果。
- **优先级：** M1 — #66 的 `clip.nest` 已有。
- **BAE 模块：** bae-edit (+ bae-ui-edit, bae-render)
- **数据模型：** 片段 `source` 指向 Sequence；不能循环嵌套（edit-model.md 第 5.5 节）。
- **备注：** 渲染时嵌套序列作为图层源递归求值，需要 04 支持"序列作为图层源"（见 04 的请求）。

### PR-TL-037 · 子序列（Make Subsequence）

- **行为要点：** Shift+U：把选中剪辑（或入出点范围）复制成一条新的序列放进项目面板，原序列不变。常用于把一个段落单独拿出来交给别人或另做版本。
- **优先级：** M4
- **BAE 模块：** bae-edit
- **数据模型：** 无新增。
- **备注：** 与嵌套的区别：嵌套会替换原位置的剪辑，子序列不会。

## 速度与时间

### PR-TL-038 · 速度/持续时间（Speed/Duration）

- **行为要点：** Cmd+R 打开对话框：速度（%）和持续时间（链接按钮锁定两者关系，解开后可单独改）、倒放速度、保持音频音调、波纹编辑（移动尾部剪辑）、时间插值（帧采样 / 帧混合 / 光流法）。可以一次改多个剪辑。剪辑名称后显示速度百分比；倒放显示负号。
- **优先级：** M4（M1 预留 `reverse`）
- **BAE 模块：** bae-edit (+ bae-ui-edit, bae-media, bae-render)
- **数据模型：** Clip 的 `speed`、`reverse`、`maintain_pitch`、`frame_interp`（edit-model.md 第 5.1、5.3 节）。
- **备注：** 光流法补帧需要 GPU 光流（以后，可以先降级成帧混合）；保持音调需要 08 的时间伸缩。

### PR-TL-039 · 时间重映射（Time Remapping）

- **行为要点：** 剪辑的 fx 徽章右键"时间重映射 > 速度"后，剪辑上显示速度橡皮筋；Cmd 点击（或钢笔工具）添加速度关键帧，上下拖动橡皮筋改变一段的速度；把速度关键帧拉开成两半形成平滑的速度坡度，坡度可以用贝塞尔手柄调；Opt 拖动关键帧可以做倒放段，Cmd+Opt 拖动做定格段（待核）。剪辑长度随速度变化。效果控件面板里有对应的"时间重映射 > 速度"属性。
- **优先级：** 以后（M1 预留属性名）
- **BAE 模块：** bae-edit (+ bae-anim, bae-ui-edit)
- **数据模型：** Clip 的 `time:remap_enabled`、`time:remap`（片段时间 → 源时间，与 AE 的时间重映射同一种表达），界面把它显示成 Pr 式的速度曲线（edit-model.md 第 5.3 节）。
- **备注：** 存成"源时间曲线"而不是"速度曲线"，求值简单、和 AE 互通；Pr 式的速度坡度编辑由 `bae-ui-edit` 换算。导入 Pr XML 时需要从速度关键帧积分出源时间。

### PR-TL-040 · 帧定格（Frame Hold）

- **行为要点：** 右键"添加帧定格"：在播放头处切开，后半段变成定格在该帧的剪辑；"插入帧定格分段"：在播放头处插入一段定格（默认 2 秒，待核），后面的内容往后推；"帧定格选项"：定格在源时间码 / 序列时间 / 入点 / 出点 / 标记 0，可选"定格滤镜"（效果也停在那一帧）。
- **优先级：** M4
- **BAE 模块：** bae-edit (+ bae-anim)
- **数据模型：** Clip 的 `frame_hold`、`frame_hold:time`（edit-model.md 第 5.3 节）。
- **备注：** "添加帧定格"的结果也可以表达为 `speed` 趋近 0 的剪辑，但单独的属性更直观、导出 XML 更准确。

## 多机位

### PR-TL-041 · 创建多机位源序列（Create Multi-Camera Source Sequence）

- **行为要点：** 选中多个机位的剪辑，右键"创建多机位源序列"：同步方式（入点、出点、时间码、剪辑标记、音频波形）、序列预设（自动或指定）、音频设置（摄像机 1、所有摄像机、切换音频）、机位名称（按剪辑名、轨道名等），可选把源剪辑移进"已处理的剪辑"素材箱。生成的多机位源序列每个机位一条视频轨。
- **优先级：** 以后（M1 预留 `multicam` 名字）
- **BAE 模块：** bae-edit (+ bae-media)
- **数据模型：** Sequence `multicam`（edit-model.md 第 8 节）。
- **备注：** 按音频同步需要 08 提供音频互相关分析。

### PR-TL-042 · 多机位剪辑（Multi-Camera Editing）

- **行为要点：** 把多机位源序列放进序列（成为多机位剪辑），节目监视器切换到多机位视图（Shift+0，左边所有机位网格，右边节目输出）；播放时按 1–9 实时切换机位（自动在切换处添加编辑），0 是"多机位录制"开关；停下后 Ctrl+1–9 把播放头下的剪辑换成另一个机位。剪辑上的效果作用于当前机位；"多机位 > 启用"可以关掉多机位（只显示当前机位）。
- **优先级：** 以后
- **BAE 模块：** bae-edit (+ bae-ui-edit, bae-render)
- **数据模型：** Clip `multicam:angle`、`multicam:audio_angle`（edit-model.md 第 8 节）。
- **备注：** 多机位视图要同时解码多路素材，强烈依赖代理。

### PR-TL-043 · 拼合多机位（Flatten Multi-Camera）

- **行为要点：** 右键"多机位 > 拼合"：把多机位剪辑替换成当前机位对应的原始剪辑（保留编辑点和效果），之后不能再切机位。
- **优先级：** 以后
- **BAE 模块：** bae-edit
- **数据模型：** 无新增。
- **备注：** 导出 XML/EDL/AAF 前通常要拼合（交换格式不一定支持多机位）。

### PR-TL-044 · 场景编辑检测（Scene Edit Detection）

- **行为要点：** 对一个整段的剪辑（例如导出的成片）右键"场景编辑检测"：分析画面里的剪切点，选择"在每个检测到的剪切点应用剪切"、"从每个检测到的剪切点创建子剪辑素材箱"或"在每个检测到的剪切点生成剪辑标记"。
- **优先级：** 以后
- **BAE 模块：** bae-edit (+ bae-media)
- **数据模型：** 无新增：结果是添加编辑、子剪辑或剪辑标记。
- **备注：** 适合做成 Agent 工具或插件；镜头检测算法在 08（解码）侧做 GPU 帧差即可。

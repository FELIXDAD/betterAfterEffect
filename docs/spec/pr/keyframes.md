# Pr 清单：关键帧（PR-KF）

## 范围

剪辑上属性的关键帧：在效果控件和时间轴里添加、编辑、插值、图表，音频关键帧，以及关键帧随修剪、速度变化的行为。关键帧的数据格式和插值数学与 AE 相同（data-model.md 第 3 节、`docs/spec/ae/transform-keyframes-expressions.md`），这里只写 Pr 的交互和语义差异。

**基本约定：** 剪辑上的关键帧存在剪辑属性的 `AttrSpec.keyframes` 里，时间基准是"片段时间"（edit-model.md 第 5.6 节），由 03 `bae-anim` 求值。Pr 没有表达式，剪辑属性不需要表达式界面，但数据层不禁止（Agent 和脚本仍可写）。

### PR-KF-001 · 切换动画与添加关键帧（Toggle Animation / Add Keyframe）

- **行为要点：** 效果控件里点属性左边的秒表打开动画，在播放头处建第一个关键帧；之后在别的时间改数值自动加关键帧。属性右边的"添加/移除关键帧"菱形按钮在播放头处加或删；左右小箭头跳到上一个/下一个关键帧（跳转时播放头移过去）。再次点秒表关闭动画会弹框确认删除该属性的所有关键帧，并保留当前时间的值。
- **优先级：** M4
- **BAE 模块：** bae-ui-edit (+ bae-edit, bae-ui)
- **数据模型：** 无新增，使用 `key.set` / `key.remove`（data-model.md 第 6 节）。
- **备注：** 秒表和关键帧导航控件 11 已提供，与动效工作区一致。

### PR-KF-002 · 效果控件里的关键帧时间轴（Effect Controls Timeline）

- **行为要点：** 效果控件面板右半部分是只覆盖当前剪辑的小时间轴，显示每个属性的关键帧（菱形、沙漏等形状表示插值）；"固定到剪辑"开关（面板菜单）关闭时显示整个序列时间、可以看到剪辑范围外的关键帧；底部可缩放。可以框选、拖动关键帧，双击关键帧跳过去。剪辑范围外的关键帧在剪辑边缘显示小箭头提示。
- **优先级：** M4
- **BAE 模块：** bae-ui-edit
- **数据模型：** 无
- **备注：** 小时间轴的时间刻度显示序列时间，存储用片段时间，界面负责换算（edit-model.md 第 5.1、5.6 节）。

### PR-KF-003 · 时间轴里的剪辑关键帧（Clip Keyframes in Timeline）

- **行为要点：** 轨道展开到足够高时，剪辑上显示一条"橡皮筋"（默认是不透明度或音量），剪辑的 fx 徽章右键选择要显示哪个属性（运动 > 位置、某个效果的参数……）。Cmd 点击橡皮筋（或用钢笔工具 P）添加关键帧；上下拖动橡皮筋整体调整（两个关键帧之间的那段）；拖动关键帧改时间和值；右键关键帧改插值、删除。时间轴扳手菜单可关掉"显示视频关键帧""显示音频关键帧"。
- **优先级：** M4
- **BAE 模块：** bae-ui-edit (+ bae-edit)
- **数据模型：** 无。剪辑上显示哪个属性是视图状态。
- **备注：** 剪音频时最常用的是在时间轴上直接拉音量关键帧（做音乐压低、淡入淡出），这条在 M4 必须顺手：Cmd 点击加点、Opt 拖动只移动一个关键帧、拖动整段时显示 dB 变化量。

### PR-KF-004 · 关键帧插值（Keyframe Interpolation）

- **行为要点：** 时间插值：线性、贝塞尔曲线、自动贝塞尔曲线、连续贝塞尔曲线、定格、缓入、缓出（缓入/缓出会把关键帧改成贝塞尔并设置速度为 0）。空间插值（位置这类空间属性）：线性、贝塞尔曲线、自动贝塞尔曲线、连续贝塞尔曲线。右键关键帧选择；不同插值的关键帧在时间轴上形状不同（菱形线性、沙漏贝塞尔、圆形自动、方块定格，待核图形细节）。
- **优先级：** M4
- **BAE 模块：** bae-anim (+ bae-ui-edit)
- **数据模型：** 无新增：`interp_in` / `interp_out`（`linear | bezier | hold`）、`flags.temporal_continuous`、`flags.auto_bezier`、`ease_*`（data-model.md 第 3 节）。"缓入/缓出"是命令，写速度 0、影响 33.33% 的贝塞尔。
- **备注：** Pr 的贝塞尔手柄在图表上是"值 × 时间"的切线；BAE（与 AE 一样）存速度 + 影响。导入 Pr 工程时要把手柄换算成速度/影响（bae-interop-edit），换算公式与 AE 的图表编辑器相同。

### PR-KF-005 · 值图与速度图（Value Graph / Velocity Graph）

- **行为要点：** 在效果控件里展开属性的箭头，右侧小时间轴显示该属性的值曲线和速度曲线；拖动关键帧的贝塞尔手柄调整缓动；多维属性（位置）只显示速度图。
- **优先级：** 以后
- **BAE 模块：** bae-ui-edit (+ bae-anim)
- **数据模型：** 无
- **备注：** 动效工作区的图表编辑器（12）功能更全，剪辑里只需要简化版，可以复用曲线绘制代码。

### PR-KF-006 · 选择、移动与复制关键帧（Select / Move / Copy Keyframes）

- **行为要点：** 框选或 Shift 点击选中多个关键帧（可以跨属性、跨效果）；拖动一起移动；Opt 拖动选中关键帧的外侧端点按比例缩放时间（待核）；Cmd+C 复制，选中另一个剪辑（或同一剪辑）后把播放头放到目标位置 Cmd+V，以播放头为起点粘贴（保持相对时间）；可以粘贴到同类属性。Delete 删除选中关键帧。
- **优先级：** M4
- **BAE 模块：** bae-ui-edit (+ bae-edit)
- **数据模型：** 无
- **备注：** 一次移动多个关键帧是一个命令、一个撤销步骤（`key.move_many` 之类，可以放在 03 或 14）。

### PR-KF-007 · 运动路径（Motion Path）

- **行为要点：** 位置有关键帧时，在效果控件里选中"运动"后，节目监视器画面上显示运动路径（点表示每一帧的位置，点越稀越快），可以直接拖动路径上的关键帧和贝塞尔手柄。
- **优先级：** 以后
- **BAE 模块：** bae-ui-edit (+ bae-anim)
- **数据模型：** 无，空间切线 `spatial_in` / `spatial_out`（data-model.md 第 3 节）。
- **备注：** 与动效工作区合成查看器里的运动路径共用绘制。

### PR-KF-008 · 关键帧随修剪与速度变化（Keyframes vs Trim / Speed）

- **行为要点：** 修剪剪辑入点时，关键帧留在原来的画面内容上（不跟着剪辑开头移动），修掉的部分里的关键帧仍然保存、只是不可见；改变剪辑速度时关键帧跟着内容在时间轴上伸缩；剃刀切开后两段各自保留自己范围内的关键帧以及影响该范围的前后关键帧（待核：Pr 是否在切点补一个关键帧）。外滑时关键帧是否随内容移动待核。
- **优先级：** M1 — 时间基准现在就要定（edit-model.md 第 5.6 节），否则以后改动会让已有工程的动画错位。
- **BAE 模块：** bae-anim (+ bae-edit)
- **数据模型：** 片段属性的关键帧时间 = 片段时间 τ = `source_in + (t − start) × speed / 100`（edit-model.md 第 5.6 节）。
- **备注：** 剃刀切开时，为了让两段各自的动画在切点处连续，`clip.razor` 应在切点为每个动画属性补一个关键帧（值取切点处的求值结果）。这是 BAE 的做法，和 Pr 是否一致待核。

### PR-KF-009 · 音频关键帧：剪辑音量与轨道音量（Clip vs Track Volume Keyframes）

- **行为要点：** 音频剪辑的音量关键帧跟着剪辑走；音频轨道也有自己的音量和声像关键帧（轨道头右键或扳手菜单切换显示"轨道关键帧"），轨道关键帧固定在序列时间上，不随剪辑移动，主要由音轨混合器的自动化写入（PR-AUD-008）。音量橡皮筋的纵轴按 dB 显示（0 dB 在上部，上限 +6 dB）。
- **优先级：** M4（剪辑音量）；以后（轨道关键帧）
- **BAE 模块：** bae-ui-edit (+ bae-anim, bae-media)
- **数据模型：** 剪辑的 `audio:level`（片段时间）；轨道的 `audio:level`、`audio:pan`（序列时间）（edit-model.md 第 4、5.2 节）。
- **备注：** 音量在 dB 上插值还是在线性振幅上插值会影响淡出听感；Pr 的做法待核，BAE 先按 dB 线性插值。

### PR-KF-010 · 剪辑范围外的关键帧与删除全部（Off-Clip Keyframes / Delete All）

- **行为要点：** 关键帧可以落在剪辑范围之外（修剪造成的），效果控件里在剪辑边缘显示箭头，打开"固定到剪辑"后看不到它们；它们仍然影响剪辑范围内的插值。关闭秒表会删除该属性所有关键帧（包括范围外的）。
- **优先级：** M4
- **BAE 模块：** bae-ui-edit (+ bae-anim)
- **数据模型：** 无
- **备注：** 无

# Pr 清单：项目、素材箱与序列设置（PR-PRJ）

## 范围

剪辑开始之前和周边的东西：项目、项目面板与素材箱、导入、解释素材、媒体链接、子剪辑、合并剪辑、新建项（调整图层、彩条等）、项目设置、新建序列与序列设置。格式和优先级见 [README.md](README.md)，数据模型见 [edit-model.md](edit-model.md)。

和 AE 共用的部分（导入格式、图像序列识别、素材查找与重新链接、打包）在 `docs/spec/ae/project-comp-layers.md` 里已经写过，这里只写 Pr 不同或剪辑特有的地方。**BAE 只有一个项目面板**：Pr 的素材箱和 AE 的项目文件夹是同一种 `Folder` Prim，动效工作区和剪辑工作区看到的是同一棵项目树，只是列和默认视图不同。

## 项目

### PR-PRJ-001 · 项目（Project）

- **行为要点：** Pr 项目（`.prproj`）保存素材引用、序列、素材箱结构、项目设置，不保存媒体本身。一个项目里可以有任意多条序列。Pr 允许同时打开多个项目，可以在项目之间拖动素材和序列（会复制）；关闭项目时只关它自己的面板。
- **优先级：** M1 — BAE 已经有工程（`.bae` 目录包），剪辑数据放在同一个工程里，不另设项目格式。
- **BAE 模块：** bae-model (+ apps/bae)
- **数据模型：** 无新增。序列、素材、素材箱都是工程里的 Prim（edit-model.md 第 2 节）。
- **备注：** 同时打开多个工程、在工程之间复制序列属于外壳能力（11），M4 以后再看需要。

### PR-PRJ-002 · 作品（Productions）

- **行为要点：** 把多个 Pr 项目组织成一个"作品"文件夹，项目之间可以互相引用素材和序列而不复制，并提供项目级的锁（别人打开的项目只读）。
- **优先级：** 以后
- **BAE 模块：** bae-model (+ bae-sync)
- **数据模型：** 无新增。BAE 的跨工程引用（`Reference { project, prim }`，data-model.md 第 2 节）和工程层协同已经覆盖这个需求。
- **备注：** BAE 的多人协同天然比作品的"按项目加锁"更细，不需要照搬。

### PR-PRJ-003 · 自动保存（Auto Save）

- **行为要点：** 按间隔（默认 15 分钟）把项目副本存到"Adobe Premiere Pro Auto-Save"文件夹，保留最近若干份（默认 20 份）；可选"将备份项目保存到 Creative Cloud"。只在项目有改动时保存。
- **优先级：** M1 — BAE 的 CRDT 增量日志本身就是持续保存，不需要 Pr 式的定时副本。
- **BAE 模块：** bae-model (+ bae-sync)
- **数据模型：** 无
- **备注：** 对剪辑岗位要保证的是"崩溃不丢操作"，由工程层的增量日志保证（ARCHITECTURE 4.6）。界面上可以在偏好里展示"历史版本"入口（09 的命名版本）。

### PR-PRJ-004 · 项目设置（Project Settings）

- **行为要点：** 常规：视频渲染和回放引擎（Mercury 加速 / 仅软件）、视频和音频显示格式（时间码、帧、英尺+帧、音频采样）、动作和字幕安全区域百分比（默认 90% / 80%）、"项目中的所有序列使用相同的预览文件位置"。暂存盘：采集、视频预览、音频预览、项目自动保存、CC 库下载、动态图形模板媒体的位置。收录设置：见 PR-EXP-001。色彩：项目工作色彩空间（Pr 25 起）、HDR 图形白色、自动检测 Log。
- **优先级：** M4
- **BAE 模块：** bae-ui-edit (+ bae-model, bae-color)
- **数据模型：** 安全区域百分比放 Project Prim：`safe:action`（默认 90）、`safe:title`（默认 80），和 AE 共用。显示格式属于用户偏好，不进工程。预览缓存位置由 04 的缓存设置决定。
- **备注：** BAE 没有"仅软件渲染"模式，渲染一律走 GPU（VISION 第 1 条）。

### PR-PRJ-005 · 撤销与历史记录（Undo / History）

- **行为要点：** Cmd+Z / Shift+Cmd+Z 撤销重做；历史记录面板列出步骤，点某一步回到那里，之后再做新操作会丢掉后面的步骤；撤销次数上限可设（默认 32 步，待核）。
- **优先级：** M1 — 外壳（11）已实现历史面板，剪辑命令自动进入按作者撤销的栈。
- **BAE 模块：** bae-ui (+ bae-model)
- **数据模型：** 无
- **备注：** BAE 撤销上限 1000 步、只撤销自己的修改（data-model.md 第 5 节），比 Pr 好。剪辑工作区要保证每个手势只产生一个撤销步骤（例如拖动修剪松手才提交，见 edit-model.md 第 11 节"预演"）。

### PR-PRJ-006 · 工作区与模式（Workspaces / Import·Edit·Color·Export）

- **行为要点：** Pr 26 顶部有"导入、编辑、颜色、导出"四个模式（Opt+1 / 2 / 3 / 4），编辑模式下再有工作区（编辑、组件、颜色、效果、音频、字幕和图形、审阅、库……，Opt+Shift+1…9 切换，Opt+Shift+0 重置为已保存布局）。颜色模式有自己的一套快捷键。面板可以停靠、成组、浮动；`~`（反引号）最大化当前面板组，Shift+` 最大化光标下的面板，Ctrl+` 全屏显示监视器。
- **优先级：** M1 — 剪辑工作区注册到 11 的工作区系统（骨架布局：项目、源监视器、节目监视器、时间轴、效果控件）。
- **BAE 模块：** bae-ui-edit (+ bae-ui)
- **数据模型：** 无
- **备注：** BAE 的工作区按岗位划分（动效、剪辑、分镜、审阅、Agent），"剪辑"工作区内部再提供"编辑 / 音频 / 颜色 / 图形"几个子布局即可，不必复制 Pr 的四模式。最大化面板组的 `~` 外壳已经实现。

## 项目面板与素材箱

### PR-PRJ-007 · 素材箱（Bin）

- **行为要点：** 项目面板里的文件夹叫素材箱，可以嵌套；Cmd+/ 新建素材箱（项目面板内 Cmd+B），Shift+B 用选中项新建素材箱。双击素材箱默认在新面板中打开（可在偏好里改成就地打开或新标签打开）。拖动素材到素材箱、Cmd 拖动复制。删除素材箱会询问是否同时删除里面的项目项。
- **优先级：** M4（M1 复用已有的 Folder）
- **BAE 模块：** bae-ui-edit (+ bae-model)
- **数据模型：** 素材箱 = `Folder` Prim，与 AE 项目文件夹相同，不新增类型。
- **备注：** 项目面板应该是动效和剪辑工作区共用的一个面板（12 已在做 AE 式项目面板）。14 只增加剪辑需要的列和视图模式，具体归属由 11、12、14 商定。

### PR-PRJ-008 · 列表、图标、自由格式视图（List / Icon / Freeform View）

- **行为要点：** 列表视图显示可自定义的元数据列（名称、标签、帧速率、媒体开始/结束/持续时间、视频入点/出点、视频信息、音频信息、磁带名称、描述、日志注释、场景、镜头……），点击列头排序；图标视图显示缩略图，可调大小（项目面板内 Shift+[ / Shift+]）；自由格式视图可以随意摆放缩略图，像在桌上排卡片。Cmd+PageUp / Cmd+PageDown 切换列表和图标视图，Shift+\ 切换视图模式。
- **优先级：** M4
- **BAE 模块：** bae-ui-edit (+ bae-media)
- **数据模型：** 自由格式视图里卡片的位置属于视图状态，不进工程（Pr 存在项目里，BAE 存在面板 `save_state` 里，多人协作时不互相打乱）。
- **备注：** 缩略图由 08 解码、04 缓存；列表视图的数据来自 `MediaInfo::asset_attributes()`。

### PR-PRJ-009 · 悬停擦洗与缩略图（Hover Scrub / Poster Frame）

- **行为要点：** 图标视图里鼠标在缩略图上横向移动就预览画面（Shift+H 开关）；点击缩略图后可以用 J/K/L 播放、I/O 打入出点，直接在素材箱里粗剪；Cmd+P 设置标识帧（海报帧），Opt+P 清除。缩略图下方的细条显示入出点范围。
- **优先级：** M4
- **BAE 模块：** bae-ui-edit (+ bae-media, bae-render)
- **数据模型：** Asset 新增 `poster_frame`（time，源时间）；在素材箱里打的入出点写到来源的 `mark_in` / `mark_out`（edit-model.md 第 13 节第 9 条）。
- **备注：** 悬停擦洗要求随机取帧很快，依赖 08 的缩略图解码路径和代理（PR-EXP-001）。

### PR-PRJ-010 · 搜索与搜索素材箱（Search / Search Bin）

- **行为要点：** 项目面板顶部的搜索框按名称和所有可见元数据过滤（Shift+F 聚焦）；"从查询创建新的搜索素材箱"把查询存成一个动态素材箱，内容随项目变化自动更新；Shift+Cmd+F 打开查找对话框（按列和运算符组合条件）。
- **优先级：** M4
- **BAE 模块：** bae-ui-edit (+ bae-model)
- **数据模型：** 搜索素材箱 = `Folder` 加属性 `search:query`（string），它的子项由界面实时计算，不存 Prim。
- **备注：** Agent 侧对应 17 的 `prim.find`。

### PR-PRJ-011 · 标签颜色（Label Colors）

- **行为要点：** 每个项目项有标签颜色（默认按类型：视频紫、音频绿、序列青、静帧淡紫……），放进序列的剪辑继承来源的颜色；右键"标签 > 选择标签组"选中同色项。偏好里可以改颜色和名称。
- **优先级：** M4
- **BAE 模块：** bae-ui-edit (+ bae-model)
- **数据模型：** 沿用 Asset / Comp 的 `label`（int，与 AE 的 16 色标签同一套）；Clip 的 `label` 为空时显示来源的颜色（edit-model.md 第 5.1 节）。按类型的默认值和 Pr 不同，待核。
- **备注：** 与 AE 共用一套标签色表，跨工作区颜色一致。

### PR-PRJ-012 · 使用情况（Video Usage / Audio Usage）

- **行为要点：** 列表视图的"视频使用情况""音频使用情况"列显示素材在序列里被用了几次；图标视图的缩略图角上有已用标记；点开可以看到用在哪条序列的哪个时间点，并跳过去。右键"显示序列中的剪辑"类似。
- **优先级：** M4
- **BAE 模块：** bae-edit (+ bae-ui-edit)
- **数据模型：** 无新增，由 `bae-edit::query` 遍历序列计算（可以缓存，按 StageEvent 失效）。
- **备注：** 同一套查询给 21 打包"只打包用到的素材"复用（edit-model.md 第 10 节 `used_source_ranges`）。

### PR-PRJ-013 · 元数据（Metadata）

- **行为要点：** 元数据面板显示剪辑的 XMP 元数据和 Pr 自己的项目元数据：描述、场景、镜头、日志注释、"良好"标记、拍摄日期、磁带名称等；可编辑的字段改的是项目里的值，部分可以写回文件的 XMP。素材箱列表视图的列来自这里。
- **优先级：** 以后
- **BAE 模块：** bae-model (+ bae-media, bae-ui-edit)
- **数据模型：** Asset 增加 `meta:*` 命名空间的字符串属性（`meta:description`、`meta:scene`、`meta:shot`、`meta:log_note`、`meta:good`（bool）……），不写回媒体文件。
- **备注：** Agent 用元数据做粗剪（按场景/镜头/好条筛选）时很有价值，属性名先定下来。

## 导入与媒体

### PR-PRJ-014 · 导入（Import / Media Browser / Import Mode）

- **行为要点：** Cmd+I 导入对话框；从访达拖入项目面板或直接拖进时间轴（拖进时间轴会同时导入并放到那里）；媒体浏览器（Opt+Cmd+I 导入选中项）按卡、相机格式识别目录结构（XDCAM、AVCHD、P2 这类），预览后再导入；Pr 22 起的"导入"模式按位置浏览、勾选后导入，可选"新建序列""复制媒体""创建新素材箱"。导入时自动识别图像序列需要勾选"图像序列"。
- **优先级：** M4（M1 复用已有的导入命令）
- **BAE 模块：** bae-ui-edit (+ bae-media, bae-model)
- **数据模型：** 无新增；导入结果是 Asset Prim（与动效工作区相同）。
- **备注：** 格式支持与识别见 AE 清单的导入部分和 08。相机卡目录结构识别（把 `PRIVATE/M4ROOT/CLIP/*.MP4` 这类目录当成一组剪辑）以后再做。

### PR-PRJ-015 · 导入 PSD 和分层文件（Import Layered File）

- **行为要点：** 导入 PSD 时弹出"导入分层文件"对话框：合并所有图层、合并的图层（选择哪些）、各个图层（每层一个素材项，可选"文档大小"或"图层大小"）、序列（每层一个素材，并新建一条按图层堆叠的序列）。AI 文件按合并后的画面导入。
- **优先级：** 以后
- **BAE 模块：** bae-media (+ bae-edit)
- **数据模型：** "序列"方式 = 新建 Sequence，每个图层一条视频轨。
- **备注：** 依赖 08 的 PSD 分层读取（08 任务书里尚未完成）。

### PR-PRJ-016 · 解释素材（Interpret Footage）

- **行为要点：** 右键"修改 > 解释素材"：帧速率（使用文件中的帧率 / 采用此帧速率，改了以后素材的时长随之变化，可选"使用文件中的值"还原）、像素长宽比（使用文件中的 / 符合为）、场序、Alpha 通道（忽略、反转、预乘 Alpha）、时间码（使用文件中的 / 自定义起始时间码）、色彩管理（覆盖媒体色彩空间、输入 LUT）、VR 属性。改动影响项目里所有用到它的剪辑。
- **优先级：** M4
- **BAE 模块：** bae-model (+ bae-media, bae-color, bae-ui-edit)
- **数据模型：** 复用 Asset 已有的 `frame_rate`、`pixel_aspect`、`alpha_mode`、`color_space`；新增 `field_order`、`timecode_start`（time）。和 AE 的解释素材是同一组属性。
- **备注：** 改帧率后，已经在序列里的剪辑保持 `start` 和 `duration` 不变，按新帧率重新换算源时间（Pr 行为：剪辑长度不变、内容速度变化），待核。

### PR-PRJ-017 · 链接媒体、设为脱机、替换素材（Link Media / Make Offline / Replace Footage）

- **行为要点：** 打开项目时找不到的媒体弹出"链接媒体"对话框，列出所有脱机剪辑；可以按文件名、扩展名、媒体开始时间、磁带名称、文件 ID 等条件匹配；找到一个后"自动重新链接其他媒体"在同一目录关系里找回其余的；"脱机"保留占位。"设为脱机"可选只断开链接或同时删除媒体文件。"替换素材"（默认没有快捷键）把一个项目项换成另一个文件，所有用到它的剪辑跟着换。
- **优先级：** M1 — 素材查找与重新链接已在 02 的 PR C 实现（`asset.set_file`），剪辑工作区需要一个 Pr 式的链接媒体对话框（M4）。
- **BAE 模块：** bae-model (+ bae-ui-edit)
- **数据模型：** 无新增（data-model.md 第 6 节 `asset.set_file`、project-format.md 第 5 节）。
- **备注：** 脱机剪辑在时间轴和监视器里显示"媒体脱机"占位画面，序列照常可以编辑。

### PR-PRJ-018 · 子剪辑（Subclip）

- **行为要点：** 在源监视器打好入出点后 Cmd+U（或把源监视器画面按住 Cmd 拖到项目面板）创建子剪辑，弹框可以命名并勾选"将修剪限制为子剪辑边界"。子剪辑是独立的项目项，放进序列后修剪不能超出子剪辑范围（勾选时）；"编辑子剪辑"可改范围或转成主剪辑。子剪辑共享主剪辑的媒体、解释设置和剪辑标记。
- **优先级：** M4（M1 预留类型）
- **BAE 模块：** bae-edit (+ bae-model, bae-ui-edit)
- **数据模型：** Asset `kind` 增加 `subclip`，属性 `subclip:master`（prim_ref）、`subclip:in`、`subclip:out`（time）、`subclip:restrict`（bool）。片段 `source` 可以指向子剪辑，源时间仍用主剪辑的时间。
- **备注：** 子剪辑是 Agent 做"选好镜头"整理的常用产物，类型要先留。

### PR-PRJ-019 · 合并剪辑（Merge Clips）

- **行为要点：** 选中一个视频剪辑和若干单独录制的音频剪辑，"合并剪辑"按入点、出点、时间码或剪辑标记对齐，生成一个新的项目项；可选"移除摄像机音频"。合并剪辑放进序列时视频和这些音频一起出现并互相链接。
- **优先级：** 以后
- **BAE 模块：** bae-edit (+ bae-model, bae-media)
- **数据模型：** Asset `kind` 增加 `merged`，子 Prim 列出各组成部分（`source`、`offset`、`use_audio`）。M1 不预留。
- **备注：** 按音频波形对齐（Pr 的"同步"用的是音频）依赖 08 的音频分析。

### PR-PRJ-020 · 新建项（New Item: Adjustment Layer / Bars and Tone / Black Video / Color Matte / Transparent Video / Universal Counting Leader）

- **行为要点：** 项目面板"新建项"：调整图层（按序列尺寸）、彩条和色调（SMPTE 彩条 + 1 kHz 测试音，可选 HD 彩条）、黑场视频、颜色遮罩（拾色器选颜色并命名）、透明视频、通用倒计时片头（擦除颜色、背景色、线条色、目标色、数字颜色，出点处提示音、倒数 2 秒提示音）。它们都是合成项，没有源文件，默认持续时间按静止图像默认持续时间。
- **优先级：** M4（M1 预留 Asset 种类）
- **BAE 模块：** bae-edit (+ bae-effects, bae-model)
- **数据模型：** Asset `kind` 增加 `adjustment`、`generator`（`generator:type` = `bars_tone | black_video | transparent_video | countdown` 加各自参数）；颜色遮罩复用 `solid`（edit-model.md 第 5.5 节）。
- **备注：** 渲染由 07 的生成器实现；通用倒计时片头可以以后用一个内置动效合成实现。

### PR-PRJ-021 · 静止图像默认持续时间（Still Image Default Duration）

- **行为要点：** 偏好 > 时间轴："静止图像默认持续时间"（默认 5 秒，可按帧或秒设置）。导入后放进序列的静帧、新建的合成项按它取长度；改偏好不影响已经放进序列的。
- **优先级：** M1 — #66 已用 `DEFAULT_STILL_DURATION = 5 s`。
- **BAE 模块：** bae-edit (+ bae-ui-edit)
- **数据模型：** 偏好，不进工程；命令参数可以覆盖。
- **备注：** 静帧剪辑可以无限拉长，不会"媒体不足"。

## 序列

### PR-PRJ-022 · 新建序列与序列预设（New Sequence / Sequence Presets）

- **行为要点：** Cmd+N 打开"新建序列"：左边是按类别分组的预设（Pr 26.2 自带：HD 1080p、UHD (4K)、UHD (4K) HDR、Social（竖屏 4:5、9:16，方形 1:1）、Broadcast（多声道离散单声道），以及按相机格式分组的旧版预设 ARRI、AVC-Intra、AVCHD、Canon XF、DNxHD、DNxHR、DV、DVCPRO、HDV、ProRes RAW、RED R3D、XDCAM 等）；"设置"页改各项参数；"轨道"页设视频轨数、音频主轨类型和每条音频轨的类型；可以保存为自定义预设。
- **优先级：** M1 — `sequence.create` 已在 #66；预设列表 M4。
- **BAE 模块：** bae-edit (+ bae-ui-edit)
- **数据模型：** 序列预设是 Sequence 属性值的集合，作为 `bae-edit` 的内置数据，不是 Prim（edit-model.md 第 3 节）。
- **备注：** 预设名称和分组见本机 `Settings/SequencePresets/`；BAE 只需要常用的几组（HD、4K、竖屏、方形），按相机格式分组的旧预设不需要，"从剪辑新建序列"更常用（PR-PRJ-024）。

### PR-PRJ-023 · 序列设置（Sequence Settings）

- **行为要点：** 编辑模式（决定预览文件格式和可选的帧大小）、时基（帧率）、帧大小、像素长宽比、场、显示格式（时间码、丢帧/非丢帧、英尺+帧、帧）、工作色彩空间、音频采样率、音频显示格式（音频采样 / 毫秒）、视频预览（预览文件格式、编解码器、宽高）、最大位深、最高渲染品质、以线性颜色合成、VR 属性。序列建好后时基和音频采样率不能改（其余可以在"序列 > 序列设置"里改）。
- **优先级：** M1 — 属性名现在定（edit-model.md 第 3 节），设置对话框 M4。
- **BAE 模块：** bae-edit (+ bae-model, bae-ui-edit)
- **数据模型：** Sequence 增加 `pixel_aspect`、`field_order`、`audio_sample_rate`、`audio:master_format`、`start_timecode`、`timecode_display`、`color:working_space`、`render:max_bit_depth`、`render:max_quality`、`preview:format`。
- **备注：** BAE 可以允许改帧率（重新按帧号吸附所有编辑点），这是比 Pr 好的地方，但要在命令里明确"按帧号还是按时间保持"。M4 再定。

### PR-PRJ-024 · 从剪辑新建序列（New Sequence From Clip）

- **行为要点：** 把素材拖到项目面板的"新建项"按钮或空的时间轴上，或右键"从剪辑新建序列"，按素材的帧率、帧大小、像素长宽比、音频声道新建序列并把素材放进去。这是 Pr 用户最常用的建序列方式。
- **优先级：** M4
- **BAE 模块：** bae-edit (+ bae-ui-edit)
- **数据模型：** 无新增。
- **备注：** 命令可以叫 `sequence.create_from_source`，Agent 也常用。

### PR-PRJ-025 · 剪辑不匹配警告（Clip Mismatch Warning）

- **行为要点：** 往空序列里放第一个剪辑时，如果剪辑的帧率或帧大小和序列不同，弹出"剪辑不匹配警告"：更改序列设置（按剪辑改）/ 保持现有设置。偏好里可以关掉这个提示。
- **优先级：** M4
- **BAE 模块：** bae-ui-edit (+ bae-edit)
- **数据模型：** 无
- **备注：** 只在序列完全为空时出现。Agent 调用插入命令时不弹框，用参数 `match_sequence_to_clip` 决定。

### PR-PRJ-026 · 缩放为帧大小与设为帧大小（Scale to Frame Size / Set to Frame Size）

- **行为要点：** 偏好 > 媒体 > "默认媒体缩放"：无 / 缩放为帧大小 / 设为帧大小。放进序列时尺寸不同的剪辑据此处理。"缩放为帧大小"是按序列尺寸重新取样（之后再放大会糊），"设为帧大小"只是把运动 > 缩放设成合适的值（放大仍是全分辨率）。剪辑右键菜单也有这两项。
- **优先级：** M4（M1 预留属性）
- **BAE 模块：** bae-edit (+ bae-render)
- **数据模型：** Clip `fit`（`none | set_to_frame | scale_to_frame`，edit-model.md 第 5.2 节）。
- **备注：** BAE 渲染在 GPU 上按需取样，"缩放为帧大小"不需要真的降低分辨率；保留这个选项只为让运动 > 缩放的数值和 Pr 一致。

### PR-PRJ-027 · 多条序列与序列标签（Timeline Tabs）

- **行为要点：** 时间轴面板可以同时打开多条序列，每条一个标签；节目监视器跟随当前标签。双击项目面板里的序列打开它；在时间轴里双击嵌套序列打开它（PR-TL-036）。时间轴面板可以有多个实例（堆叠或并排对照两条序列）。
- **优先级：** M1 — 时间轴面板注册成可多开的面板（`timeline_edit:<序列>` 这类面板 ID，ui-shell.md 第 2 节）。
- **BAE 模块：** bae-ui-edit (+ bae-ui)
- **数据模型：** 无。打开了哪些序列是视图状态。
- **备注：** 和动效工作区的合成时间轴分开注册（面板类型不同），避免两种时间轴的快捷键作用域混在一起。

### PR-PRJ-028 · 自动重构序列（Auto Reframe Sequence）

- **行为要点：** "序列 > 自动重构序列"复制出一条新长宽比（9:16、4:5、1:1、16:9 或自定义）的序列，用 AI 跟踪画面主体，给每个剪辑加"自动重构"效果（带位置关键帧），可选运动速度（较慢 / 默认 / 较快）和"嵌套剪辑"。
- **优先级：** 以后
- **BAE 模块：** bae-edit (+ bae-effects, bae-media)
- **数据模型：** 无新增：新序列 + 每个剪辑的 `transform:position` 关键帧。
- **备注：** 主体跟踪需要分析模型，可以作为插件或 Agent 能力实现，不进核心。

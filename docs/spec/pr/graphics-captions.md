# Pr 清单：图形与字幕（PR-GFX）

## 范围

在剪辑里直接做的文字和形状图形、基本图形面板与属性面板、文本样式、响应式设计、滚动字幕、动态图形模板（.mogrt）、字幕轨与转录。

**BAE 的做法（edit-model.md 第 5.5 节）：** Pr 的"图形剪辑"在 BAE 里是一个**内嵌在序列里的小动效合成**（`/sequences/<seq>/graphics/<g>` 下的 Comp），时间轴上的剪辑引用它。剪辑工作区用简化的面板编辑它（文字、形状、对齐、外观）；需要做复杂动画时直接在动效工作区打开同一个合成，改完剪辑里立刻更新。文字排版和形状渲染复用 05 的 `bae-text` / `bae-vector`。Pr 要借助 AE 做 .mogrt 再导回来，BAE 不需要中间文件，这是"一个工程容纳多个岗位"最直观的体现。

### PR-GFX-001 · 文字工具（Type Tool, T）

- **行为要点：** 按 T（或 Cmd+T 新建文本图层）后在节目监视器画面上点击输入单行文字，拖出文本框输入段落文字；如果播放头处没有图形剪辑，就在最上面的空视频轨上新建一个图形剪辑（默认长度按静止图像默认持续时间）；已经选中图形剪辑时，新文本作为它的一个图层加进去。Opt+Cmd+' 进入文本编辑。
- **优先级：** M4
- **BAE 模块：** bae-edit (+ bae-ui-edit, bae-text, bae-motion)
- **数据模型：** 新建图形剪辑 = 在序列的 `graphics/` 下建 Comp（尺寸、帧率随序列）+ 文字图层，再放一个 `source` 指向它的 Clip（edit-model.md 第 5.5 节）。
- **备注：** 中文输入法在监视器里直接打字要走 11 已经验证过的输入法路径（`PlatformOutput::ime`，ui-shell.md 第 7 节）。

### PR-GFX-002 · 形状工具（Shape Tools）

- **行为要点：** 工具栏里的矩形、椭圆、多边形工具（Opt+Cmd+R 新建矩形、Opt+Cmd+E 新建椭圆），钢笔工具（P）画自由形状；Shift 约束比例。形状成为图形剪辑里的一个图层，有填充、描边、阴影。
- **优先级：** M4
- **BAE 模块：** bae-edit (+ bae-ui-edit, bae-vector, bae-motion)
- **数据模型：** 同 PR-GFX-001，形状是内嵌合成里的形状图层（复用 AE 形状图层模型）。
- **备注：** 无

### PR-GFX-003 · 图形剪辑与图层（Graphic Clips and Layers）

- **行为要点：** 一个图形剪辑可以包含多个图层：文本、形状、剪辑（拖进来的图片或视频，"图形中的媒体"）。基本图形面板的编辑页列出图层，拖动改顺序；Cmd+[ / Cmd+] 下移/上移一层，Shift+Cmd+[ / ] 移到最底/最顶；Opt+Cmd+[ / ] 选择下一个/上一个图层。图层可以单独设置时间（在剪辑范围内的入出点）。
- **优先级：** M4
- **BAE 模块：** bae-ui-edit (+ bae-motion, bae-edit)
- **数据模型：** 内嵌合成的 `layers/`，图层顺序与 AE 一致（第一个子节点是最上层，data-model.md 第 10 节）。
- **备注：** 图层操作直接用 12 的动效命令（`bae-motion`），14 不重复实现。

### PR-GFX-004 · 基本图形与属性面板（Essential Graphics / Properties Panel）

- **行为要点：** 基本图形面板分"浏览"（动态图形模板库）和"编辑"（当前图形的图层和属性）两页；Pr 25 起的"属性"面板按选中对象显示常用属性：对齐并变换（对齐到视频帧或选区、位置、锚点、缩放、旋转、不透明度）、文本（字体、样式、大小、字距、行距、基线偏移、仿粗体/斜体、全部大写、对齐：Shift+Cmd+L/C/R 左/中/右）、外观（填充、多个描边、背景、阴影、文本蒙版）。
- **优先级：** M4
- **BAE 模块：** bae-ui-edit (+ bae-text, bae-motion)
- **数据模型：** 无新增：属性就是内嵌合成里图层的属性（`text:source` 的 `text_document`、形状的填充描边、`transform:*`）。
- **备注：** 背景（文字后面的圆角底板）和多描边是 Pr 字幕的常用样式，05 的文字渲染需要支持（见 05 的现有任务）。

### PR-GFX-005 · 文本样式与主样式（Text Styles / Master Styles）

- **行为要点：** 在属性面板把当前文字外观"创建样式"保存为项目里的样式项（出现在项目面板）；其他文字套用这个样式；修改样式后，所有套用它的文字一起更新（"推送到样式"），也可以对单个文字解除关联。
- **优先级：** 以后
- **BAE 模块：** bae-model (+ bae-ui-edit, bae-text)
- **数据模型：** 样式 = 工程里的一个 Prim（例如 `TextStyle`），文字图层用 `references` 引用它（data-model.md 第 2 节的引用：被引用的属性比本地意见弱，本地改过的属性保留覆盖）。这正好是 BAE 引用机制的用例。
- **备注：** 同一机制以后也给分镜（Ai 式字符样式）用，类型由 02 统一定义。

### PR-GFX-006 · 响应式设计（Responsive Design: Position / Time）

- **行为要点：** 位置：把一个图层"固定到"视频帧或另一个图层的某条边，被固定的图层随之移动或伸缩（例如文字变长时背景框跟着变宽）。时间：设置开场和结尾的持续时间，拉长剪辑时开场和结尾的关键帧动画保持不变、只拉伸中间部分；可勾"滚动"。
- **优先级：** 以后
- **BAE 模块：** bae-motion (+ bae-anim)
- **数据模型：** 位置固定是图层属性 `pin:target`、`pin:edges`（以后定）；时间保护区是合成属性 `responsive:intro`、`responsive:outro`（time）。
- **备注：** "拉长剪辑只拉中间"对 BAE 的内嵌合成是时间重映射的一个特例：图形剪辑长度变化时自动生成源时间映射。这个能力对剪辑里的字幕条、角标很重要，M4 之后优先考虑。

### PR-GFX-007 · 滚动和游动字幕（Roll / Crawl）

- **行为要点：** 在属性面板对图形勾选"滚动"（垂直）或游动（水平，待核入口），选项：开始于屏幕外、结束于屏幕外、预卷、过卷、缓入、缓出；滚动速度由剪辑长度决定，节目监视器右侧出现滚动条预览。
- **优先级：** 以后
- **BAE 模块：** bae-motion (+ bae-text)
- **数据模型：** 内嵌合成上的属性（`roll:mode`、`roll:start_offscreen`…），渲染时换算成位置动画。
- **备注：** 片尾字幕是剪辑的刚需，但实现可以很简单（按长度匀速移动 + 缓入缓出）。

### PR-GFX-008 · 动态图形模板（Motion Graphics Templates, .mogrt）

- **行为要点：** 基本图形"浏览"页列出本地模板、Adobe Stock 模板；拖到时间轴生成图形剪辑，只暴露模板作者开放的属性（文字、颜色、复选框、滑块、下拉、媒体替换）。AE 制作的 .mogrt 在 Pr 里需要后台的 AE 渲染引擎；Pr 制作的 .mogrt 用 Pr 自己渲染。可以从 Pr 把图形导出为动态图形模板。
- **优先级：** 以后
- **BAE 模块：** bae-motion (+ bae-ui-edit, bae-interop-edit)
- **数据模型：** BAE 的对应物是"带开放参数的合成模板"：合成 + 一组暴露的属性（以后在 02/12 定义，类似 AE 的"基本属性"（Essential Properties，AE 清单里有））。导入 .mogrt：Pr 制作的可以解析其中的图形描述，AE 制作的需要 15 的 AE 导入能力。
- **备注：** BAE 里模板和使用模板的剪辑在同一工程中，模板作者（动效）改了模板，剪辑里实时更新，这是相对 Pr 的优势。

### PR-GFX-009 · 在动效工作区编辑图形（Edit Graphic in Motion Workspace）

- **行为要点：** （BAE 特有，对应 Pr 的"在 After Effects 中编辑"一类流程）在图形剪辑上双击或右键"在动效工作区中打开"，切到动效工作区并打开它的内嵌合成，加关键帧、表达式、效果；回到剪辑工作区立刻看到结果。
- **优先级：** M2 — 动效和剪辑在同一工程里互通是 M2"交接"的核心体验之一。
- **BAE 模块：** bae-ui-edit (+ bae-motion, bae-ui)
- **数据模型：** 无新增：Clip `source` 指向 Comp；内嵌合成也可以"提升"为项目里的普通合成（移动 Prim 到项目文件夹）。
- **备注：** 与 PR-XCH-008（双击片段跳到动效合成）是同一个跳转动作。

### PR-GFX-010 · 旧版标题（Legacy Title）

- **行为要点：** Pr 旧的字幕设计器（独立窗口）已弃用，新版本只能打开和升级旧工程里的旧版标题（转换成图形剪辑）。
- **优先级：** 以后
- **BAE 模块：** bae-interop-edit
- **数据模型：** 无
- **备注：** BAE 不做旧版标题编辑器，只在导入 Pr 工程时尽量转换。

### PR-GFX-011 · 字幕轨道（Caption Tracks）

- **行为要点：** 字幕在专门的字幕轨上（显示在视频轨上方），一个序列可以有多条字幕轨（不同语言或格式）；Opt+Cmd+A 添加字幕轨，Opt+Cmd+C 在播放头处添加字幕段；格式：副标题（Subtitle，默认）、CEA-608、CEA-708、图文电视、澳大利亚 OP-42、EBU 字幕（OP-47）等（待核完整列表）。字幕段像剪辑一样可以修剪、移动、对齐；Opt+Cmd+↑ / ↓ 跳到上一个/下一个字幕段。轨道头的眼睛控制是否显示。
- **优先级：** 以后（M1 预留 `track_kind = caption`）
- **BAE 模块：** bae-edit (+ bae-ui-edit, bae-text)
- **数据模型：** Track `track_kind = caption`、`caption:format`；字幕段是没有来源的 Clip，带 `caption:text`、`caption:style`（edit-model.md 第 4、5.5 节）。
- **备注：** 字幕段的拆分合并、文字编辑都要是命令（Agent 改字幕是高频需求）。

### PR-GFX-012 · 文本面板：转录文本与字幕（Text Panel: Transcript / Captions）

- **行为要点：** 文本面板有"转录文本""字幕""图形"三个标签。转录：显示序列音频的转录文本（带说话人和时间），点击文字跳到对应时间，可以搜索、修改说话人。字幕：列出所有字幕段，直接改文字、拆分、合并、搜索替换，和时间轴同步选中。图形：列出序列里所有文字图形，可以统一改字。
- **优先级：** 以后
- **BAE 模块：** bae-ui-edit (+ bae-edit)
- **数据模型：** 转录结果存为工程数据（每个来源一份，`Transcript` Prim 或 Asset 上的 `bytes`，以后定），以便基于文本的编辑和 Agent 使用。
- **备注：** 无

### PR-GFX-013 · 语音转文本与基于文本的编辑（Speech to Text / Text-Based Editing）

- **行为要点：** 导入时或手动"创建转录文本"（选语言，可识别说话人），在本机用模型转录；"创建字幕"按转录文本生成字幕段（每段最大字符数、最短时长、间隔、行数可设）；"基于文本的编辑"：在源剪辑的转录文本里选中一段文字直接插入/覆盖到序列，在序列转录文本里删掉文字就删掉对应片段（"提取"）、自动标记停顿和口头禅（"嗯""啊"）一键删除。
- **优先级：** 以后
- **BAE 模块：** bae-edit (+ bae-media, bae-agent)
- **数据模型：** 转录文本带每个词的源时间；基于文本的编辑最终都是普通的插入、覆盖、提取命令。
- **备注：** 语音识别模型按需下载（不进主安装包）。这是 Agent 粗剪最有价值的输入之一，17/18 的 Agent 指南可以直接利用。

### PR-GFX-014 · 字幕样式与位置（Caption Styles / Position）

- **行为要点：** 字幕段的外观：字体、大小、颜色、背景（框）、描边、阴影、对齐；位置用 9 宫格区域加偏移；可以把外观存成字幕样式（项目样式项）并套用到整条字幕轨。不同格式（CEA-608 这类）的可选样式受标准限制。
- **优先级：** 以后
- **BAE 模块：** bae-ui-edit (+ bae-text)
- **数据模型：** 字幕样式同文本样式（PR-GFX-005）；轨道级默认样式放在 Track 上。
- **备注：** 无

### PR-GFX-015 · 导入导出字幕文件（Import / Export Captions）

- **行为要点：** 导入 SRT、SCC、STL、MCC、DFXP/XML 等字幕文件（成为项目面板里的字幕项，拖进序列生成字幕轨）；导出：文本面板菜单"导出到 SRT 文件"/"导出到文本文件"，导出设置的"字幕"页可以"创建附属文件"（SRT、SCC 等）、"将字幕刻录到视频"或"嵌入到输出文件"（部分格式）。
- **优先级：** 以后（SRT 导入导出可以提前）
- **BAE 模块：** bae-interop-edit (+ bae-media)
- **数据模型：** 无新增。
- **备注：** SRT 是最常见的交付格式，解析简单，可以在字幕轨实现时一并做。

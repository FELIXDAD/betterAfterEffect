# Pr 清单：音频（PR-AUD）

## 范围

音频轨道和声道、音频增益、剪辑音量、波形、音频剪辑混合器、音轨混合器与自动化、音频表、音频效果的使用、基本声音面板、响度、淡入淡出与交叉淡化、音频时间单位、音频缓存。音频效果和音频过渡的清单见 [effects-transitions.md](effects-transitions.md) 附录 B、C。

**BAE 的分工：** 混音和播放归 08 `bae-media`（已有解码、`AudioSource`、`Waveform`；cpal 播放和音画同步时钟尚未完成）。现在没有任何模块负责"多轨混音引擎"（剪辑音量、声像、轨道推子、效果插槽、子混合、主轨），这是 14 对 08 最大的请求：建议在 `bae-media` 里加一个与界面无关的混音模块，动效工作区（AE 音频图层的音量关键帧、预览带声音）也用它。音频效果的 DSP 实现是 CPU 代码，可以作为 19 的原生插件或 `bae-media` 的内置处理器，M4 再定。

### PR-AUD-001 · 音频轨道类型与主声道（Audio Track Types / Master Track）

- **行为要点：** 新建序列时设主声道类型：立体声（默认）、5.1、多声道（指定声道数）、单声道。音频轨类型：标准（能放单声道和立体声剪辑，Pr 默认）、单声道、5.1、自适应（剪辑的每个声道可以映射到主轨的任意声道，适合多声道交付）。剪辑只能放进声道格式兼容的轨道。主声道轨显示在所有音频轨下方，只有音量（和声像，取决于格式），不能放剪辑。
- **优先级：** M1（预留类型和枚举）；M4 实现
- **BAE 模块：** bae-edit (+ bae-media, bae-model)
- **数据模型：** Sequence 的 `audio:master_format`、`audio:master_channels`；Track 的 `audio:channel_format`、`track_kind = master`（edit-model.md 第 3、4 节）。
- **备注：** M4 先支持立体声主轨 + 标准轨，5.1 和自适应以后做，但枚举现在就定，避免以后迁移。

### PR-AUD-002 · 修改音频声道（Modify Audio Channels）

- **行为要点：** 右键素材"修改 > 音频声道"（Shift+G）：剪辑声道格式（单声道、立体声、5.1、自适应）、音频剪辑数量，以及一张矩阵——每个源声道分给哪个剪辑的哪个声道。例如一条双单声道的采访录音，可以设成"2 个单声道剪辑"（每个声道一个剪辑，放进序列时占两条轨道），或"1 个立体声剪辑"。必须在放进序列之前改；已经在序列里的剪辑不受影响（Pr 会提示）。
- **优先级：** M4（M1 预留 `source_channels`）
- **BAE 模块：** bae-edit (+ bae-media, bae-ui-edit)
- **数据模型：** 来源 Asset 增加 `audio:channel_layout`（剪辑格式 + 声道分配表，JSON 或 int 列表）；放进序列后每个音频剪辑记录自己用了哪几个源声道（Clip `source_channels`，edit-model.md 第 5.1 节）。
- **备注：** 源修补里显示的 A1、A2…个数就由这个映射决定（PR-TL-015）。声道映射也是 Agent 处理多轨录音时最容易出错的地方，命令要能清楚报告每个剪辑用了哪些声道。

### PR-AUD-003 · 音频增益（Audio Gain）

- **行为要点：** 选中剪辑按 G 打开"音频增益"：将增益设置为（绝对 dB）、调整增益值（相对）、标准化最大峰值为（多个剪辑时各自标准化）、标准化所有峰值为（多个剪辑按整体标准化，保持相对响度）；对话框显示峰值振幅。增益在音量关键帧之前生效，不是关键帧。也可以对项目面板里的素材设增益（影响以后放进序列的剪辑）。
- **优先级：** M4
- **BAE 模块：** bae-edit (+ bae-media)
- **数据模型：** Clip `audio:gain`（dB，不可动画，edit-model.md 第 5.2 节）；素材级增益放 Asset `audio:gain`。
- **备注：** 标准化需要扫描音频峰值，08 的 `Waveform` 已经有 min/max 峰值，可以直接用。

### PR-AUD-004 · 剪辑音量调整（Clip Volume）

- **行为要点：** [ / ] 把选中剪辑（没选中时是播放头下目标轨道上的剪辑）音量减/加 1 dB，Shift+[ / Shift+] 按"大幅音量调整"（偏好 > 音频，默认值待核）调整；在时间轴上拖动音量橡皮筋（没有关键帧时整体调）；效果控件里"音量 > 级别"和"旁路"。音量上限 +6 dB（再大要用增益）。
- **优先级：** M4（M1 预留 `audio:level`）
- **BAE 模块：** bae-edit (+ bae-ui-edit, bae-media)
- **数据模型：** Clip `audio:level`（dB，可动画）。
- **备注：** 剪辑音量有关键帧时，[ / ] 是整体平移所有关键帧还是在播放头处加关键帧，Pr 的行为待核。

### PR-AUD-005 · 音频波形（Audio Waveforms）

- **行为要点：** 音频轨展开后显示波形；"经修正的音频波形"（默认打开）把波形画成单侧（绝对值）以便看清小声部分，关掉后是正负对称的；波形随剪辑音量调整实时变化（待核：Pr 波形是否反映音量关键帧）；立体声剪辑显示两个声道。导入后首次显示前要生成峰值文件。
- **优先级：** M1（显示波形）
- **BAE 模块：** bae-ui-edit (+ bae-media)
- **数据模型：** 无，波形缓存在工程 `cache/`（ARCHITECTURE 4.6）。
- **备注：** 08 的 `Waveform` 已支持按缩放级别取峰值；长素材的峰值生成要在后台进行，生成完之前显示占位。

### PR-AUD-006 · 音频剪辑混合器（Audio Clip Mixer）

- **行为要点：** Shift+9 打开。每条音频轨一列推子，控制的是**播放头下那个剪辑**的音量和声像（不是整条轨），播放头移到别的剪辑上推子跟着变；推子上方是声像旋钮，下方是静音、独奏、"写关键帧"按钮（打开后播放时拖推子会在剪辑上写音量关键帧）；每列有表。
- **优先级：** M4
- **BAE 模块：** bae-ui-edit (+ bae-edit, bae-media)
- **数据模型：** 无新增：写的是 Clip 的 `audio:level`、`audio:pan`。
- **备注：** 播放时写关键帧要按一定间隔采样并简化（Pr 偏好里有"自动匹配时间""关键帧的最小间隔"，待核），命令按批写入、一次撤销。

### PR-AUD-007 · 音轨混合器（Audio Track Mixer）

- **行为要点：** Shift+6 打开（`音频混合器` 面板组）。每条音频轨和主轨一列：轨道名、自动化模式下拉、声像/平衡旋钮、静音（M）/独奏（S）/录音（R）按钮、音量推子（dB）、表、输出分配（主轨或子混合轨）；展开后有 5 个效果插槽和 5 个发送。推子改的是**轨道音量**，与剪辑音量相乘。Cmd+L 循环播放（面板作用域）、Ctrl+Shift+I 仅显示输入表（待核含义）、Opt+Cmd+T 显示/隐藏轨道。
- **优先级：** 以后（M4 只做推子、声像、M/S）
- **BAE 模块：** bae-ui-edit (+ bae-media, bae-edit)
- **数据模型：** Track 的 `audio:level`、`audio:pan`、`muted`、`solo`、`audio:output`；轨道效果 `effects/`（带 `pre_fader`）、发送 `sends/`（edit-model.md 第 4 节）。
- **备注：** 混音引擎（08）要先支持"剪辑 → 剪辑效果 → 剪辑音量/声像 → 轨道效果 → 轨道推子/声像 → 主轨"的信号链。

### PR-AUD-008 · 自动化模式（Automation Modes）

- **行为要点：** 音轨混合器每轨的下拉：关（忽略轨道关键帧）、读取（默认，按关键帧播放）、闩锁（拖动推子开始写，松手后保持在最后的值继续写）、触动（松手后回到原有关键帧的值）、写入（播放一开始就从当前值覆盖写）。写入的是轨道关键帧（序列时间）。偏好里有"切换到触动后写入"、"最小时间间隔"等。
- **优先级：** 以后
- **BAE 模块：** bae-ui-edit (+ bae-media, bae-anim)
- **数据模型：** Track `audio:automation_mode`；写入目标是 Track 的 `audio:level`、`audio:pan` 关键帧。
- **备注：** 自动化写入是实时手势，要按批提交命令（例如松手时一次写入整段关键帧），避免每帧一个撤销步骤和每帧一次协同同步。

### PR-AUD-009 · 子混合与发送（Submix / Sends）

- **行为要点：** 子混合轨不能放剪辑，用来汇总几条轨的输出统一处理（例如所有对白轨进一个对白子混合，加压缩器）；发送可以把一条轨的信号按推子前/后送到子混合（常用于共享混响）。
- **优先级：** 以后
- **BAE 模块：** bae-media (+ bae-edit, bae-ui-edit)
- **数据模型：** Track `track_kind = submix`；`audio:output`；`sends/` 下的 Send Prim（`target`、`level`、`pre_fader`）。
- **备注：** M1 只预留 `submix` 枚举值。

### PR-AUD-010 · 音频表（Audio Meters）

- **行为要点：** 音频表面板（通常停靠在时间轴右边）显示主轨输出电平，dBFS 刻度（0 到 −60 或 −∞），峰值保持，超过 0 dB 顶部红灯亮（点击清除）；右键可改显示范围、动态峰值/静态峰值、显示单声道/立体声；下方有独奏按钮（立体声时单独听左或右）。
- **优先级：** M4
- **BAE 模块：** bae-ui-edit (+ bae-media)
- **数据模型：** 无
- **备注：** 表的数值由混音引擎在播放时报告（08）。

### PR-AUD-011 · 应用音频效果（Apply Audio Effects）

- **行为要点：** 把音频效果拖到音频剪辑（剪辑效果）或音轨混合器的效果插槽（轨道效果）；效果控件里显示参数，很多效果有"编辑"按钮打开自定义界面（例如参数均衡器的曲线、多频段压缩器）；每个效果有预设下拉。效果顺序可拖动，音量在最后。
- **优先级：** 以后（M4 先做常用的几个：参数均衡器、强制限幅、动态处理、降噪、室内混响）
- **BAE 模块：** bae-media (+ bae-plugin, bae-ui-edit)
- **数据模型：** 与视频效果相同的 Effect Prim（edit-model.md 第 5.4 节）；轨道效果在 Track 的 `effects/` 下。
- **备注：** 音频效果自定义界面需要插件能画自己的控件，见 ARCHITECTURE 第 15 节"效果控件面板预留自定义绘制区域"。

### PR-AUD-012 · 基本声音：分类与预设（Essential Sound: Clip Types）

- **行为要点：** 基本声音面板里先选剪辑类型：对话、音乐、SFX（音效）、环境；每种类型下有一组预设和对应的处理区块。可以给多个剪辑一次分类；分类之后同类剪辑可以"自动匹配"、互相拷贝设置。Pr 26 起还有自动给剪辑贴类型标签（AI 分类，词典里有"语音/音乐/其他"分类器）。
- **优先级：** 以后
- **BAE 模块：** bae-edit (+ bae-media, bae-ui-edit)
- **数据模型：** Clip 增加 `audio:role`（enum `dialogue | music | sfx | ambience`），各处理区块的设置落在剪辑的音频效果上（基本声音只是这些效果的简化界面）。
- **备注：** "基本声音 = 预配置的效果链 + 简化面板"这个思路很适合 Agent：Agent 只要设 `audio:role` 和几个滑块。

### PR-AUD-013 · 基本声音：响度自动匹配（Loudness Auto-Match）

- **行为要点：** 对话、音乐、SFX、环境都有"响度 > 自动匹配"按钮：分析剪辑的综合响度（LUFS），把剪辑增益调到目标值（对话的目标响度在偏好里设，Pr 默认值待核），显示"已自动匹配到 @ LUFS"。
- **优先级：** 以后
- **BAE 模块：** bae-media (+ bae-edit)
- **数据模型：** 结果写 Clip `audio:gain`；目标值是偏好或序列属性 `audio:loudness_target`（以后）。
- **备注：** 响度测量按 ITU-R BS.1770，08 实现。

### PR-AUD-014 · 基本声音：修复与增强语音（Repair / Enhance Speech）

- **行为要点：** 对话类型的"修复"区块：减少杂色、降低隆隆声、消除嗡嗡声（50/60 Hz）、消除齿音、减少混响，各有一个强度滑块；"增强语音"（AI）一键提升录音清晰度，可调混合量。Pr 背后对应的是降噪、消除嗡嗡声、消除齿音、减少混响这些音频效果。
- **优先级：** 以后
- **BAE 模块：** bae-media (+ bae-plugin)
- **数据模型：** 无新增，结果是剪辑上的音频效果。
- **备注：** 增强语音依赖机器学习模型，按需下载的插件，不进主安装包（VISION 轻量化原则）。

### PR-AUD-015 · 基本声音：透明度与创意（Clarity / Creative）

- **行为要点：** 对话的"透明度"：动态（压缩）、EQ 预设（如"背景音乐""播客语音"）与强度、增强语音（高音/低音）；"创意"：混响预设与数量；音乐和 SFX 有"立体声宽度"等。
- **优先级：** 以后
- **BAE 模块：** bae-media (+ bae-ui-edit)
- **数据模型：** 无新增。
- **备注：** 无

### PR-AUD-016 · 基本声音：自动回避（Ducking）

- **行为要点：** 音乐剪辑的"回避"：选择回避依据（对话、音乐、SFX、环境、未标记），敏感度、降噪幅度（dB）、淡化持续时间、淡化位置，点"生成关键帧"后在音乐剪辑上生成音量关键帧，在有对白的地方自动压低。
- **优先级：** 以后
- **BAE 模块：** bae-edit (+ bae-media)
- **数据模型：** 无新增，结果是 Clip `audio:level` 关键帧。
- **备注：** 这类"分析后生成关键帧"的功能天然适合 Agent，`bae-edit` 提供命令，分析由 08 做。

### PR-AUD-017 · 基本声音：重新混合（Remix）

- **行为要点：** 音乐剪辑的"持续时间 > 重新混合"：设定目标时长后，Pr 分析音乐结构，在节拍合适的地方切开重组，使音乐刚好结束在目标长度（结果是剪辑上带锯齿标记的多个片段）。
- **优先级：** 以后
- **BAE 模块：** bae-edit (+ bae-media)
- **数据模型：** 无新增：结果是若干剪辑和交叉淡化。
- **备注：** 无

### PR-AUD-018 · 响度计与响度标准化（Loudness Meter / Loudness Normalization）

- **行为要点：** "响度计"效果（Pr 25 起）和较早的"响度探测计"插在主轨上实时测量瞬时、短期、综合响度和真峰值；导出设置的"效果 > 响度标准化"按 ITU BS.1770 把整条节目标准化到目标（如 −23 LUFS / −24 LKFS / −16 LUFS），可设真峰值上限。
- **优先级：** 以后（导出时的响度标准化 M4）
- **BAE 模块：** bae-media (+ bae-ui-edit)
- **数据模型：** 导出设置里的选项，不进序列。
- **备注：** 导出响度标准化需要两遍处理（先测再调），08 的渲染队列要支持。

### PR-AUD-019 · 淡入淡出与交叉淡化（Fades / Crossfades）

- **行为要点：** 在两个音频剪辑之间加交叉淡化（默认恒定功率，Shift+Cmd+D）；在剪辑开头/结尾加单侧过渡就是淡入/淡出；在剪辑头尾拖音量关键帧也能淡入淡出。J/L 剪切（音频比画面早进或晚出）配合交叉淡化是对白剪辑的基本手法（PR-TL-018）。
- **优先级：** M4
- **BAE 模块：** bae-edit (+ bae-media)
- **数据模型：** 音频剪辑的 `transition_in` / `transition_out`（edit-model.md 第 6 节），种类 `bae.constant_power`、`bae.constant_gain`、`bae.exponential_fade`。
- **备注：** 音频过渡的曲线见 effects-transitions.md 附录 C。

### PR-AUD-020 · 音频时间单位（Show Audio Time Units）

- **行为要点：** 时间轴面板菜单"显示音频时间单位"后，时间标尺按音频采样（或毫秒）显示，音频剪辑可以在帧内移动和修剪（精确到采样），用于修掉咔嗒声、对齐。视频剪辑仍按帧。
- **优先级：** 以后（M1 保证时间表示能做到采样精度）
- **BAE 模块：** bae-ui-edit (+ bae-edit)
- **数据模型：** 无新增：flicks 能整除 44.1/48/96 kHz 的采样间隔（edit-model.md 第 1 节原则 3）；音频剪辑的 `start` / `source_in` 允许不在帧边界上。
- **备注：** 命令的帧吸附规则要区分视频和音频剪辑；链接剪辑一起移动时以视频为准对齐帧。

### PR-AUD-021 · 画外音录制（Voice-over Record）

- **行为要点：** 音频轨道头的麦克风按钮（需在轨道头设置里打开）：点击后倒数，从播放头开始录音到该轨道，录完生成一个音频文件和剪辑；输入设备、倒数、预卷在"画外音录制设置"里设。
- **优先级：** 以后
- **BAE 模块：** bae-media (+ bae-ui-edit, bae-edit)
- **数据模型：** 无新增：录音结果是新的 Asset 和 Clip。
- **备注：** 需要 08 的音频输入。

### PR-AUD-022 · 音频预读与缓存（Audio Peak Files / Conformed Audio）

- **行为要点：** Pr 导入素材后生成峰值文件（.pek，波形用）和"符合"音频（.cfa，把压缩音频解成便于随机访问的格式）到媒体缓存目录；生成期间波形不显示、播放可能不流畅。偏好 > 媒体缓存可以清理。
- **优先级：** M4
- **BAE 模块：** bae-media
- **数据模型：** 无，缓存在工程 `cache/` 或全局缓存目录。
- **备注：** 08 的 `FileAudio` 已支持按采样帧随机读取，可能不需要单独的"符合"缓存；峰值缓存需要。

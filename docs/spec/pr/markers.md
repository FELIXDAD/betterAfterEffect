# Pr 清单：标记（PR-MRK）

## 范围

序列标记、剪辑标记、标记对话框、标记类型和颜色、范围标记、标记面板、波纹序列标记、导出标记、按标记自动生成序列。数据模型见 edit-model.md 第 7 节（复用 schema 里已有的 `Marker`）。

### PR-MRK-001 · 添加标记（Add Marker）

- **行为要点：** M 在播放头处添加标记：时间轴获得焦点且没有选中剪辑时加序列标记；在源监视器、或时间轴上选中了剪辑时加剪辑标记（待核：Pr 在时间轴选中剪辑后按 M 是否加剪辑标记）。播放时按 M 可以边听边打点（打节拍）。时间轴和监视器的标记按钮同样效果。
- **优先级：** M1 — #66 的 `sequence.add_marker` 已有序列标记。
- **BAE 模块：** bae-edit (+ bae-ui-edit)
- **数据模型：** 序列标记 `/sequences/<seq>/markers/<m>`（序列时间）；剪辑标记在来源的 `markers/` 下（源时间）（edit-model.md 第 7 节）。
- **备注：** 播放时打点要求命令足够快、不打断播放（每次一个撤销步骤也可以，Pr 就是这样）。

### PR-MRK-002 · 编辑标记（Marker Dialog）

- **行为要点：** 双击标记，或在已有标记处再按一次 M，打开标记对话框：名称、持续时间、注释、颜色、类型（注释 / 章节 / 分段 / Web 链接 / Flash 提示点）及类型相关字段（URL、帧目标、提示点名称和参数）；"上一个""下一个"按钮在对话框里切换标记；"删除"按钮。
- **优先级：** M4
- **BAE 模块：** bae-ui-edit (+ bae-edit)
- **数据模型：** Marker 的 `name`、`duration`、`comment`、`label`、`marker:type`、`url`、`frame_target`、`cue_point_name`（edit-model.md 第 7 节；`name` 和 `marker:type` 是新增）。
- **备注：** 无

### PR-MRK-003 · 标记类型（Marker Types）

- **行为要点：** 注释（默认，只做备忘）、章节（导出 H.264/MP4、DVD 时写成章节点）、分段（广播交付里标出节目分段）、Web 链接（带 URL，播放到该点时可打开网页，部分播放器支持）、Flash 提示点（导出 FLV 时的事件/导航提示点，已基本过时）。
- **优先级：** M4（注释、章节）；以后（其余）
- **BAE 模块：** bae-edit (+ bae-media)
- **数据模型：** Marker `marker:type`。
- **备注：** 章节标记写进导出文件需要 08 的编码器支持（MP4 章节轨）。

### PR-MRK-004 · 标记颜色（Marker Colors）

- **行为要点：** 8 种颜色：绿（默认）、红、紫、橙、黄、白、蓝、青；标记对话框或右键标记改色；偏好里可以改每种颜色的显示值和名称（待核）；标记面板可以按颜色过滤。颜色常被团队约定成含义（例如红 = 待修改）。
- **优先级：** M4
- **BAE 模块：** bae-ui-edit (+ bae-edit)
- **数据模型：** Marker `label` 存颜色序号（0 = 绿，依次红、紫、橙、黄、白、蓝、青，edit-model.md 第 7 节）。
- **备注：** AE 的标记颜色用的是 16 色标签，Pr 的是这 8 色；同一个 `label` 属性在两种工作区按各自色表解释，导出 AE / Pr 时各自换算。

### PR-MRK-005 · 范围标记（Duration Markers）

- **行为要点：** 标记可以有持续时间：在标记对话框里设，或按住 Opt 拖动标记的右半边拉出长度；Ctrl+M 按当前入出点创建范围标记，Ctrl+Shift+M 创建范围标记（待核：后者长度如何确定）。范围标记在时间标尺上显示为一段色块。
- **优先级：** M4
- **BAE 模块：** bae-edit (+ bae-ui-edit)
- **数据模型：** Marker `duration`（已有）。
- **备注：** 范围标记常被用作"这一段要改"的审阅批注，和 BAE 审阅工作区的批注可以互通。

### PR-MRK-006 · 标记导航与清除（Go to / Clear Markers）

- **行为要点：** Shift+M 跳到下一个标记，Shift+Cmd+M 跳到上一个；Opt+M 清除播放头处的标记，Opt+Cmd+M 清除所有标记（作用于当前面板：时间轴是序列标记，源监视器是剪辑标记）。
- **优先级：** M4
- **BAE 模块：** bae-edit (+ bae-ui-edit)
- **数据模型：** 无
- **备注：** 无

### PR-MRK-007 · 标记面板（Markers Panel）

- **行为要点：** 列出当前序列（或源监视器里的剪辑）的所有标记：缩略图、名称、入点、出点、持续时间、注释；可以直接改名称和注释、按颜色过滤、搜索；点击跳转播放头；"显示所有序列标记"/"显示所有剪辑标记"切换（待核）。
- **优先级：** 以后
- **BAE 模块：** bae-ui-edit (+ bae-edit)
- **数据模型：** 无
- **备注：** 标记面板也是 Agent 留言（"第 32 秒这里节奏太慢"）的好落点。

### PR-MRK-008 · 剪辑标记（Clip Markers）

- **行为要点：** 剪辑标记属于主剪辑（来源）：在源监视器里打的标记，放进序列后显示在时间轴的剪辑上（剪辑内的小标记），所有使用这个来源的剪辑都显示；在时间轴上加的剪辑标记同样写回主剪辑。剪辑标记的时间跟着源媒体，修剪、外滑时随内容移动。
- **优先级：** M4
- **BAE 模块：** bae-edit (+ bae-ui-edit)
- **数据模型：** 来源 Asset（或 Comp、Sequence）下的 `markers/`，时间是源时间（edit-model.md 第 7 节）。
- **备注：** 动效合成作为来源时，合成自己的合成标记就是剪辑标记——动效那边打的节点在剪辑里直接可见，反之亦然。

### PR-MRK-009 · 波纹序列标记（Ripple Sequence Markers）

- **行为要点：** 标记菜单里的"波纹序列标记"开关：打开时插入、提取、波纹删除、波纹修剪会把受影响位置之后的序列标记一起移动；关闭时序列标记留在原来的时间。
- **优先级：** M4（M1 命令参数预留 `ripple_markers`）
- **BAE 模块：** bae-edit
- **数据模型：** 无新增；开关是用户偏好，命令参数显式传入（edit-model.md 第 7 节）。
- **备注：** 无

### PR-MRK-010 · 导出标记（Export Markers）

- **行为要点：** "文件 > 导出 > 标记"把序列标记导出为 CSV 或 HTML（HTML 带缩略图），可选字段；章节标记在导出 MP4 时写入文件。
- **优先级：** 以后
- **BAE 模块：** bae-interop-edit (+ bae-media)
- **数据模型：** 无
- **备注：** Agent 和外部审阅工具读 CSV 很方便；BAE 的 `bae export-json` 已能导出所有标记数据。

### PR-MRK-011 · 自动匹配序列（Automate to Sequence）

- **行为要点：** 在项目面板选中一组素材，"剪辑 > 自动匹配序列"：排序方式（按选择顺序 / 按素材箱排序）、放置方式（按顺序 / 在未编号的标记处）、方法（插入 / 覆盖）、剪辑重叠（用于过渡的帧数）、静止剪辑持续时间、是否应用默认音频/视频过渡、忽略音频/视频。常用于把一组照片按音乐节拍的标记铺进序列。
- **优先级：** 以后
- **BAE 模块：** bae-edit
- **数据模型：** 无新增。
- **备注：** 适合做成一个命令给 Agent 用（"把这些镜头按标记铺好"）。

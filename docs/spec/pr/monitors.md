# Pr 清单：源监视器与节目监视器（PR-MON）

## 范围

源监视器、节目监视器、入出点、三点和四点编辑、J/K/L 穿梭与播放控制、匹配帧、回放分辨率、显示选项、比较视图和修剪监视器。快捷键均已对照 Pr 26.2 的默认键位文件（macOS），完整表见 [shortcuts.md](shortcuts.md)。

两个监视器的画面都由 `bae-render` 渲染到与界面共用设备的纹理上（零拷贝，04 的视口输出），播放时钟和音频由 `bae-media` 提供。监视器面板本身只负责显示、交互和调用命令。

## 监视器与播放

### PR-MON-001 · 源监视器（Source Monitor）

- **行为要点：** 显示单个来源（素材、子剪辑、序列、动效合成）。双击项目面板里的项目项、或在项目面板按 Shift+O 加载；标题栏下拉菜单列出最近加载过的来源，可切换或关闭；Shift+2 聚焦源监视器。音频素材显示波形。源监视器打的入出点存在来源上，下次加载还在。
- **优先级：** M1 — 骨架界面要能加载素材、播放、打入出点。
- **BAE 模块：** bae-ui-edit (+ bae-render, bae-media)
- **数据模型：** 入出点写来源的 `mark_in` / `mark_out`（#66 已用这两个属性名，edit-model.md 第 13 节第 9 条）。最近来源列表是视图状态。
- **备注：** 来源是动效合成时，源监视器实时显示合成最新内容（和动效工作区的合成查看器同一个渲染结果），这是 BAE 取代"动态链接"的关键体验之一。

### PR-MON-002 · 节目监视器（Program Monitor）

- **行为要点：** 显示当前活动序列在播放头处的画面，跟随时间轴面板的当前标签切换；Shift+4 聚焦。播放头和时间轴同步；在节目监视器里可以直接选中、拖动、缩放画面里的剪辑（运动属性的直接操作），也可以用文字工具直接创建图形。
- **优先级：** M1 — 骨架界面要能显示序列画面并播放。
- **BAE 模块：** bae-ui-edit (+ bae-render, bae-edit)
- **数据模型：** 无。画面来自 `bae-edit` 的序列求值（edit-model.md 第 10 节）+ `bae-render`。
- **备注：** 在画面里直接拖动剪辑改 `transform:position` 等属性是 M4；M1 只需要显示。

### PR-MON-003 · 时间码显示与跳转（Timecode Display / Go to Time）

- **行为要点：** 左下角是播放头时间码，右下角是入出点之间的持续时间（没有入出点时是整个序列/来源长度）。点击时间码可以直接输入跳转；输入 `+10` / `-10` 表示相对当前位置前进/后退 10 帧，`+1.00` 这类可以带秒；时间轴面板获得焦点时直接敲数字也会进入跳转。时间码可以在帧、时间码、英尺+帧之间切换（Cmd 点击时间码循环）。
- **优先级：** M4
- **BAE 模块：** bae-ui-edit (+ bae-ui)
- **数据模型：** 无
- **备注：** 11 已有时间码控件，需要补"相对输入"和"敲数字直接跳转"。显示格式跟随序列的 `timecode_display` 和 `start_timecode`（edit-model.md 第 3 节）。

### PR-MON-004 · 播放与停止（Play / Stop Toggle）

- **行为要点：** 空格播放/停止；Ctrl+Space 从播放头播放到出点；Opt+K 从入点播放到出点；Shift+Space 带预卷/过卷从入点播放到出点；Shift+K "播放邻近区域"（以播放头为中心前后各播一段，预卷/过卷长度在偏好 > 回放里设，默认 2 秒）。停止时播放头停在停止的位置（偏好"停止时返回初始状态"可改，待核）。循环播放按钮打开后在入出点之间或整个序列循环。
- **优先级：** M1（空格播放停止、循环）；其余 M4
- **BAE 模块：** bae-ui-edit (+ bae-media, bae-render)
- **数据模型：** 无
- **备注：** 音画同步的播放时钟以音频设备为主时钟，由 08 提供（08 的 cpal 播放、音画同步时钟尚未完成）。

### PR-MON-005 · J/K/L 穿梭（JKL Shuttle）

- **行为要点：** L 正放，再按 L 依次加速（2 倍、3 倍、4 倍……，具体档位待核）；J 倒放，同样逐次加速；K 停止。按住 K 再按 L / J：慢速正放 / 倒放；按住 K 点按 L / J：前进 / 后退一帧。Shift+L / Shift+J 慢速往复（每按一次慢一档，待核）。倒放和快速穿梭时音频跟着变速播放（带音高变化），倍速高时只播放片段。J/K/L 在源监视器、节目监视器、时间轴、素材箱缩略图里都有效（作用于获得焦点的那个）。
- **优先级：** M4（M1 先做 J/K/L 的 1 倍正反放和停止）
- **BAE 模块：** bae-ui-edit (+ bae-media)
- **数据模型：** 无
- **备注：** 倒放和多倍速需要解码端支持往回读、跳帧解码（长 GOP 素材倒放要按 GOP 缓存），这是 08 的请求之一。代理（PR-EXP-001）能大幅减轻这里的压力。

### PR-MON-006 · 逐帧与跳转（Step / Go to Edit / Home·End）

- **行为要点：** ←/→ 后退/前进一帧，Shift+←/→ 五帧；Home/End 到序列（来源）开头/结尾；Shift+Home/End 到选中剪辑的开头/结尾；↑/↓ 跳到目标轨道上的上一个/下一个编辑点，Shift+↑/↓ 跳到所有轨道上的编辑点；Shift+I / Shift+O 跳到入点/出点；Shift+M / Shift+Cmd+M 下一个/上一个标记。
- **优先级：** M1（←/→、Home/End、↑/↓）；其余 M4
- **BAE 模块：** bae-ui-edit (+ bae-edit)
- **数据模型：** 无。"下一个编辑点"由 `bae-edit::query` 按目标轨道计算。
- **备注：** Shift+←/→ 的五帧是固定值；修剪时的大幅偏移是另一项偏好（偏好 > 修剪 > 大修剪偏移，默认 5 帧，待核），两者独立。

## 入出点与三点、四点编辑

### PR-MON-007 · 入点和出点（Mark In / Mark Out）

- **行为要点：** I / O 在播放头处设入点/出点；Opt+I / Opt+O / Opt+X 清除入点 / 出点 / 两者；入出点之间在监视器时间标尺上高亮，时间轴上显示为亮色区域。序列的入出点决定插入/覆盖的落点、提升/提取的范围、"渲染入点到出点"和导出的范围。在时间轴里可以拖动入出点的边界。
- **优先级：** M1 — #66 的 `marks.set` 已实现。
- **BAE 模块：** bae-edit (+ bae-ui-edit)
- **数据模型：** 序列和来源的 `mark_in` / `mark_out`（time，出点不含，edit-model.md 第 3 节）。
- **备注：** Pr 把这些标记存在项目里。多人同时剪同一条序列时入出点会互相干扰，M2 协同时再决定是否把它们放进个人工程层（edit-model.md 第 12 节）。

### PR-MON-008 · 标记剪辑与标记选择项（Mark Clip / Mark Selection）

- **行为要点：** X：以播放头下、目标轨道上的剪辑为范围设置序列入出点；/：以当前选中的剪辑（可以多个）的总范围设置入出点。常和 ;（提升）、'（提取）连用：X 然后 ' 等于删掉这个剪辑并合拢。
- **优先级：** M4
- **BAE 模块：** bae-edit (+ bae-ui-edit)
- **数据模型：** 无
- **备注：** 命令只是计算范围后调用 `marks.set`，范围计算放在 `bae-edit::query`。

### PR-MON-009 · 三点编辑（Three-Point Editing）

- **行为要点：** 源入点、源出点、序列入点、序列出点这四个点里给出任意三个，第四个自动推算。常见用法：源监视器打入出点 + 序列里的播放头或入点 → 按 ,（插入）或 .（覆盖）。规则：没有序列入出点时用播放头作为序列入点；只给了序列出点时向前倒推（"后退编辑"）；源没有入出点时用整段来源。剪辑放到哪些轨道由源修补决定（PR-TL-015）。
- **优先级：** M1 — #66 的 `clip.insert` / `clip.overwrite` 已按三点编辑实现（`resolve_three_point`）。
- **BAE 模块：** bae-edit (+ bae-ui-edit)
- **数据模型：** 无新增；命令参数显式给出四个点中的若干个和源修补（edit-model.md 第 11 节）。
- **备注：** 命令输出要返回最终使用的四个点，界面据此显示结果、Agent 据此确认。

### PR-MON-010 · 四点编辑与"适合剪辑"（Four-Point Editing / Fit Clip）

- **行为要点：** 四个点都给出且源时长和序列时长不一致时，弹出"适合剪辑"对话框：更改剪辑速度（适合填充）、忽略源入点、忽略源出点、忽略序列入点、忽略序列出点，可勾选"始终使用此选项"（偏好里有"重置适合剪辑对话框"）。时长一致时直接执行。"更改剪辑速度"会给剪辑设置恒定速度。
- **优先级：** M4
- **BAE 模块：** bae-edit (+ bae-ui-edit)
- **数据模型：** 无新增，结果写 Clip 的 `speed`。
- **备注：** 命令参数 `fit: change_speed | ignore_source_in | ignore_source_out | ignore_sequence_in | ignore_sequence_out`，缺省且时长不一致时报错（Agent 不能弹框）。

### PR-MON-011 · 从监视器插入和覆盖（Insert / Overwrite Buttons）

- **行为要点：** 源监视器下方的"插入"和"覆盖"按钮等同 , 和 .；把源监视器画面拖到时间轴上按放下的位置和轨道放置（拖动时按住 Cmd 变插入）；源监视器底部的"仅拖动视频"（胶片图标）和"仅拖动音频"（波形图标）只带一种轨道。拖到节目监视器上会出现编辑方式的叠加层（插入、覆盖、叠加、替换等，按住 Cmd 显示），具体选项待核。
- **优先级：** M4（M1 先做按钮和快捷键）
- **BAE 模块：** bae-ui-edit (+ bae-edit)
- **数据模型：** 无
- **备注：** 拖放和按钮最终都调用同一个 `clip.insert` / `clip.overwrite`，区别只是参数由谁填。

### PR-MON-012 · 提升与提取按钮（Lift / Extract）

- **行为要点：** 节目监视器下方的"提升"（;）删除序列入出点之间、目标轨道上的内容并留下空隙；"提取"（'）删除后把后面的内容前移合拢（遵守同步锁定）。没有入出点时按钮不可用。
- **优先级：** M1 — #66 的 `clip.lift` 已有；提取 = 按范围的波纹删除。
- **BAE 模块：** bae-edit (+ bae-ui-edit)
- **数据模型：** 无
- **备注：** 提升/提取作用于"目标轨道"（PR-TL-014），不是源修补。命令参数显式给出目标轨道。

### PR-MON-013 · 匹配帧与反向匹配帧（Match Frame / Reverse Match Frame）

- **行为要点：** F：把播放头下、目标轨道最上面的剪辑的来源加载到源监视器，定位到同一帧，并把源入出点设成该剪辑用到的范围（偏好可改，待核）。Shift+R：反过来，从源监视器当前帧找到它在当前序列里被用到的位置并移动播放头。
- **优先级：** M4
- **BAE 模块：** bae-edit (+ bae-ui-edit)
- **数据模型：** 无。源时间换算见 edit-model.md 第 5.1 节。
- **备注：** 来源是动效合成时，匹配帧打开的是合成；"在动效工作区中打开"见 PR-XCH-008。

## 显示

### PR-MON-014 · 回放分辨率与暂停分辨率（Playback / Paused Resolution）

- **行为要点：** 监视器下方的下拉框：完整、1/2、1/4、1/8、1/16（可选档位取决于序列帧大小）；"暂停分辨率"单独设置停下时的画质；"高品质回放"开关让播放时不降低静帧和矢量的画质。降分辨率时画面变糊但播放更流畅。
- **优先级：** M4
- **BAE 模块：** bae-ui-edit (+ bae-render)
- **数据模型：** 无，视图状态。
- **备注：** 对应 04 的预览分辨率降级（完整、1/2、1/3、1/4、自动）。BAE 的目标是 4K 素材在完整分辨率下也能实时播放（VISION 验收），降级只是兜底。

### PR-MON-015 · 缩放级别（Zoom Level）

- **行为要点：** 下拉框：适合、10%、25%、50%、75%、100%、150%、200%、400%；Shift+Cmd+0 / Shift+Cmd+1 节目监视器适合 / 100%，Opt+Shift+Cmd+0 / 1 是源监视器的。放大后用手形工具（H）或滚动条平移。
- **优先级：** M4（M1 只要"适合"）
- **BAE 模块：** bae-ui-edit
- **数据模型：** 无
- **备注：** 和动效工作区合成查看器的缩放交互保持一致。

### PR-MON-016 · 安全边距、参考线和标尺（Safe Margins / Guides / Rulers）

- **行为要点：** 扳手菜单 > 安全边距：显示动作安全（默认 90%）和字幕安全（默认 80%）框，比例在项目设置里改；节目监视器获得焦点时 Cmd+R 显示标尺、Cmd+; 显示参考线、Shift+Cmd+; 对齐参考线，可以从标尺拖出参考线，参考线可以存成模板。
- **优先级：** M4
- **BAE 模块：** bae-ui-edit (+ bae-ui)
- **数据模型：** 安全区域百分比在 Project 的 `safe:action` / `safe:title`（PR-PRJ-004）；参考线位置是视图状态。
- **备注：** 和动效工作区合成查看器共用叠加层绘制代码。

### PR-MON-017 · 显示模式（Composite Video / Alpha / Scopes）

- **行为要点：** 扳手菜单：合成视频（默认）、Alpha（灰度显示透明度）、所有示波器、矢量示波器、YC 波形、YCbCr 分量、RGB 分量，以及"多机位"和"比较视图"；"透明网格"用棋盘格显示透明区域。
- **优先级：** M4
- **BAE 模块：** bae-ui-edit (+ bae-render, bae-color)
- **数据模型：** 无
- **备注：** 示波器由 Lumetri 范围面板提供（PR-CLR-008），监视器里的示波器模式复用同一套计算。

### PR-MON-018 · 比较视图（Comparison View）

- **行为要点：** 节目监视器按钮打开：左边参考帧、右边当前帧；布局可选并排、垂直拆分、水平拆分（拆分时可拖动分界线）；参考帧可以选同一序列的其他时间点、其他序列的帧，或"镜头/帧比较"（同一剪辑应用效果前后）。主要用于调色时对比镜头。
- **优先级：** 以后
- **BAE 模块：** bae-ui-edit (+ bae-render)
- **数据模型：** 无
- **备注：** BAE 的审阅工作区本来就要做版本对比，可以共用实现。

### PR-MON-019 · 修剪监视器（Trim Mode in Program Monitor）

- **行为要点：** 进入修剪模式（双击编辑点、或选中编辑点后 Shift+T，待核）时节目监视器分成两半：左边是出点那一侧剪辑的最后一帧，右边是入点那一侧剪辑的第一帧，下方有 −5、−1、+1、+5 帧按钮和"应用默认过渡"按钮；在左/右画面上拖动分别修剪出点/入点，在中间拖动是滚动修剪。修剪模式下 J/K/L 是"动态修剪"：边播放边修剪，按 K 停下时修剪生效。
- **优先级：** M4
- **BAE 模块：** bae-ui-edit (+ bae-edit)
- **数据模型：** 无
- **备注：** 修剪逻辑见 PR-TL-018 至 PR-TL-021；动态修剪依赖播放时钟和 `plan_*` 预演（edit-model.md 第 11 节）。

### PR-MON-020 · 按钮编辑器（Button Editor）

- **行为要点：** 两个监视器右下角的"+"打开按钮编辑器，可以把常用命令（循环、安全边距、导出帧、多机位录制开关、比较视图、切换代理……）拖到按钮栏，或者从按钮栏拖走。偏好里可以隐藏所有按钮。
- **优先级：** 以后
- **BAE 模块：** bae-ui-edit (+ bae-ui)
- **数据模型：** 无，按钮配置随工作区保存。
- **备注：** 按钮只是命令 ID 的列表，外壳的命令解析可以直接复用。

### PR-MON-021 · 音频擦洗与音频波形显示（Audio Scrubbing / Waveform in Source）

- **行为要点：** 拖动播放头时播放对应的声音片段（Shift+S 开关"音频擦洗"）；源监视器加载纯音频时显示放大的波形，可以在波形上直接打入出点；加载视频时扳手菜单可切换"音频波形"显示。
- **优先级：** M4
- **BAE 模块：** bae-ui-edit (+ bae-media)
- **数据模型：** 无
- **备注：** 波形数据来自 08 的 `Waveform`（已有 min/max 峰值和缩放级别）。

### PR-MON-022 · 在源监视器中打开序列（Open Sequence in Source Monitor）

- **行为要点：** 右键项目面板里的序列"在源监视器中打开"，可以像素材一样打入出点并把序列的一段插入到另一条序列里；时间轴面板的"将序列作为嵌套或个别剪辑插入并覆盖"开关决定插进去的是一个嵌套剪辑还是展开后的原始剪辑。
- **优先级：** M4
- **BAE 模块：** bae-edit (+ bae-ui-edit)
- **数据模型：** 无新增：嵌套时片段 `source` 指向序列；展开时复制原始片段。
- **备注：** 展开插入（"个别剪辑"）需要把被引用序列在入出点范围内的片段、过渡、效果整体复制并平移，命令里按轨道映射处理。

# Pr 清单：调色（PR-CLR）

## 范围

Lumetri 颜色效果和面板（基本校正、创意、曲线、色轮和匹配、HSL 辅助、晕影）、Lumetri 范围、色彩管理、Pr 26 的颜色模式。

**BAE 的做法：** Lumetri 颜色是一个效果（matchName `AE.ADBE Lumetri`），面板只是它的参数界面，一个剪辑可以有多个实例。BAE 实现一个对应的内置效果（暂称 `bae.lumetri`，参数按 Pr 的分区组织），GPU 实现由 06 `bae-color` 提供色彩数学、07 `bae-effects` 注册成效果；面板由 `bae-ui-edit` 实现，动效工作区也可以用同一个效果和面板。调色整体是 M4 之后的增强，M4 只需要基本校正、创意 Look（LUT）、曲线里的 RGB 曲线和 Lumetri 范围的波形、矢量示波器。

### PR-CLR-001 · Lumetri 颜色（Lumetri Color）

- **行为要点：** Lumetri 颜色面板显示选中剪辑上的 Lumetri 颜色效果（没有就在第一次调整时自动加一个），顶部下拉选择编辑哪个实例或"添加 Lumetri 颜色效果"；各分区有开关（勾选框）可以单独旁路；参数改动实时反映在节目监视器。效果控件里也能看到同一组参数。常见做法是放在调整图层上统一调色。
- **优先级：** M4（基本校正 + 创意 Look）
- **BAE 模块：** bae-effects (+ bae-color, bae-ui-edit)
- **数据模型：** 普通 Effect Prim，参数是 `param:NNNN`；Pr 的 Lumetri 参数序号作为 `param` 编号，导入导出时直接对应（与 AE 效果参数的约定一致，data-model.md 第 11 节）。曲线、色轮这类复合参数用 `float_list` 或 `bytes`。
- **备注：** Lumetri 参数很多（上百个），参数 ID 要一次定好，以后加参数只追加不改号。

### PR-CLR-002 · 基本校正（Basic Correction）

- **行为要点：** 输入 LUT（选 .cube 等，把 Log 素材转到显示空间；Pr 25 起更推荐在色彩管理里设）；颜色：白平衡吸管、色温、色彩、饱和度；灯光：曝光、对比度、高光、阴影、白色、黑色；"自动"按钮自动调色调，"重置"恢复。数值范围对称（色温、色彩 −100…100 这类），双击滑块复位。
- **优先级：** M4
- **BAE 模块：** bae-color (+ bae-effects, bae-ui-edit)
- **数据模型：** 同 PR-CLR-001；输入 LUT 是 `asset_ref` 参数（引用工程里的 LUT 文件，随打包带走）。
- **备注：** 色温/色彩的数学要与 Pr 一致才能导入调色（结果对不上），先以"手感相近"为目标，导入 Pr 工程时的视觉一致性以后再追。

### PR-CLR-003 · 创意（Creative）

- **行为要点：** Look：选择内置或自定义 LUT（Pr 自带一组 Look，带缩略图预览），强度滑块；调整：淡化胶片、锐化、自然饱和度、饱和度；阴影色彩、高光色彩两个色轮；色彩平衡（阴影/高光之间的偏向）。
- **优先级：** M4（Look + 强度）；以后（其余）
- **BAE 模块：** bae-color (+ bae-effects, bae-ui-edit)
- **数据模型：** 同 PR-CLR-001。
- **备注：** 不复制 Adobe 自带的 Look 文件；BAE 自带少量自制 LUT，或按需下载（VISION 轻量化）。

### PR-CLR-004 · 曲线（Curves）

- **行为要点：** RGB 曲线：主曲线（白）、红、绿、蓝，点击加控制点、拖出曲线区删除点、双击复位；"色相饱和度曲线"：色相与饱和度、色相与色相、色相与亮度、亮度与饱和度、饱和度与饱和度，每条曲线有吸管在画面上取色自动加三个控制点。
- **优先级：** M4（RGB 曲线）；以后（色相饱和度曲线）
- **BAE 模块：** bae-color (+ bae-ui-edit)
- **数据模型：** 曲线控制点存成 `float_list`（x0,y0,x1,y1…），可做关键帧（Pr 的曲线可以加关键帧，待核）。
- **备注：** 曲线界面控件可以和 AE 的"曲线"效果共用。

### PR-CLR-005 · 色轮和匹配（Color Wheels & Match）

- **行为要点：** 三向色轮：阴影、中间调、高光各一个色轮加一个亮度滑块（色轮中心双击复位）；颜色匹配：打开比较视图（PR-MON-018），选参考帧，点"应用匹配"自动调色使当前镜头接近参考镜头，可选"人脸检测"优先匹配肤色。
- **优先级：** 以后
- **BAE 模块：** bae-color (+ bae-ui-edit)
- **数据模型：** 同 PR-CLR-001。
- **备注：** 颜色匹配适合做成 Agent 能力（看两帧画面后调参数）。

### PR-CLR-006 · HSL 辅助（HSL Secondary）

- **行为要点：** 键：设置颜色吸管（加/减吸管扩展、收缩选区）、色相/饱和度/亮度三个范围滑块（可调柔和度）、"彩色/灰色"、"彩色/黑色"、"白色/黑色"显示蒙版；优化：降噪、模糊（柔化选区）；更正：单个或三向色轮、色温、色彩、对比度、锐化、饱和度。用于只调某种颜色（例如肤色、天空）。
- **优先级：** 以后
- **BAE 模块：** bae-color (+ bae-ui-edit)
- **数据模型：** 同 PR-CLR-001。
- **备注：** 与效果级蒙版（PR-FX-006）组合是局部调色的主要手段。

### PR-CLR-007 · 晕影（Vignette）

- **行为要点：** 数量（负值变暗、正值变亮）、中点、圆度、羽化。作用在剪辑画面范围上。
- **优先级：** 以后
- **BAE 模块：** bae-color (+ bae-effects)
- **数据模型：** 同 PR-CLR-001。
- **备注：** Pr 26 另有 Film Impact 的"晕影"效果（附录 A.1），两者参数不同。

### PR-CLR-008 · Lumetri 范围（Lumetri Scopes）

- **行为要点：** 面板里可以同时显示多种示波器（右键选择）：矢量示波器（YUV / HLS）、直方图、分量（RGB / YUV / RGB 白色）、波形（RGB、亮度、YC、YC 无色度）；刻度可选 8 位、浮点、HDR（nits）；可调亮度；色彩空间（Rec.709、Rec.2020、Rec.2100 PQ / HLG）。示波器显示的是节目监视器当前帧（或源监视器）。
- **优先级：** M4（波形、矢量示波器）；以后（其余）
- **BAE 模块：** bae-color (+ bae-render, bae-ui-edit)
- **数据模型：** 无
- **备注：** 示波器在 GPU 上用 compute 统计（不回读整帧），与 06 的显示变换一起做。动效工作区也需要（AE 有 Lumetri 范围）。

### PR-CLR-009 · 色彩管理（Color Management）

- **行为要点：** Pr 25 起的色彩管理：项目/序列工作色彩空间（Rec.709、Rec.2100 PQ/HLG、宽色域线性等）、"自动检测 Log 视频色彩空间"、媒体的输入色彩空间覆盖（解释素材）、"自动色调映射"（把 HDR/Log 素材映射到 SDR 序列）、显示色彩管理（按显示器配置文件显示）、HDR 图形白色（nits）。导出时按序列色彩空间写标签。
- **优先级：** M4
- **BAE 模块：** bae-color (+ bae-model, bae-media)
- **数据模型：** Sequence `color:working_space`（空 = 跟工程），Asset 的 `color_space` 已有（edit-model.md 第 3 节）。
- **备注：** BAE 的色彩管理（06）本来就按工作空间设计，剪辑只需要"序列可以有自己的工作空间"。默认值要能让 Pr 用户的 Rec.709 工作流"打开即对"。

### PR-CLR-010 · 颜色模式与颜色控件（Color Mode / Color Controls）

- **行为要点：** Pr 26 新增"颜色"模式（Opt+3），有自己的工作区和一套快捷键：在颜色控件面板里用快捷键激活曝光、对比度、色温、饱和度、平衡、纹理、锐度、色相偏移/亮度偏移/饱和度偏移，以及按亮度区域（最暗、较暗、阴影、高光、较亮、最亮、全局）调整；可以添加"调整""样式调整"，提取画面里的主要色相、采样色相，调整时屏幕上出现实时信息小窗（HUD）。这是 Pr 26 的新功能，具体行为待核。
- **优先级：** 以后
- **BAE 模块：** bae-ui-edit (+ bae-color)
- **数据模型：** 无新增（调整落在 Lumetri 或新的颜色效果参数上，待核）。
- **备注：** 命令名来自 Pr 26.2 默认键位文件里颜色模式的 `cmd.colortools.*` 条目。BAE 不必追这个新界面，先做好 Lumetri 面板。

### PR-CLR-011 · 导出 LUT 与 Lumetri 预设（Export LUT / Lumetri Presets）

- **行为要点：** Lumetri 面板菜单"导出 .cube"/"导出 .look"把当前调色烘焙成 LUT；效果面板的"Lumetri 预设"文件夹提供内置调色预设（电影、单色、技术等），拖到剪辑上应用；用户可以把 Lumetri 设置存成效果预设。
- **优先级：** 以后
- **BAE 模块：** bae-color (+ bae-ui-edit)
- **数据模型：** 无
- **备注：** 导出 .cube 由 06 实现（它已经能读 LUT）。

# Illustrator 功能对照表

负责：16 `interop/ai`。列出 Illustrator 的功能导入 BAE 后变成什么、支持到什么程度。实现见 `crates/bae-interop-ai`，导出脚本见 `bridges/ai/`。

状态：✅ 已支持　◐ 部分支持或近似　✗ 不支持（导入报告里有警告）　… 计划中

进度：表里的状态指「Ai 内容 → BAE 形状图层」的转换（`plan_import`），已经实现并有测试；.ai / PDF 读取和桥接脚本在后续 PR 里接上，接上后在这里补「来源」。

来源：**PDF** = 读 .ai 内嵌的 PDF（不需要 Illustrator）；**桥接** = 在 Illustrator 里运行 `bridges/ai` 的导出脚本；**剪贴板** = 在 Ai 里复制、在 BAE 里粘贴。

## 文档与画板

| Illustrator | BAE | 状态 | 说明 |
|---|---|---|---|
| 画板 | 合成（每个画板一个）+ `Artboard` Prim | ✅ | 合成尺寸按画板向上取整，1 pt = 1 px；`Artboard` Prim 记录名称、尺寸和在文档里的位置，合成的 `ai:artboard` 指向它 |
| 画板名称 | 合成名、`Artboard.name` | … | PDF 里没有画板名，按「画板 N」命名；桥接脚本能拿到真实名称 |
| 文档单位、标尺原点 | — | ✅ | 统一换成画板空间的 pt（= px），原点在画板左上角 |
| 文档颜色模式 CMYK | RGB | … | 按简单公式换算成 RGB，不做色彩管理（06 以后可以接 ICC） |

## 图层与编组

| Illustrator | BAE | 状态 | 说明 |
|---|---|---|---|
| 顶层图层 | 形状图层 | ✅ | 锚点 (0, 0)，位置在合成中心，与 AE「从矢量图层创建形状」一致 |
| 图层可见性 / 锁定 | 视频开关 / 锁定 | ✅ | 也可以选择跳过隐藏内容 |
| 子图层 | 形状组 | … | 与编组同样处理 |
| 编组 | 形状组「组 N」 | ✅ | 有名字时用 Ai 里的名字；编组的不透明度和混合模式放在组上 |
| 剪切组（建立剪切蒙版） | 图层蒙版 | ◐ | 顶层剪切组变成单独的形状图层，剪切路径变成相加蒙版；复合剪切路径的洞不裁掉；嵌套剪切组暂不裁剪 |
| 不透明蒙版 | — | ✗ | 计划用轨道遮罩实现 |
| 编组里的点文字 | 文字图层 | ◐ | 文字不能放进形状图层，提到所在形状图层上方 |

## 路径

| Illustrator | BAE | 状态 | 说明 |
|---|---|---|---|
| 路径（开放、闭合） | 形状组里的「路径 1」 | ✅ | 顶点和切线逐点保留，可以逐点编辑 |
| 复合路径 | 一个形状组里的多条路径 + 一个填充 | ✅ | 填充规则（非零 / 奇偶）保留 |
| 矩形、椭圆、多边形、星形（实时形状） | 自由路径 | ◐ | 导成普通路径；以后可以识别成参数化的矩形 / 椭圆 / 星形 |
| 复合形状（实时路径查找器） | 展开后的路径 | ◐ | 只保留展开后的外观 |

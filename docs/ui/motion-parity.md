## 4. 快捷键（AE 键位，动效工作区）

AE 26 的全部菜单项和默认快捷键命令（669 条，32 个上下文）都登记在 [AE 命令目录](ae-commands.md)，每条对应一个 BAE 动作 id、负责的 agent 和状态。

**覆盖率**：AE 默认快捷键文件 669 条命令，612 条有默认快捷键；**已生效 122 条**（Windows 和 macOS 各 122 条：命令已实现，AE 键位表里按 AE 的默认快捷键绑定，按 AE 的上下文限定面板）。数字由目录生成，见目录的"统计"一节。

- 键位表从目录生成（`catalog::ae_bindings`）：已实现的命令绑定 AE 文件里的全部快捷键（macOS 按 AE 26.2.1 的 Mac 文件，Ctrl→Cmd、Alt→Option 之外的例外照 Mac 文件）。菜单上显示的是 AE 菜单显示的那一个（例如 置于顶层 显示 Cmd+Shift+]，不是 Cmd+Alt+Shift+↑）。
- 没实现的命令不绑定（否则按键会被吞掉却什么都不做）；负责的 agent 注册了处理器后，启动时自动绑定 AE 的默认快捷键，不用改目录。已经部分实现的命令的其他变体（例如 显示所有修改的属性）要等目录把状态改成已实现。
- 工具快捷键由 A 自己绑定（目录里标"另行绑定"）；数字小键盘的快捷键暂时绑定不了（BAE 还不区分小键盘）。
- 快捷键编辑器里能看到、能改所有已生效的快捷键。

## 6. 领域命令（bae-motion）与 AE 默认值

- 新图层默认放在选中图层上方（没有选中时在最上面），锚点在内容中心，位置在合成中心；纯色在 `/assets/solids` 建纯色素材；形状图层的内容结构与 AE 相同（内容 > 矩形 1 > 内容 > 矩形路径 1 / 填充 1，组有自己的变换）。
- 默认名字按 AE 编号（Comp 1、Shape Layer 1、Solid 1……），中文界面传入中文名（合成 1、形状图层 1……）；形状内部项目的名字暂时固定为英文。
- 缓动：速度 0、影响 33.33%，位置等空间属性一组，其他按维度。
- 父级：默认保持屏幕位置，换算位置、旋转、缩放（静态值和全部关键帧），父级有非均匀缩放加旋转时与 AE 有细微差别。
- 新关键帧的空间插值跟首选项"默认的空间插值为线性"走（默认开 = 线性；关掉后新的空间关键帧是自动贝塞尔）✅。表达式输入框的字号和颜色跟首选项"表达式编辑器"走（语法高亮还没有）。
- 数值拖动只在松手时提交一个撤销步骤；查看器在拖动时实时预览变换属性，其他属性（颜色、形状大小）松手后更新。

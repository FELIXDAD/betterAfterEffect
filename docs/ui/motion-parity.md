负责工作流：12 `ui/motion`。本表列出 After Effects 动效工作区的交互细节，以及 BAE 当前的实现状态。命令列是 `bae-motion` / `bae-model` 的命令 id，界面、快捷键和 Agent 走同一条命令。

状态：✅ 已实现　◐ 部分实现（见说明）　☐ 未实现

## 4. 快捷键（AE 键位，动效工作区）

AE 26 的全部菜单项和默认快捷键命令（669 条，32 个上下文）都登记在 [AE 命令目录](ae-commands.md)，每条对应一个 BAE 动作 id、负责的 agent 和状态。

**覆盖率**：AE 默认快捷键文件 669 条命令，612 条有默认快捷键；**已生效 120 条**（Windows 和 macOS 各 120 条：命令已实现，AE 键位表里按 AE 的默认快捷键绑定，按 AE 的上下文限定面板；查看器和时间轴自己的动作只在它们自己的面板里绑定，AE 在别的上下文里重复列出的不算）。数字由目录生成，见目录的"统计"一节。

## 6. 领域命令（bae-motion）与 AE 默认值

- 新图层默认放在选中图层上方（没有选中时在最上面），锚点在内容中心，位置在合成中心；纯色在 `/assets/solids` 建纯色素材；形状图层的内容结构与 AE 相同（内容 > 矩形 1 > 内容 > 矩形路径 1 / 填充 1，组有自己的变换）。
- 默认名字按 AE 编号（Comp 1、Shape Layer 1、Solid 1……），中文界面传入中文名（合成 1、形状图层 1……）；形状工具和钢笔工具建的组、路径和蒙版由命令按界面语言命名（矩形 1、矩形路径 1、描边 1、填充 1、多边星形 1、形状 1、路径 1、蒙版 1，`bae_motion::names`）。图层 ▸ 新建 ▸ 矩形 / 椭圆建的形状内部项目名字暂时固定为英文。
- 缓动：速度 0、影响 33.33%，位置等空间属性一组，其他按维度。
- 父级：默认保持屏幕位置，换算位置、旋转、缩放（静态值和全部关键帧），父级有非均匀缩放加旋转时与 AE 有细微差别。
- 新关键帧的空间插值跟首选项"默认的空间插值为线性"走（默认开 = 线性；关掉后新的空间关键帧是自动贝塞尔）✅。表达式输入框的字号和颜色跟首选项"表达式编辑器"走（语法高亮还没有）。
- 数值拖动只在松手时提交一个撤销步骤；查看器在拖动时实时预览变换属性，其他属性（颜色、形状大小）松手后更新。

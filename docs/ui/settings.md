# 首选项（macOS：设置）

AE：Windows 上是 编辑 ▸ 首选项 ▸ 各页，macOS 上是 After Effects ▸ 设置 ▸ 各页（AE 2026 在 Mac 上叫"设置"）。BAE 的动作 id 是 `app.settings`，参数 `{"page": "<页面 id>"}`；常规页的快捷键是 Cmd+Option+; / Ctrl+Alt+;。菜单入口由主菜单工作流（B）放，处理器在外壳里。

## 结构

| 部分 | 位置 | 内容 |
|---|---|---|
| 数据 | `crates/bae-prefs` | 19 页的结构（分组、行、控件类型、英文文字、范围、单位、默认值、对应的 AE 首选项键、联动条件、平台），读写、校验，`PrefsStore`（当前值、代号、订阅），中文文字表 |
| 对话框 | `crates/bae-ui/src/settings.rs` | 按结构画出对话框；`settings::apply` 把标签和外观交给主题；`GridGuides` 给查看器画网格和安全边距 |
| 外壳 | `apps/bae` | 启动时读文件、打开对话框、确定后保存并应用（撤消级别、主题）、"在访达/资源管理器中显示首选项"、"选择文件夹..."、自动保存 |

- 文件：配置目录下的 `preferences.json`（`bae_platform::SettingsFile` 信封，`kind = "bae-preferences"`，`version = 1`），内容是 `"页面.名字": 值` 的平铺对象。
- 读取宽松：缺的键用默认值；类型不对或选项不存在的键用默认值；数字超出范围时夹到范围内；不认识的键（新版本写的）原样保留、写回。文件损坏（不是 JSON、`kind` 不对）时移到 `preferences.json.corrupt`，全部用默认值，不会崩。
- 确定才保存；取消、Esc、关闭按钮都不保存。冒烟测试不读也不写这个文件。

## 别的模块怎么读

```rust
// 面板：从资源里拿（apps/bae 插入的 Arc<PrefsStore>）
let store = cx.resources.get::<Arc<bae_prefs::PrefsStore>>();
let prefs = store.current();            // Arc<Preferences>，便宜
prefs.bool(bae_prefs::keys::DEFAULT_SPATIAL_LINEAR);
// 变了再刷新缓存：比较 store.generation()，或 store.subscribe(|p| …)
```

命令 crate（bae-motion 等）可以依赖 `bae-prefs`（不开 `file` 特性就没有平台依赖）。

## 已经生效的设置

| 页面 | 设置 | 接到哪里 |
|---|---|---|
| 常规 | 撤消级别 | `Stage::set_undo_limit`（每个打开的项目都用） |
| 网格和参考线 | 网格颜色、样式、网格线间隔、次分隔线；动作安全、字幕安全、中心剪切动作安全、中心剪切字幕安全 | 合成查看器的网格和"标题/动作安全"（`GridGuides`） |
| 标签 | 16 种标签颜色和名称 | `theme::label_color` / `theme::label_name`（时间轴图层条、项目面板、查看器手柄等所有用标签颜色的地方） |
| 外观 | 亮度、影响标签颜色、交互控件、焦点指示器 | 每帧细分后的顶点颜色统一经过 `theme::adjust`（只改界面自己画的形状和文字，不改图像和查看器画面）；默认值时完全不处理 |
| 自动保存 | 自动保存项目、保存间隔、最大项目版本、自动保存位置（项目旁边 / 自定义） | 有未保存的更改时，按间隔把副本写到项目旁边的 `BAE Auto-Save` 文件夹（或自定义文件夹），`<名字> auto-save N.bae`，满了覆盖最旧的；不改项目本身的位置和保存状态。未命名项目只在设了自定义文件夹时保存 |

## 待核（需要 R1 在 AE 26 上核对）

页面和控件是按已有资料（`docs/reference/ae/preferences.json` 的键）和对 AE 2025 的了解先做的；R1 的 `docs/reference/ae/ui/preferences-dialog.json` 合并后逐项对齐。拿不准的：

1. 按钮位置：现在是右边一竖列（确定、取消，空一行，上一个、下一个），协调人和我的印象一致，等 R1 确认。
2. 默认值以 AE 26 的 preferences.json 为准（撤消级别 99、自动保存间隔 5 分钟、最大版本 3）；磁盘缓存大小 100 GB、运动路径"不超过 15 个关键帧"、默认拖动导入为"合成"、参考线颜色是估计值。
3. 常规页是否还有"启动时显示主页屏幕"、"图层双击打开图层面板"之类的项；"在原始图层上创建拆分图层"的位置。
4. "自动重新加载素材"在常规页还是导入页；"导入"页的序列素材选项全不全。
5. 外观页：亮度滑块的范围（键名是 `[0.0..1.0]`，默认 0，即最暗？），是否还有"使用渐变"、"使用无障碍对比度"。
6. 内存与性能、视频预览、音频硬件、类型、3D、通知各页的控件清单和文字。
7. 表达式编辑器：AE 用主题（"After Effects 经典暗色"）而不是逐个颜色；是否能选字体。
8. 中文文字：按 AE 中文版习惯翻译的，需要 R1 用中文版截图核对。

# 首选项（macOS：设置）

AE：Windows 上是 编辑 ▸ 首选项 ▸ 各页，macOS 上是 After Effects ▸ 设置 ▸ 各页（AE 2026 在 Mac 上叫"设置"）。BAE 的动作 id 是 `app.settings`，参数 `{"page": "<页面 id>"}`；Cmd+Option+; / Ctrl+Alt+; 打开"启动和修复"页。菜单入口由主菜单工作流（B）放，处理器在外壳里。

AE 26 把首选项改成 16 页（`docs/reference/ae/menus.json`，Mac 见 R2 的 `docs/reference/ae/mac/`），顺序和菜单里的分隔线：

| 页面 id | 英文 | 中文 |
|---|---|---|
| `startup_repair` | Startup & Repair | 启动和修复 |
| `project` | Project | 项目 |
| `composition` | Composition | 合成 |
| `previews` | Previews | 预览 |
| ― | | |
| `appearance` | Appearance | 外观 |
| `grids_guides` | Grids & Guides | 网格和参考线 |
| `labels` | Labels | 标签 |
| `type` | Type | 类型 |
| ― | | |
| `import` | Import | 导入 |
| `export` | Export | 导出 |
| ― | | |
| `audio` | Audio | 音频 |
| `disk` | Disk | 磁盘 |
| `memory_cpu` | Memory & CPU | 内存和 CPU |
| `video` | Video | 视频 |
| ― | | |
| `3d` | 3D | 3D |
| `scripting_expressions` | Scripting & Expressions | 脚本和表达式 |

存储键（`general.levels_of_undo`、`auto_save.interval`……）沿用功能名，不等于页面 id。

## 结构

| 部分 | 位置 | 内容 |
|---|---|---|
| 数据 | `crates/bae-prefs` | AE 26 的 16 页结构（分组、行、控件类型、英文文字、范围、单位、默认值、对应的 AE 首选项键、联动条件、平台），读写、校验，`PrefsStore`（当前值、代号、订阅），中文文字表 |
| 对话框 | `crates/bae-ui/src/settings.rs` | 按结构画出对话框；`settings::apply` 把标签和外观交给主题；`GridGuides` 给查看器画网格和安全边距 |
| 外壳 | `apps/bae` | 启动时读文件、打开对话框、确定后保存并应用（撤消级别、主题）、"在访达/资源管理器中显示首选项"、"选择文件夹..."、自动保存 |

- 文件：配置目录下的 `preferences.json`（`bae_platform::SettingsFile` 信封，`kind = "bae-preferences"`，`version = 1`），内容是 `"页面.名字": 值` 的平铺对象。
- 读取宽松：缺的键用默认值；类型不对或选项不存在的键用默认值；数字超出范围时夹到范围内；不认识的键（新版本写的）原样保留、写回。文件损坏（不是 JSON、`kind` 不对）时移到 `preferences.json.corrupt`，全部用默认值，不会崩。
- 确定才保存；取消、Esc、关闭按钮都不保存。冒烟测试不读也不写这个文件。

## 别的模块怎么读

```rust
// 面板：从资源里拿（apps/bae 插入的 Arc<PrefsStore>）
let store = cx.resources.get::<Arc<bae_prefs::PrefsStore>>();
let prefs = store.current();            // Arc<Preferences>，便宜
prefs.bool(bae_prefs::keys::DEFAULT_SPATIAL_LINEAR);
// 变了再刷新缓存：比较 store.generation()，或 store.subscribe(|p| …)
```

命令 crate（bae-motion 等）可以依赖 `bae-prefs`（不开 `file` 特性就没有平台依赖）。

## 已经生效的设置

| 页面 | 设置 | 接到哪里 |
|---|---|---|
| 启动和修复 | 撤消级别 | `Stage::set_undo_limit`（每个打开的项目都用） |
| 网格和参考线 | 网格颜色、样式、网格线间隔、次分隔线；动作安全、字幕安全、中心剪切动作安全、中心剪切字幕安全 | 合成查看器的网格和"标题/动作安全"（`GridGuides`） |
| 标签 | 16 种标签颜色和名称 | `theme::label_color` / `theme::label_name`（时间轴图层条、项目面板、查看器手柄等所有用标签颜色的地方） |
| 外观 | 亮度、影响标签颜色、交互控件、焦点指示器 | 每帧细分后的顶点颜色统一经过 `theme::adjust`（只改界面自己画的形状和文字，不改图像和查看器画面）；默认值时完全不处理 |
| 自动保存 | 自动保存项目、保存间隔、最大项目版本、自动保存位置（项目旁边 / 自定义） | 有未保存的更改时，按间隔把副本写到项目旁边的 `BAE Auto-Save` 文件夹（或自定义文件夹），`<名字> auto-save N.bae`，满了覆盖最旧的；不改项目本身的位置和保存状态。未命名项目只在设了自定义文件夹时保存 |

## 待核（需要 R1 在 AE 26 上核对）

页面列表、顺序和 id 已按 AE 26 的菜单定好；每页里的控件是把 AE 2025 的 19 页内容按理解放进 16 页的，R1 的 `docs/reference/ae/ui/preferences-dialog.json` 合并后逐页对齐。目前的放法（拿不准的都要核）：

- 启动和修复：启动时显示主页屏幕、撤消级别、显示工具提示、使用系统拾色器、（Mac）使用系统快捷键、在访达/资源管理器中显示首选项。AE 26 这一页大概还有"重置首选项""修复"一类按钮，现在没有。
- 项目：同步所有相关项目的时间、在项目面板中禁用缩略图、自动保存（分组）、新建项目（模板、纯色 / 填充文件夹，分组）。
- 合成：路径点和手柄大小、在合成开始时间创建图层、开关影响嵌套的合成、默认的空间插值为线性、保持蒙版顶点数、在原始图层上创建拆分图层、新形状图层锚点居中、运动路径。
- 预览：原预览页 + 硬件加速合成/图层/素材面板、在信息面板和流程图中显示渲染进度、显示备用时间。
- 导出：原输出页 + 原通知页（渲染完成时通知 / 播放声音）。
- 音频：原音频硬件、音频输出映射两页（两个分组）。磁盘：原媒体和磁盘缓存页。内存和 CPU：原内存与性能页。视频：原视频预览页。
- "以简明英语编写表达式拾取"只放在脚本和表达式页。

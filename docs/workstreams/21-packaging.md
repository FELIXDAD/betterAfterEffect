# 21 · 工程与素材打包

| 项 | 内容 |
|---|---|
| 分支 | `io/packaging` |
| Orca 工作区 | `bae-21-packaging` |
| 阶段 | P2 |
| 依赖 | 02（素材引用、工程文件格式）、08（裁片需要的解码/直拷/编码） |
| 负责目录 | `crates/bae-package/` |

## 目标

参考 Blender 的资源打包，把工程和用到的素材打成一个自包含的 `.baez` 单文件；可选只打包时间线上实际用到的视频片段。设计见 `docs/ARCHITECTURE.md` 第 16 节。

## 要做

- **素材收集**：遍历工程（含嵌套合成）找出所有被引用的素材；区分"用到的"和"项目里有但没用到的"。
- **素材引用解析**：相对路径 → 绝对路径 → 按文件名 + 指纹搜索 → 缺失；批量重新链接；路径映射规则（Windows 盘符、UNC、macOS /Volumes）。
- **打包**：`.baez`（zip，大文件用 zip64；媒体存储不压缩、可直接定位读取；工程数据压缩）；直接打开 `.baez`（素材按需从包内读取）与解包成目录两种方式；"收集文件到文件夹"。
- **视频裁片（可选）**：
  - 计算每个素材实际用到的源时间区间：图层入出点、时间伸缩、时间重映射、嵌套合成递归、同一素材多处使用时合并重叠区间。
  - 参数先留好、默认值后续再定：前后余量、是否重新编码、目标编码。
  - 默认优先无损直拷（按关键帧边界切；对不齐时扩展到最近关键帧），由 08 提供能力。
  - 裁片只生成新文件放进包内，包内工程的引用改为新文件 + 时间偏移；原始素材与原工程不改。
  - 图片序列只打包用到的帧。
- **字体**：可选打包（提示字体许可），否则只记录字体名与回退字体。
- **报告**：缺失素材、体积统计、裁片前后对比。
- **命令**：打包、解包、收集文件都是命令（在非界面 crate 里注册），Agent 也能调用。

## 验收

- 一个引用了分散在多个目录的素材的工程，打包后在另一台电脑（或改名移走原素材后）能完整打开。
- 开启裁片后，体积明显减小，画面与原工程逐帧一致（含时间重映射和嵌套合成的测试用例）。
- 原始素材文件的修改时间和内容都不变（有测试）。

## 不做

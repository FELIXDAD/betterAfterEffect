# 12 · 动效工作区（AE 式）

| 项 | 内容 |
|---|---|
| 分支 | `ui/motion` |
| Orca 工作区 | `bae-12-ui-motion` |
| 阶段 | P2 |
| 依赖 | 03、04、11（以及 05、07 的面板对接） |
| 负责目录 | `crates/bae-motion/`（动效领域命令）、`crates/bae-ui-motion/`（界面） |

## 目标

做一个 AE 用户打开就会用的动效工作区：布局、交互、快捷键都和 AE 一致。

## 要做

- **领域命令（bae-motion，不依赖界面）**：预合成、序列图层、关键帧助手（缓动 F9、缓入、缓出、时间反向）、从矢量图层创建形状、拆分图层、修剪到工作区、对齐、父级设置等。Agent 也能直接调用这些命令。
- **面板（bae-ui-motion）**：
  - 项目面板：素材、合成、文件夹，与 AE 一致的列。
  - 合成查看器：缩放、分辨率、网格/参考线/安全框、变换手柄、遮罩和路径绘制、3D 视图切换。
  - 时间轴：图层列表；开关列（显示、音频、独奏、锁定、消隐、折叠、质量、效果、运动模糊、调整图层、3D）；父级与关联器（pick whip）；属性展开（U、UU、P/S/R/T/A）；关键帧的拖动、框选、复制粘贴；工作区范围、标记；图表编辑器（值图表、速度图表）；已缓存帧绿条。
  - 效果控件、效果和预设、字符、段落、对齐、预览（播放控制）、渲染队列面板。
- **协同显示**：其他人的选中状态和播放头、属性值来自哪个工程层的标记。
- **AE 一致性清单**：在 `docs/ui/motion-parity.md` 里列出 AE 的交互细节与实现状态。

## 对外接口

- 动效工作区注册到 11；`bae-motion` 的命令注册到 CommandRegistry。

## 验收

- 一位 AE 用户不看文档，能完成：新建合成 → 形状图层 → 位置和缩放关键帧 → F9 缓动 → 图表编辑器调曲线 → 预览 → 加入渲染队列导出。
- 在 B1 基准工程里拖动播放头流畅。

## 不做

- 剪辑序列（14）、Ai 风格绘图工具（13）。

### 20 interop/aex-compat → 12（2026-11-20）

AE 插件的自定义界面要两个界面位置，现在只需要在布局上留出来，实现等 19 的 ABI 0.2。详见 `docs/spec/aex-compat.md` §3.12、§5.4。

1. **R12-01 效果控件里的自绘区域。** 一行参数的标题区和 / 或控件区可以由效果绘制，全宽，高度由效果设置且可变，坐标是面板坐标，支持鼠标捕获和键盘焦点。
2. **R12-02 查看器叠加层与视图变换。** 合成和图层查看器在画面上方为选中的效果回放显示列表、转发事件（拖动时捕获、键盘焦点、悬停、离开），并提供视图变换快照（面板像素 ↔ 合成 / 图层像素，含缩放、平移、降采样、像素宽高比、设备缩放）。

协调人决定（14 任务书"已决定"第 2 条）：项目面板、效果控件、效果和预设面板由 12 实现，通过 11 的 Panel API 注册成全局面板，14 的剪辑工作区直接复用，剪辑特有的行为通过扩展点（trait 或 hook）加，不复制面板。0.0.1 不需要实现剪辑那一侧，只请在设计面板时留好下面的扩展点，免得以后改面板结构（条目见 `docs/spec/pr/`）：

1. **项目面板**：别的模块能追加列（例如"视频使用情况""音频使用情况"，PR-PRJ-012）、追加视图模式（Pr 的自由格式视图，PR-PRJ-008）、追加右键菜单项和双击行为（剪辑工作区里双击素材是"在源监视器中打开"，PR-MON-001）、按当前工作区切换默认列和排序；序列（`Sequence` Prim）作为一种项目项显示，有自己的图标和双击行为。缩略图上的悬停擦洗可以作为可选行为由 14 注册（PR-PRJ-009）。

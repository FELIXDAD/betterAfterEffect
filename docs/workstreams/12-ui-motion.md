## 目标

做一个 AE 用户打开就会用的动效工作区：布局、交互、快捷键都和 AE 一致。

## 要做

- **领域命令（bae-motion，不依赖界面）**：预合成、序列图层、关键帧助手（缓动 F9、缓入、缓出、时间反向）、从矢量图层创建形状、拆分图层、修剪到工作区、对齐、父级设置等。Agent 也能直接调用这些命令。
- **面板（bae-ui-motion）**：
  - 项目面板：素材、合成、文件夹，与 AE 一致的列。
  - 合成查看器：缩放、分辨率、网格/参考线/安全框、变换手柄、遮罩和路径绘制、3D 视图切换。
  - 时间轴：图层列表；开关列（显示、音频、独奏、锁定、消隐、折叠、质量、效果、运动模糊、调整图层、3D）；父级与关联器（pick whip）；属性展开（U、UU、P/S/R/T/A）；关键帧的拖动、框选、复制粘贴；工作区范围、标记；图表编辑器（值图表、速度图表）；已缓存帧绿条。
  - 效果控件、效果和预设、字符、段落、对齐、预览（播放控制）、渲染队列面板。
- **协同显示**：其他人的选中状态和播放头、属性值来自哪个工程层的标记。
- **AE 一致性清单**：在 `docs/ui/motion-parity.md` 里列出 AE 的交互细节与实现状态。

## 对外接口

- 动效工作区注册到 11；`bae-motion` 的命令注册到 CommandRegistry。

## 验收

- 一位 AE 用户不看文档，能完成：新建合成 → 形状图层 → 位置和缩放关键帧 → F9 缓动 → 图表编辑器调曲线 → 预览 → 加入渲染队列导出。
- 在 B1 基准工程里拖动播放头流畅。

## 不做

- 剪辑序列（14）、Ai 风格绘图工具（13）。

### 进展记录

- 2026-11-20（PR A，`[interface]`）：新建 `crates/bae-motion`，不依赖界面和 GPU。18 个命令，全部是一个撤销单元、按 schema 校验，Agent 通过 MCP 直接可用：
  - 合成与项目：`comp.create`（尺寸、帧速率 fps 自动换成 NTSC 有理数、时长、背景色；同时建 `layers` 文件夹；默认放在 `/comps`，名字按 AE 编号 "Comp N"）、`comp.set_work_area`（B / N）、`comp.trim_to_work_area`、`folder.create`。
  - 图层：`layer.create`（形状 / 文本 / 纯色 / 空对象 / 摄像机 / 灯光 / 调整图层 / 预合成 / 素材；AE 默认值：放在最上面、锚点在中心、居中；纯色在 `/assets/solids` 建纯色素材；形状图层可带矩形 / 椭圆 / 星形和填充）、`layer.reorder`、`layer.duplicate`（Cmd+D，放在原图层上方，名字递增）、`layer.split`（Cmd+Shift+D）、`layer.trim`（Alt+[ / ]）、`layer.set_parent`（父级；默认保持屏幕位置不变，用 03 的求值结果换算位置、旋转、缩放，含关键帧；防止循环）。
  - 关键帧：`attr.set_animated`（秒表）、`attr.set_at`（在当前时间改值：有关键帧就加 / 改关键帧，没有就改静态值）、`key.ease`（F9 缓动、Shift+F9 缓入、Cmd+Shift+F9 缓出；速度 0、影响 33.33%，按维度生成）、`key.set_interpolation`、`key.move`（拖动，落到已有关键帧上时替换）、`key.delete`（删光时关掉秒表并保留值）、`key.reverse`（时间反向）、`key.paste`。
  - 关键帧时间与 `key.set` 一致，用存储的时间（图层属性是图层时间）；入点、出点、拆分、工作区用合成时间。`bae_motion::query` 提供合成设置、图层列表、图层时间换算、显示名等只读帮助函数，界面和命令共用。
  - 注册：`bae_motion::register_commands(&mut CommandRegistry)`；`MotionModule` 把命令发布到 `bae_app::Registry<dyn DynCommand>`（id = 命令 id），应用从这里收集各模块的命令（接入 apps/bae 在下一个 PR）。
  - 测试：7 个集成测试（经过 CommandRegistry 执行，覆盖撤销、父级换算前后世界坐标一致、缓动的维度、关键帧移动 / 反向 / 粘贴 / 删除、工作区）。

## 请求（其他工作流在这里留言）

### 20 interop/aex-compat → 12（2026-11-20）

AE 插件的自定义界面要两个界面位置，现在只需要在布局上留出来，实现等 19 的 ABI 0.2。详见 `docs/spec/aex-compat.md` §3.12、§5.4。

1. **R12-01 效果控件里的自绘区域。** 一行参数的标题区和 / 或控件区可以由效果绘制，全宽，高度由效果设置且可变，坐标是面板坐标，支持鼠标捕获和键盘焦点。
2. **R12-02 查看器叠加层与视图变换。** 合成和图层查看器在画面上方为选中的效果回放显示列表、转发事件（拖动时捕获、键盘焦点、悬停、离开），并提供视图变换快照（面板像素 ↔ 合成 / 图层像素，含缩放、平移、降采样、像素宽高比、设备缩放）。

P3：R12-03 效果元数据展示（已弃用分组、GPU / 非线程安全 / 水印徽标、"关于"和"选项…"按钮）。

1. **项目面板**：别的模块能追加列（例如"视频使用情况""音频使用情况"，PR-PRJ-012）、追加视图模式（Pr 的自由格式视图，PR-PRJ-008）、追加右键菜单项和双击行为（剪辑工作区里双击素材是"在源监视器中打开"，PR-MON-001）、按当前工作区切换默认列和排序；序列（`Sequence` Prim）作为一种项目项显示，有自己的图标和双击行为。缩略图上的悬停擦洗可以作为可选行为由 14 注册（PR-PRJ-009）。

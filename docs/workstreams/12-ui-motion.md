# 12 · 动效工作区（AE 式）

| 项 | 内容 |
|---|---|
| 分支 | `ui/motion` |
| Orca 工作区 | `bae-12-ui-motion` |

## 目标

做一个 AE 用户打开就会用的动效工作区：布局、交互、快捷键都和 AE 一致。

## 要做

- **领域命令（bae-motion，不依赖界面）**：预合成、序列图层、关键帧助手（缓动 F9、缓入、缓出、时间反向）、从矢量图层创建形状、拆分图层、修剪到工作区、对齐、父级设置等。Agent 也能直接调用这些命令。
- **面板（bae-ui-motion）**：
  - 项目面板：素材、合成、文件夹，与 AE 一致的列。
  - 合成查看器：缩放、分辨率、网格/参考线/安全框、变换手柄、遮罩和路径绘制、3D 视图切换。
  - 时间轴：图层列表；开关列（显示、音频、独奏、锁定、消隐、折叠、质量、效果、运动模糊、调整图层、3D）；父级与关联器（pick whip）；属性展开（U、UU、P/S/R/T/A）；关键帧的拖动、框选、复制粘贴；工作区范围、标记；图表编辑器（值图表、速度图表）；已缓存帧绿条。
  - 效果控件、效果和预设、字符、段落、对齐、预览（播放控制）、渲染队列面板。
- **协同显示**：其他人的选中状态和播放头、属性值来自哪个工程层的标记。
- **AE 一致性清单**：在 `docs/ui/motion-parity.md` 里列出 AE 的交互细节与实现状态。

## 对外接口

- 动效工作区注册到 11；`bae-motion` 的命令注册到 CommandRegistry。

## 验收

- 一位 AE 用户不看文档，能完成：新建合成 → 形状图层 → 位置和缩放关键帧 → F9 缓动 → 图表编辑器调曲线 → 预览 → 加入渲染队列导出。
- 在 B1 基准工程里拖动播放头流畅。

## 不做

- 剪辑序列（14）、Ai 风格绘图工具（13）。

## 目标

写一套规范的《Agent 动画操作指南》，让 Agent 不只是能连上 BAE，还知道怎样做出合格的动画、怎样和人协作。

## 要做

- **指南（`docs/agent-guide/`）**：
  1. 概念与术语：AE/Ai 概念与 BAE 的对应关系；工程层、提案层是什么。
  2. 操作流程：先读后写（先 `stage.describe`）；只在自己的提案层工作；用事务把相关修改分组；命名规范（合成、图层、标记）；每完成一步就渲染关键帧自检。
  3. 动画规范：
     - 用帧思考时间，常见时长参考表（按 24/25/30/60 fps）。
     - 缓动：默认不用线性（机械运动除外）；常用缓动曲线及适用场景。
     - 节奏：错帧（stagger）、层级、预备动作、跟随与重叠、过冲与回弹、停顿。
     - 文字动画、Logo 演绎、转场、镜头运动、按音乐节拍卡点的常见做法。
  4. 分镜规范：镜头号、时长、景别、运动标注的写法。
  5. 协作礼仪：不修改别人的层；需要改时留批注说明；每个提案写清楚改了什么、为什么。
  6. 质量检查清单与自评标准（rubric）。
  7. 配方（recipes）：标题出场、下三分之一字幕、Logo 演绎、数据图表动画、UI 动效、分镜生成动态分镜、交接给 AE 用户。
  8. 常见错误与反例。
- **Agent Skill（`skills/bae-animation/SKILL.md`）**：把指南打包成 Claude / Codex 可以加载的 Skill。
- **MCP instructions 精简版**：交给 17 内置到服务器里。
- **评测集**：一组任务描述 + 期望结果 + 评分标准，之后用来自动评测 Agent 的操作质量。

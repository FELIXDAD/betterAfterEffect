## Media Foundation 占位

源码 `crates/bae-media/src/media_foundation.rs`：`MediaFoundationFormat::open` 固定：

```text
video decoding on Windows (Media Foundation) is not implemented yet: <path>
```

仓库外探测（`E:\bae-test\media-probe`，不提交）：对带 `ftyp` 的假 `.mp4`：

```text
sniffed=mediafoundation
open=Err: not supported: video decoding on Windows (Media Foundation) is not implemented yet: …
```

见 [`media-mf-probe.txt`](./media-mf-probe.txt)。

**编码：** 文档写明 ProRes 等走可选 FFmpeg 插件；本测未跑视频编码路径。图片序列编码（PNG/EXR 序列）已由 export 测试覆盖。

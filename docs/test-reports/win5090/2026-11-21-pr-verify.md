## 重要更正汇总

1. **默认过渡持续时间（PR-FX-017）**：偏好 › 时间轴 — 视频 **25 帧**、音频 **1.00 秒**（非「均为 1 秒」）。
2. **封闭间隙菜单位置（PR-TL-012）**：**序列 › 封闭间隙**（词典键 `Close Gap` →「封闭间隙」，非「闭合间隙」）。
3. **嵌套序列快捷键（PR-TL-036 / PR-KEY-007）**：中文版 Windows 默认键位（`zh\...Defaults.kys` 及中文 UI 实测）为 **Ctrl+Shift+F**，而英文版 `en\...Defaults.kys` 已更新为 **Ctrl+Alt+F**（`Ctrl+Shift+F` 让给 `cmd.searchwindow.open`），命令名 **「显示嵌套的序列」**。
4. **修剪监视器进入方式（PR-KEY-007 / PR-MON-019）**：**Shift+T** 在 Windows 上有效（kys 绑定 `cmd.placeholder`，非无效占位）。
5. **Ctrl+修饰常规修剪（PR-TL-018）**：编辑点**左侧** Ctrl+单击/拖动 → **波纹（黄）**；**正中** → **滚动（红）**；需点在剪辑体而非不透明度线。
6. **直通编辑连接（PR-TL-027）**：效果冲突时保留 **左侧（前段）** 属性（如 Position X=400，非 900）。
7. **剪辑音量 `]` 与关键帧（PR-AUD-004）**：播放头在两关键帧之间按 `]` → **在播放头加新关键帧**；落在现有关键帧上 → **改该关键帧 dB 值**（非整体平移）。
8. **时间重映射（PR-TL-039）**：**Alt** 拖动速度关键帧 → 倒放段（五边形标记）；**Ctrl+Alt** → 定格段。
9. **混合模式数量（PR-FX-005）**：不透明度下拉 **27 种**（含溶解、相减、相除等），与词典 `BlendModeChoicesUI` 一致。
10. **标记面板切换（PR-MRK-007）**：面板菜单为 **「显示所有标记 / 显示序列标记 / 显示剪辑标记」**（非「显示所有序列标记」措辞）。
11. **吉他套件（PR-FX-023）**：26.2 效果面板 **音频效果 › 特殊 › 吉他套件** 仍在。
12. **弹簧键工具（PR-KEY-004）**：按住 C/H **1s** 时工具栏仍高亮 **V**，未见临时切换 — Windows 默认键位表亦无 spring 绑定 → **疑似不支持**（与 macOS 待核描述不同）。
13. **游动/水平滚动字幕（PR-GFX-007）**：属性 › 响应式设计 - 时间下仅有垂直 **「滚动」** 开关（启动/结束屏幕外、预/后滚动、缓慢放大/缩小、柔化），**无内置「游动（Crawl）」入口**，水平游动需手动打位置关键帧。
14. **标记颜色偏好（PR-MRK-004）**：首选项 20 个分类中仅有项目/剪辑 16 色「标签」页，**无「标记颜色」偏好页**；标记对话框为固定 8 色块（绿/红/淡紫/橙/黄/白/蓝/青），不可在偏好中改色值或改名。
15. **停止回放与预/过卷（PR-MON-004）**：空格停止后播放头停在原地；首选项「回放」与「时间轴」均**无「停止时返回初始状态」开关**（仅「时间轴」有「在回放末尾，重新开始回放时返回开头」默认勾选）；另「回放」默认**预卷 3 秒、过卷 2 秒**（非均为 2 秒）。
16. **J/K/L 穿梭倍速与 Shift+L（PR-MON-005）**：连按 L/J 为 **2 的幂次倍速**（**1× → 2× → 4× → 8× → 16× → 32×**，非 2×/3×/4×）；**Shift+L 不是「每按一次慢一档」**，而是 **+10%（+0.1×）步进加速**（从停止按 1/2/3 次约 0.1×/0.2×/0.3×，在 1×/2× 基础上按 Shift+L 加速至约 1.1×/2.1×）；K+按住 L 为慢速正放（约 0.17×），K+点按 L 前进 1 帧。
17. **范围标记快捷键（PR-KEY-009）**：Windows 上 `Ctrl+Shift+M` 为「转到上一标记」，`Ctrl+M` 为「导出媒体」；26.0.2 中文 UI 与 `标记(M)` 菜单未启用范围标记（词典标为 BetaFeature），仅英文 `en\...Defaults.kys` 预留 `cmd.set.rangedmarker = Ctrl+Alt+Shift+N`、`cmd.set.rangedmarker.inandout = Alt+Shift+N`。
18. **添加到收藏夹（PR-KEY-013）**：属 **媒体浏览器面板**（非项目面板），用于将磁盘目录收藏到媒体浏览器顶部「收藏夹」；Windows 26.0.2 默认无快捷键绑定（非 `Alt+Shift+A`）。
19. **Shift 单击轨道定位（PR-TL-014）**：不是「独占」，而是 **批量切换同类型全部轨道（所有视频或所有音频）的定位开关**；Alt/Ctrl 单击亦仅单轨切换。
20. **剃刀切点是否补关键帧（PR-KF-008）**：实测 `clip_b`（1s X=500、5s X=900）在 3s 处 `Ctrl+K` 切开后，Pr **不在切点补关键帧**——左右两段 XML 均完整继承全部原始源时间关键帧（`1.0s` 与 `5.0s`），靠范围外关键帧自然保持切点连续（两侧在 3s 处插值均为 `700.0`，EC 菱形空心），且拉长切口时原关键帧仍在；与 BAE 提案「切点补一个关键帧」不一致。另实测确认修剪入点保留范围外关键帧、200% 变速使源 5s 关键帧落至时间轴 2.5s、外滑（`edit-model.md` #10）关键帧保持源时间并随画面内容移动。
21. **Windows 默认键位非机械映射例外（`shortcuts.md` HEADER）**：逐项比对 `shortcuts.md` 全表与本机 26.0.2 `en`/`zh` 默认 `.kys`，除正文已列 3 条外，共查出 **12 处**非 `Cmd→Ctrl / Opt→Alt` 映射例外（详见文末对照表），最易踩坑的是 **导出帧（`Ctrl+Shift+E`）与启用剪辑（`Shift+E`）互换**、**修剪（`Ctrl+←/→`）与微移（`Alt+←/→`）互换**、清除入/出点（`Ctrl+Shift+I/O/X`）、从入点播到出点（`Ctrl+Shift+Space`）、切换修剪类型（`Ctrl+Shift+T`）、不合拢修剪至播放头（`Ctrl+Alt+Q/W`）、上一间隙（`Ctrl+Shift+;`）、清除标记（`Ctrl+Alt+M` / `Ctrl+Alt+Shift+M`）、范围标记（`en` 为 `Alt+Shift+N` / `Ctrl+Alt+Shift+N`，`zh` 未绑定）、首选项与多机位切机位 9 未绑定，以及 `en`（392 条）与 `zh`（334 条）默认 `.kys` 的分歧。

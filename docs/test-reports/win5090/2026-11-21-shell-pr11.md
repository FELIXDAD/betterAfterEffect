## 细节

1. 启动日志：`GPU device created … Dx12 … DiscreteGpu`；初始窗口 a11y 尺寸 2182×1406（含装饰）。
2. 缩放后状态栏示例：`1778x1264 @1.50x`（第二屏）/ `2878x1564 @1.50x`（回到主屏放大后）。
3. 清晰度：在 1.50x 下文字与图标边缘正常，未见明显模糊发虚（目视截图）。
4. 中文重命名：自动化可把文本贴进编辑态，但确认（Return）后名称未保留——可能焦点/重命名提交路径未吃掉粘贴内容；需人工用中文输入法再验一次。

# Windows 实机：#6 AE vs BAE 速度对比（B1 动效图形）

- 日期：2026-11-21
- 机器：Windows 11 + **NVIDIA GeForce RTX 5090 D v2**（D3D12, discrete）
- BAE：`origin/dev` @ **`afc054f`**；`WGPU_DX12_COMPILER=fxc`；`BAE_GPU_VALIDATION=0`
- AE：**After Effects 2026 `26.0x67`**
- 锁：持有 `ae.lock` + `perf.lock`；测速期间未并行编译/其它重负载
- 产物（本机，不进仓库）：`E:\bae-test\b1-speed\`（`B1.aep`、ae-out TIFF×300、bae-out PNG×300）

## 测法（写进 0.0.1 发布说明时可直接引用）

### 场景

B1 级动效图形（对齐 `docs/perf.md` / `fixture::b1` 的**当前代替品**定义）：

| 项 | 值 |
|---|---|
| 分辨率 / 帧率 / 时长 | 1920×1080 / 30 fps / 10 s = **300 帧** |
| 图层 | **61**：50 动画纯色 + 10 段素材标签 PNG + 1 背景 |
| 动画 | 位置（3 关键帧）、旋转、缩放、不透明度；每第 5 个纯色用 Add/Screen/Multiply/Overlay |
| 效果 | **无模糊/发光**（与当前 fixture 一致；真实形状/文字/效果待 05/07） |

AE 工程由 JSX 搭好后 `app.project.save()` → `E:\bae-test\b1-speed\B1.aep`（渲染队列已写入）。  
BAE 工程：`cargo run -p bae-render --release --example b1_project` → `E:\bae-test\b1-bae\B1.bae`。

两边图层数/时长/帧率对齐；AE 侧 RNG 近似 fixture 种子 `0xB1`，**不做像素对齐**（本任务只比速度）。

### AE：`aerender.exe`（无界面）

1. 清崩溃标记后 warm-start AfterFX，`-r` 写入 RQ 后 `app.quit()`。
2. 渲染设置模板：**`最佳设置`**；输出模块：**`带有 Alpha 的 TIFF 序列 `**（本机中文模板名，末尾有空格）。
3. 计时命令（墙钟 = 进程寿命，含 aerender 拉起 AE）：

```text
aerender.exe -project E:\bae-test\b1-speed\B1.aep -v ERRORS_AND_PROGRESS
```

4. 输出：`E:\bae-test\b1-speed\ae-out\b1_####.tif` × **300**。

### BAE：`bae render`（写 PNG 序列）

```text
bae render E:\bae-test\b1-bae\B1.bae --comp b1 --frames all --depth 8 --resolution full -o ...\b1_####.png --json
```

墙钟 = 进程寿命（含 GPU 初始化与 PNG 编码）。`--json` 另报 `total_ms`（本轮 12273.5 ms）。

### 公平性说明

- 同一台机器、先后跑，不并行重负载。
- **编码格式不同**：AE = TIFF+Alpha；BAE = PNG 8 bpc。墙钟对比含磁盘编码，不是纯 GPU。
- aerender 墙钟含启动 AE；BAE 墙钟含设备创建。
- 另附 B1 **bench**（`cargo xtask bench -p bae-render --bench b1`，不算文件编码）作参考——见 §2。

## 4. #6b 追测（PNG 对齐 / 1 帧开销 / `bae --json` 分相 / 3× 中位数）

日期续：2026-11-21；同一机器与同一 `bae.exe`（`afc054f`，`WGPU_DX12_COMPILER=fxc`）。持有 `ae.lock`+`perf.lock`。机器 JSON：[`speed-b1-6b-timings.json`](./speed-b1-6b-timings.json)（源：`E:\bae-test\b1-speed\6b\timings.json`）。

### 4.1 AE PNG 怎么拿到

中文 AE 2026：RQ **Format 只读**，无可用 PNG OM 模板（`settable`/`OM` 探测见本机 `6b/om-probe*.txt`）。  
改用 **`comp.saveFrameToPng` + 每次 `new File(path)` 重读 `exists/length`**（ExtendScript 同一 `File` 对象上 `length` 会卡在 0）。  
计时含打开工程 + 逐帧写盘等待，**不是** `aerender` RQ 路径——比 TIFF aerender 慢属预期。

### 4.2 3× 中位数总表

| 侧 | 方法 | 帧 | 3× 墙钟 (s) | **中位数 (s)** | 导出 fps |
|---|---|---:|---|---:|---:|
| AE | `saveFrameToPng` PNG | 300 | 25.652 / 22.645 / 22.419 | **22.645** | **13.25** |
| AE | `saveFrameToPng` PNG | 1 | 1.728 / 1.810 / 1.810 | **1.810** | — |
| AE | `aerender` TIFF+Alpha（§1 单次） | 300 | — | **18.269** | 16.42 |
| AE | `aerender -s0 -e0` TIFF | 1 | 8.180 / 7.915 / 7.939 | **7.939** | — |
| BAE | `bae render` PNG 8bpc | 300 | 13.015 / 13.010 / 13.009 | **13.010** | **23.06** |
| BAE | `bae render --frame 0` PNG | 1 | 1.006 / 1.007 / 1.003 | **1.006** | — |

**同格式 PNG 墙钟比（AE PNG / BAE PNG）≈ 1.74×**（BAE 更快）。  
相对 §1 的 TIFF aerender，BAE PNG 仍约 **1.40×**。

### 4.3 1 帧开销（近似启动）

`overhead ≈ t_one − t_all/300`：

| 侧 | overhead (s) | 含义 |
|---|---:|---|
| AE TIFF aerender | **~7.88** | 拉起 AE + 读工程为主 |
| AE PNG saveFrameToPng | **~1.73** | 打开工程 + 首帧；无独立 aerender 进程 |
| BAE PNG | **~0.96** | 进程/GPU 初始化；与 `total_ms` 差墙钟一致 |

BAE 单帧：墙钟中位 **1.006 s**，`--json` `total_ms` ≈ **57 ms** → 约 **0.95 s** 在进程外（启动/设备）。

### 4.4 BAE `--json` 分相（300 帧，三次）

| 运行 | Σ `eval_ms` | Σ `render_ms` | `total_ms` | 墙钟 (s) |
|---|---:|---:|---:|---:|
| 1 | 88.5 | 1579.0 | 11955 | 13.015 |
| 2 | 94.7 | 1586.0 | 12064 | 13.010 |
| 3 | 88.0 | 1530.1 | 11802 | 13.009 |

单帧（中位墙钟那次附近）：`eval_ms`≈0.80，`render_ms`≈45.8（含首帧暖机）；后续帧 `render_ms` 中位约 **5.3–5.4 ms**。  
GPU 标注：`NVIDIA GeForce RTX 5090 D v2 (D3D12, discrete)`。  
测速空闲抽检 `nvidia-smi`：利用率 0%（未在导出峰值采样；导出时以墙钟与 `--json` 为准）。

### 4.5 结论（给 0.0.1）

- 同机、同 B1、**同 PNG**：BAE 最终导出墙钟约 **1.7×** 于 AE `saveFrameToPng`；对 AE `aerender` TIFF 约 **1.4×**。
- BAE 瓶颈仍在 **PNG 编码/写盘**（bench `export_fps_full`≈304 vs 写盘 ≈23 fps）。
- AE 侧无 RQ PNG 时，勿把 `saveFrameToPng` 墙钟当成 aerender 级吞吐。

## 问题 / 备注

1. 中文 AE 的 `-RStemplate "Best Settings"` **无效**；须用 **`最佳设置`**，或先把 RQ 写进 `.aep` 再 `aerender -project`。
2. OM 名 **`带有 Alpha 的 TIFF 序列 `** 末尾有空格，脚本需精确匹配。
3. 本机无现成「PNG 序列」OM 模板；RQ Format 只读 → #6b 用 `saveFrameToPng` 做 PNG 对齐。
4. B1 仍是纯色+标签纹理代替品，无模糊/发光；换代后需重测并注明。
5. ExtendScript：`File.length` 在同一对象上可能一直为 0；等待时需 `new File(path)` 重打开。

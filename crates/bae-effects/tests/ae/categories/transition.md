## 渐变图层输入

渐变擦除默认读取当前图层的源，也可选择独立控制图层。

本组在一次加锁的 `aectl run` 中生成了 51 帧。与其他类别用例共用 `cases.json` 的输入生成器和误差单位。最大差取整帧所有 RGBA 通道的最大绝对差。平均差先逐像素取四通道最大绝对差，再对全幅求平均。

| 用例 | 最大差 / 平均差（8 位色阶） | 实测行为或剩余误差 |
|---|---|---|
| 线性擦除 | 1 / 0.002；斜向羽化 55 / 1.319 | 热点位于画框与羽化边的交点，解析边缘积分没有完整复现 AE 在画框处的滤波。 |
| 径向擦除 | 9 / 0.013；双向羽化 52 / 0.654 | 起始射线和移动射线在圆心汇合，近圆心的双边羽化和 AE 不同。 |
| 百叶窗 | 18 / 1.547；斜向羽化 81 / 2.339 | 条带以图层中心为基准；亚像素边的取样相位及画框边界仍有差异。 |
| 渐变擦除 | 0 / 0；反转加柔和度 4 / 0.096 | 当前图层的 Rec.601 亮度先量化，再比较阈值。 |
| 块溶解 | 255 / 97.231 | 块消失的顺序不同；柔化边缘按相邻网格采样。该帧 alpha 的标准差为 AE 85.0、BAE 86.0。 |

## 渐变擦除的控制图层

读取独立渐变图层，提供拼贴、居中和拉伸。硬阈值按实测量化完成度，三个普通渐变用例覆盖 8 / 16 / 32 bpc，最大差为 1/255。反转柔和擦除最大差为 3/255。见[图层与蒙版输入复测](channel.md#图层与蒙版输入复测)。

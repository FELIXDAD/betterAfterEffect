## 演化与外部输入

分形杂色支持四种采样方式、分数复杂度、种子、演化与循环。AE 与 BAE 分别在相同的循环起止点复现自己的图像。同种子在两端会生成不同纹理。分形类型中的脏污到线程（菜单值 12–20）暂按基本型渲染。添加颗粒的胶片预设使用 AE 色阶图实测的 RGB 颗粒强度，噪点位置与 AE 有差异。添加颗粒的外部蒙版图层尚待渲染图接入，相关选择器及设置保留并禁用。

本组在一次加锁的 `aectl run` 中生成了 51 帧。与其他类别用例共用 `cases.json` 的输入生成器和误差单位。最大差取整帧所有 RGBA 通道的最大绝对差。平均差先逐像素取四通道最大绝对差，再对全幅求平均。

| 用例 | 最大差 / 平均差（8 位色阶） | 实测行为或剩余误差 |
|---|---|---|
| 杂色（彩色 25%、单色 15%） | 64 / 30.781；38 / 2.658 | 随机序列不同；25% 用例中间调的通道扰动标准差均约 18.5。 |
| 分形杂色（默认、种子 7、复杂度 2.5） | 131 / 13.724；84 / 23.215；150 / 44.561 | 格点周期约 66.7 px（缩放 100）；BAE 使用整数哈希生成自己的格点值。小缩放下逐像素最大差可达 255。 |
| 分形杂色（循环两圈，−90° → 630°） | 两帧各 103 / 33.681 | AE 两帧彼此完全一致。GPU 测试分别验证 BAE 的 RGBA16F / RGBA32F 首尾一致、非循环整圈改变图像、种子和分数复杂度生效。 |
| 添加颗粒（最终输出、随机种子 17） | 20 / 4.588；22 / 4.519 | 用 13 个胶片预设在灰阶上的通道标准差校准相对强度。胶片颗粒的空间分布和 AE 不同。 |

`noise_amplitude_matches_ae` 另行比较灰阶格点、块覆盖率、中间调的 RGB 扰动均值和标准差，避免仅凭较大的逐像素容差放过空白图像。当前 AE golden 全部来自 8 bpc；GPU 测试单独覆盖整数裁剪、16 bpc 擦除阈值和 HDR 填充。

## 中间值、蒙尘与划痕

| 效果 | 最大 | 平均 | 对照结果 |
|---|---:|---:|---|
| 中间值 | 2 | 0.048 | 不透明纹理在测试的所有半径、位深逐像素一致。透明邻域的直通颜色受预乘精度影响。 |
| 蒙尘与划痕 | 1 | 0.001 | 阈值按 RGB 最大通道差判定，边缘只统计有效样本。读取直通输入时，处理 alpha 的半透明边最大差 1。其余用例逐像素一致。 |

完整 3×3 邻域直接取中位数，较大半径按通道比较实际样本。32 bpc 的负值和超白值会保留。

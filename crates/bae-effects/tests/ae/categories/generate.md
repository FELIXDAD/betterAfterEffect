# 生成与 AE 26 的像素对照

本组在一次加锁的 `aectl run` 中生成了 51 帧。与其他类别用例共用 `cases.json` 的输入生成器和误差单位。最大差取整帧所有 RGBA 通道的最大绝对差。平均差先逐像素取四通道最大绝对差，再对全幅求平均。

| 用例 | 最大差 / 平均差（8 位色阶） | 实测行为或剩余误差 |
|---|---|---|
| 填充（透明素材、降低不透明度、反转、无蒙版羽化） | 0–1 / ≤0.036 | 不透明度同时缩放填充颜色和 alpha。无蒙版时，设置羽化不改变图像。 |
| 线性及径向渐变 | 1 / ≤0.014 | 使用整数像素坐标计算色值，保留输入覆盖率。 |
| 四色渐变（混合 25、50、100、200） | 1 / ≤1.000 | 每个控制点的权重与 `1 / (距离² + 混合半径²)` 成正比；归一化后混色。 |
| 网格 | 1 / 0.073；羽化 4 / 0.256 | 单元格间距随图层尺寸变化，线条向内羽化。 |

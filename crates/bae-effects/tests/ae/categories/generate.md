## 图层与蒙版输入

无蒙版填充以素材原有的 Alpha 为覆盖率，羽化对它无效。指定或使用全部蒙版时，经过羽化的覆盖率决定填充色叠加的范围。

本组在一次加锁的 `aectl run` 中生成了 51 帧。与其他类别用例共用 `cases.json` 的输入生成器和误差单位。最大差取整帧所有 RGBA 通道的最大绝对差。平均差先逐像素取四通道最大绝对差，再对全幅求平均。

| 用例 | 最大差 / 平均差（8 位色阶） | 实测行为或剩余误差 |
|---|---|---|
| 填充（透明素材、降低不透明度、反转、无蒙版羽化） | 0–1 / ≤0.036 | 不透明度同时缩放填充颜色和 alpha。无蒙版时，设置羽化不改变图像。 |
| 线性及径向渐变 | 1 / ≤0.014 | 使用整数像素坐标计算色值，保留输入覆盖率。 |
| 四色渐变（混合 25、50、100、200） | 1 / ≤1.000 | 每个控制点的权重与 `1 / (距离² + 混合半径²)` 成正比；归一化后混色。 |
| 网格 | 1 / 0.073；羽化 4 / 0.256 | 单元格间距随图层尺寸变化，线条向内羽化。 |

## 填充蒙版

指定蒙版和全部蒙版的覆盖图由渲染器生成，GPU 对覆盖图分别做水平与垂直羽化，再将颜色叠到原画面。指定、全部和反转用例逐像素一致，方向羽化最大差为 3/255。图测试验证选择一个蒙版时保留其他蒙版中的原画面。见[图层与蒙版输入复测](channel.md#图层与蒙版输入复测)。


## 描边、写入、涂抹和勾画

在 macOS 的 AE 26.2.1（8 bpc、无项目色彩管理、非线性混合）上探测画笔和路径。描边的大小是半径，间距按直径的百分比换算，实际下限为 1%。起止值从同一个固定落点序列裁切。写入的时间参数按 16.16 定点秒采样。永久路径从图层入点累计，有限路径从当前时间减去描边长度的位置重排落点。当前帧恰好是落点时刻时，AE 在下一帧才纳入该落点。首个采样时刻会画出落点。

涂抹的静态探针确认了基于投影包围盒的扫描顺序与连接方向。角度为 0° 时扫描竖线，90° 时扫描横线。硬边以 4×4 子像素采样。复杂边缘分段、转弯形状与随机序列近似，随机开启后不能按位置重现 AE 的笔迹。勾画的开口蒙版探针中，AE 忽略最后一段。均匀分布沿弧长划分，成簇分布把各段相接，旋转按整条路径长度换算。勾画的轮廓链接、边缘和透明度过渡是近似。 [Adobe 生成效果说明](https://helpx.adobe.com/after-effects/desktop/apply-effects-and-animation-presets/list-of-effects/generate-effects.html)

勾画的图像模式在 GPU 上提取通道并应用阈值，回读单通道数据后在 CPU 上连接等高线，再由 GPU 画片段。图像模式增加了一次同步。蒙版模式直接使用求值后的贝塞尔数据。

27 张参考图的误差如下。色阶单位为 1/255，平均值按全幅统计。

| 用例 | 最大差 | 最大全幅平均差 |
|---|---:|---:|
| 描边，笔刷、顺序裁切、斜线与贝塞尔揭示 | 10 | 0.100 |
| 写入，亚像素落点、时间窗与逐落点历史属性 | 2 | 0.024 |
| 涂抹，静态内部与边缘填充 | 255 | 6.347 |
| 勾画，开口蒙版、闭合蒙版与图像等高线 | 217 | 1.272 |

额外探针里，描边半径 0.9 px、间距 1% 时，笔刷重叠的整数舍入差异使最大差升至 67，全幅平均差为 0.323。大半径、高硬度的静态写入最大差为 8。涂抹的随机摆动和重叠探针全幅平均差最高为 25.837，主要来自两边随机序列产生的笔迹位置不同。勾画硬边的最大差集中在边缘。图像等高线应用轮廓简化，宽、窄两组的全幅平均差分别为 1.131 和 1.272。
